## 방법(검증됨)
1. `generate-image` — 기준 그림체 `imageReferences=[MEDIA MAHXa5OetnI]`(AI랩 학생들+선생님+로봇 그림), `SQUARE_1_1`. 프롬프트 앞부분: "Flat vector illustration, bright friendly educational style, soft pastel colors, plain white background, absolutely no text or letters. Same cartoon cast and drawing style as the reference image. Scene: …". 끝나면 `get-generate-image-job` 로 MEDIA id 를 받는다.
2. 한꺼번에 못 받는다. 한 번에 2~9장까지만 접수되고 나머지는 `quota_cooldown`. 몇 분 쉬면 2~6장씩 다시 된다(이번에 막힌 이유).
3. 내려받기(전용 스크래치 디자인 `DAHXaxRv8No`): 3쪽(`PBQQhCSd2p7P9Pwv`, 3792×3792, 3×3 칸)의 칸 그림을 `update_fill` 로 새 그림으로 바꾼다 → `commit` → `export-design`(png, pages [3], 3792×3792) → curl.
   - 칸 locator = `PBQQhCSd2p7P9Pwv-` + [LBNjfvrG6Q3DZ2LV, LBHPnMypz6xqWZH9, LB3KrFGWTqsR8Zrt, LBCyNbv70LKJ3wJD, LBrFWWgSyvRTzbKX, LBVGlv0T9vcJVNZZ, LBXHwLWXzp7mKMVs, LBzXfYhKs2QlcMqS, LBKY7HnJ4bL2lbg6] (행 우선).
   - 편집 전에 `read-design`(open_transaction, page_indices [3]) 로 transaction_id 를 받는다. 로컬에 저장되는 이미지는 200px 썸네일뿐이라 이 방법으로만 원본 크기를 얻는다.
4. 9장 시트를 640px WebP 로 잘라 저장(장당 10~30KB): `python -I cut.py <sheet.png> public/img/aimath 3 640 <이름…>` (스크립트: 이 문서 맨 아래).
5. `unit.json` 에 `images` 를 달고 검사기를 돌린다.

## 2단원 장면 계획(남은 것)
시작 전 이야기① s1-3 엉뚱한 검색 결과 카드 / ② 도서관: s2-1 큰 도서관, s2-2 십진분류 책장, s2-3 도서관에서 문서가 숫자로 바뀌는 화면 / ③ 번역기: s3-1 사전 직역이 엉터리, s3-2 단어 지도(뜻이 비슷하면 가까움), s3-3 관용구에 헷갈린 번역 / ④ 비꼬는 말: s4-1 식당 앱 감성 분류, s4-2 차가운 국물에 비꼬는 후기, s4-3 사람이 후기를 읽는 장면.

## cut.py
```python
import sys, os
from PIL import Image
sheet, outdir, cols, size = sys.argv[1], sys.argv[2], int(sys.argv[3]), int(sys.argv[4])
names = sys.argv[5:]
im = Image.open(sheet).convert("RGB")
cell = im.width // cols
os.makedirs(outdir, exist_ok=True)
for i, n in enumerate(names):
    if n == "-": continue
    r, c = divmod(i, cols)
    tile = im.crop((c*cell, r*cell, (c+1)*cell, (r+1)*cell)).resize((size, size), Image.LANCZOS)
    tile.save(os.path.join(outdir, n + ".webp"), "WEBP", quality=80, method=6)
```
