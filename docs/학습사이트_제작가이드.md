# 학습 사이트 제작 가이드 (손발전기 사이트를 본보기로)

새 학습 사이트(예: 간이 전동기, 종이 비행기, 비누 만들기)를 만들 때 이 문서를 보고 **같은 방식으로** 만든다.
작업지시서(AI에게 줄 설명서)는 `public/handgen/guide.md`이고, 이 문서는 **어디를 어떻게 고치는지** 알려 주는 안내서다.

| 항목 | 위치 |
|---|---|
| 안내 페이지(작업지시서 편집·복사) | `public/handgen/index.html` → https://penedu.web.app/handgen/ |
| 같이 해보기 | `public/handgen/together/index.html` |
| **완성 사이트(본보기)** | `public/handgen/site/index.html` → https://penedu.web.app/handgen/site/ |
| 작업지시서 원문 | `public/handgen/guide.md` |
| 멘트 mp3 + 길이 | `public/handgen/audio/` (`a01.mp3`…, `durations.json`) |
| 학습지 파일 | `public/handgen/worksheet/` (학생용·교사용 `.docx` `.hwpx`) |
| 만들기 도구 | `scripts/make-narration.py`, `scripts/make-worksheet.py` |
| 메인 카드 | `src/site.ts`의 `SECTIONS` |

## 1. 새 사이트 만드는 전체 순서 (한눈에)

1. 폴더 복사: `public/handgen/` → `public/새이름/` (안내·같이 해보기·사이트·작업지시서가 한 묶음)
2. `public/새이름/guide.md`의 [대괄호]를 새 주제로 고친다.
3. AI에게 "이 작업지시서대로 진행해. 단계마다 멈추고 보고해."
4. 교육과정 조사 → 원고 → 그림 → 구조 → 실험·퀴즈·학습지 → 영상 → 검토 순으로 확인하며 진행
5. 안내·같이 해보기 페이지 제목과 문구, `src/site.ts` 카드, 파일 안의 링크(`/handgen/` → `/새이름/`)를 바꾼다.
6. `npm run build` → 휴대폰 너비로 확인 → `npm run deploy`

> 폴더를 복사한 뒤 반드시 바꿀 문자열 검색: `handgen`, `손발전기`, `10통과2-02-05`, `a01`~`b10`

## 2. 완성 사이트 파일(`site/index.html`) 구조

한 파일 안에 위에서 아래로 이렇게 들어 있다. **바꿀 곳만 바꾸고 나머지는 건드리지 않는다.**

| 순서 | 구역 | 코드에서 찾는 곳 | 새 주제에서 하는 일 |
|---|---|---|---|
| 1 | 히어로 | `<header class="hero">`, `#heroFig` | 제목, 한 줄 설명, 대표 그림 |
| 2 | 준비물 | `const PARTS=[...]` | 줄마다 `["이름", 개수, "아이콘 SVG"]` |
| 3 | **만들기 단계** | `const STEPS=[...]` | 단계마다 `t, svg, txt, check, time, warn` |
| 4 | 안 켜질 때 | `<section id="fix">` 안의 `<details>` | 자주 틀리는 것 5개 |
| 5 | 기초자료 | `<section id="base">` | 교육과정 표, 용어 카드, 수치 표, 자가진단, 생활 속 예 |
| 6 | 원리·실험 | `<section id="why">`, `(function(){ const cv=$('#sim')…` | 슬라이더 2개와 그래프 식 |
| 7 | **영상** | `const A=[…]`, `const B=[…]` | 5절 참고 |
| 8 | 퀴즈 | `const QZ=[...]` | `{q, o:[보기 4개], a:정답 번호(0~3), e:해설}` |
| 9 | 학습지 | `<section id="sheet">` | 빈칸·기록표·탐구 질문, `class="ans"`는 정답 |

## 3. 만들기 단계 쓰는 법 (학생이 따라 하기 쉽게)

### 3-1. 한 단계의 코드 모양
```js
{ t:"링을 끼우고 자석 넣기",                       // 제목: 동사로 끝낸다
  svg:()=>tube({gap:0,dim:true,mag:.5,alt:"…"}),   // 그림: 한 개의 그리기 함수에 옵션만 바꿔 호출
  txt:["문장 1 (동작 하나, 숫자 포함)","문장 2"],
  check:["링 사이가 12~13mm인가요?","자석이 관 안에서 움직이나요?"],   // 예/아니오로 답할 수 있게
  time:"약 3분",
  warn:"자석이 아주 강해요. 손가락이 끼이지 않게 조심하세요." }       // 다치거나 망가지는 것만
```

### 3-2. 문장 쓰는 규칙
- 한 문장에 동작 하나. "~하고 ~한 뒤 ~하세요" 대신 문장을 나눈다.
- 길이·개수·시간은 숫자로: "5~6바퀴", "약 100mm".
- 확인 문장은 눈으로 보고 답한다: "선 끝이 구릿빛으로 반짝이나요?" (O) / "잘 했나요?" (X)
- 주의는 단계마다 1개. 많으면 아무것도 안 읽는다.
- 단계는 4~6개, 한 단계 5분 안팎.

### 3-3. 예: 손발전기의 4단계
| 단계 | 제목 | 확인 3~4개 (요약) |
|---|---|---|
| 1 | 링을 끼우고 자석 넣기 | 링 간격 12~13mm / 자석이 움직임 / 마개 닫힘 |
| 2 | 에나멜선 감기 | 한 방향 촘촘히 / 끝 100mm 남김 / 끝 코팅 벗겨 구릿빛 |
| 3 | LED 끼우기 | 링이 벌어짐 / LED 다리가 안→밖으로 나옴 |
| 4 | 모으고 고정하기 | 링 모임 / 다리에 5~6바퀴 감김 / 당겨도 안 빠짐 / 흔들면 깜빡임 |

## 4. 그림(SVG)을 통일하는 법

### 4-1. 원칙
- 모든 그림을 `tube(옵션)` **하나의 함수**로 그린다. 단계 그림, 영상 장면, 히어로가 모두 이 함수를 쓰므로 모양과 색이 저절로 같아진다.
- 부품 색은 한 번 정하면 끝까지 같게 쓴다. 손발전기: 투명관 연한 파랑, 링 초록, 코일 구리색, N극 빨강, S극 파랑, 마개 회색.
- 색은 `:root` 변수로 쓴다. (`var(--cu)`, `var(--tube)` …) 다크 모드에서 자동으로 바뀐다.
- 그림마다 `aria-label`(대체 텍스트)을 쓴다. (`alt:"…"` 옵션)

### 4-2. `tube()` 옵션표 (새 주제는 이 표처럼 옵션을 정해 새 함수를 만든다)
| 옵션 | 값 | 뜻 |
|---|---|---|
| `gap` | 0~1 | 링 사이 벌어진 정도 |
| `ringIn` | 0~1 | 링이 공중에서 내려오는 정도 (1=멀리 떠 있음) |
| `caps` | 0~1 | 마개가 닫힌 정도 (0=위에 떠 있음) |
| `mag`, `magY` | 숫자 | 자석 가로 위치(0.17=왼쪽 끝, 0.725=가운데, 1.28=오른쪽 끝), 세로 이동 |
| `coil` | true/0~1 | 코일 감긴 비율. `spool:true`면 실패에서 풀리는 선이 보임 |
| `ends`, `endTxt` | 0~1, false | 남긴 선 끝, "약 100mm" 글자 표시 |
| `sand` | true | 사포질 |
| `led`, `ledIn`, `legSpread`, `wire`, `nowire` | | LED가 내려오는 정도, 다리가 벌어지는 정도, 전선 |
| `glow` | 0~1 | LED 밝기 |
| `field` | true | 자기장 점선 |
| `cur` | -1~1 | 전류 막대 (빨강=한 방향, 파랑=반대) |
| `shake`, `magAnim` | px | 통째로 흔들기, 자석만 흔들기 |
| `dim`, `labels`, `banner`, `arrows` | | 치수선, 이름표, 아래 문구, 움직이는 화살표 |
| `t` | 초 | 영상용 시간. 있으면 CSS 대신 직접 계산해 움직인다 |

### 4-3. "부품이 아직 없는 상태 → 들어오는 상태"를 그린다
영상에서 학생이 헷갈린 곳이다. 순서대로 보이게 그린다.
- 마개는 처음엔 위에 떠 있다가 **자석을 넣은 뒤** 닫힌다.
- 자석은 관 **밖에서 시작해** 열린 입구로 들어간다. 입구에 걸쳐 시작하면 안 된다.
- 선은 실패에서 풀려 감긴다.

## 5. 영상 만드는 법 (문장 하나 = 동작 하나)

### 5-1. 왜 이렇게 하나
긴 해설 하나를 한 장면에 얹으면 말과 동작이 어긋난다. **짧은 문장마다 장면 하나**를 만들면 말이 끝날 때 동작도 끝난다.

### 5-2. 만드는 순서
1. **대본**: 영상 A(조립) 12문장, 영상 B(원리) 10문장 정도. 1~2절 짜리 문장.
2. **mp3**: `scripts/make-narration.py`의 `LINES`에 `"a01": "문장"`을 쓰고 실행하면 `public/…/audio/a01.mp3`와 `durations.json`이 생긴다.
   ```bash
   pip install edge-tts mutagen
   python scripts/make-narration.py
   ```
   - 목소리: `VOICE = "ko-KR-SunHiNeural"`(여성) / `"ko-KR-InJoonNeural"`(남성), 속도 `RATE = "-6%"`
   - 읽는 말로 적기: `LED`→`엘이디`, `12~13mm`→`십이에서 십삼 밀리미터`, `100mm`→`백 밀리미터`
   - edge-tts는 마이크로소프트의 비공식 무료 서비스다. 만들 때만 인터넷이 필요하고, 사이트에는 mp3 파일만 올라간다. 공개 수업 전에 약관을 확인한다.
3. **장면 코드** (`site/index.html`의 `boot()` 안):
   ```js
   S('a03', '1단계', "이제 자석을 관 속으로 쏙 밀어 넣어요.", "이제 자석을 관 속으로 쏙 밀어 넣어요.",
     (p,t,T)=>tube({t:T, caps:0, dim:true,
                    magY:44*(1-e3(seg(p,.05,.3))),               // 먼저 위로 올라오고
                    mag:lerp(-.068, REST, e3(seg(p,.3,.9))),     // 그다음 입구로 들어간다
                    alt:"자석이 열린 입구로 들어가는 그림"}))
   ```
   - 인수: `S(mp3 번호, 단계 이름표, 자막, 읽을 문장, 그림 함수)`
   - 그림 함수 인수: `p`=장면 진행(0~1), `t`=장면 안 시간(초), `T`=영상 전체 시간(초)
   - 보조 함수: `seg(p,a,b)` = p가 a~b 구간일 때 0→1, `e3()` = 부드럽게, `lerp(a,b,k)` = a에서 b로
4. **길이는 자동**: 장면 길이 = `durations.json`의 mp3 길이 + 0.8초. 손으로 맞추지 않는다.
5. **이어지는 움직임**: 자석 왕복처럼 장면이 바뀌어도 이어져야 하는 움직임은 `T`로 계산한다. (영상 B의 `PH(T)` 참고) 장면이 끝날 때의 모습 = 다음 장면의 시작 모습.

### 5-3. 목소리·음악·조작
- 목소리: 미리 만든 mp3 → 실패하면 브라우저 한국어 음성으로 대신 읽는다.
- 음악: `Music` 객체가 코드로 잔잔한 화음을 만든다. 볼륨 0.22(목소리보다 작게). 저작권 걱정 없음.
- 버튼: ▶/⏸, ↺ 처음부터, 🎵, 🗣, 재생 위치 바. 일시정지 후 재생하면 **그 문장 처음부터** 다시 한다. 선택(음악·목소리 켬/끔)은 기억된다.

### 5-4. 검토 방법 — 반드시 한다
브라우저 콘솔에서 모든 장면의 중간과 끝 프레임을 한 화면에 모아 눈으로 본다. 영상 오류의 대부분(걸침, 미리 보임, 끝까지 안 감)이 이렇게 보인다.
```js
const V=window.__video.A, box=document.createElement('div');
box.style.cssText='position:fixed;inset:0;z-index:9999;background:#fff;overflow:auto;display:grid;grid-template-columns:repeat(4,1fr);gap:6px';
V.scenes.forEach((s,i)=>[.5,1].forEach(p=>{const c=document.createElement('div');
  c.innerHTML=s.draw(p,s.d*p,V.starts[i]+s.d*p)+'<b>'+(i+1)+' '+s.cap+'</b>';box.appendChild(c)}));
document.body.appendChild(box);
```
확인할 것: ①멘트에 나온 것이 화면에 보이는가 ②아직 일어나지 않은 일이 미리 보이지 않는가 ③부품이 겹치거나 걸치지 않는가 ④움직이는 것이 끝까지 가는가 ⑤앞 장면의 끝과 다음 장면의 시작이 이어지는가.

## 6. 학습지 만드는 법

1. **화면용**: `<section id="sheet">` 안의 `.sheet`. 인쇄 스타일은 `@media print`에서 A4·여백 14~16mm·표 테두리·쓰는 칸 높이를 따로 잡고, 학습지 외 요소를 모두 숨긴다.
2. **파일용**: `scripts/make-worksheet.py`의 `content()` 한 곳에 문항을 쓰면 학생용·교사용 `.docx` `.hwpx`가 모두 만들어진다.
   ```bash
   pip install python-docx python-hwpx
   python scripts/make-worksheet.py
   ```
   - 항목 종류: `("h","제목")` `("p","문단")` `("q","질문","정답")` `("t",머리글,행들)`
   - 정답본은 정답을 초록 굵은 글씨로 넣는다.
   - `.hwpx`는 한글 2014 이상에서 열린다. (옛 `.hwp`는 만들지 않는다.)
3. **같은 문항을 화면·워드·한글에서 따로 고치지 않는다.** 문항을 바꾸면 화면(`#sheet`)과 `content()` 두 곳을 같이 고친다.
4. 확인: 만든 `.hwpx`를 한글에서 열어 표 폭·글꼴을 본다. (스크립트는 구조 검증까지만 한다.)

## 10. 이 사이트에 반영한 2022 개정 교육과정 사실 (교사 확인 필요)
- 전자기 유도는 중학교에서 빠지고 고1 통합과학2 **[10통과2-02-05]**(발전기에서 운동 에너지가 전기 에너지로 바뀌는 과정 이해)로 이동했다.
- 성취기준 해설: 코일을 지나는 자기장이 변할 때 유도 전류가 생기는 것을 정성적으로 이해하고 간이 발전기를 만들어 설명한다. 패러데이·렌츠·오른손 법칙 등 방향·세기 계산 법칙은 다루지 않는다.
- **[12물리02-06]** 전자기 유도의 응용(센서·무선통신·무선충전), **[9과14-04]** 중3 전동기(선수 개념).
- 위 내용은 교사 공유 정리본에서 확인한 것이므로 NCIC(ncic.kice.re.kr) 원문과 대조해야 한다.

## 11. 자주 겪는 문제
| 증상 | 원인과 해결 |
|---|---|
| 영상 소리가 안 난다 | 브라우저가 소리를 막음 → 재생 버튼을 눌러야 시작됨(자동재생 아님). 🗣/🎵 켜짐 확인 |
| 영상이 안 움직인다 | 화면이 가려진 창에서는 브라우저가 애니메이션을 멈춘다. 눈에 보이는 창에서 확인 |
| 한글 파일이 안 열린다 | 한글 2014 미만. 워드(.docx)를 쓴다 |
| 메인에서 들어가면 "페이지 없음" | 카드 주소 끝의 `/` 확인, `external:true` 확인, 폴더에 `index.html`이 있는지 확인 |
| 배포했는데 예전 화면 | 브라우저 캐시 → 새로고침(Ctrl+F5) |
| 멘트와 화면이 어긋남 | 문장을 더 쪼갠다. 장면 길이는 mp3 길이로 자동이므로 문장 단위로 그림을 나눠야 맞는다 |
