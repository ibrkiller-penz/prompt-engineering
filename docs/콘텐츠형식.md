# 콘텐츠 형식 안내 (content/prompt/**)

교재 문장을 고치거나 차시를 더할 때 이 문서를 따른다. 형식의 기준 코드는 `src/content/types.ts`.

## 원칙
- **교재 문장은 고쳐 쓰지 않고 그대로 옮긴다.** PDF 줄바꿈 때문에 깨진 띄어쓰기만 바로잡는다 (예: "추 가 제안" → "추가 제안", "나\n옵니다" → "나옵니다").
- PDF 텍스트(`source/text/*.txt`, `pdftotext -layout`)는 **표의 칸이 섞여서** 나올 때가 많다. 표는 반드시 읽기 순서로 다시 확인한다:
  `pdftotext -f <쪽> -l <쪽> -enc UTF-8 <pdf> -` (‑layout 없이) — 인쇄된 쪽 번호 = PDF 쪽 번호.
- 교재에 없는 문장·예시를 지어내지 않는다. 화면 구성상 꼭 필요한 짧은 안내(버튼 글자 등)만 예외. 확인 못 한 곳은 문자열 안에 `TODO(검토)`를 남기고 `review`에 적는다.
- 강조는 `**굵게**`, 줄바꿈은 `\n`만 쓴다.
- JSON 문자열 안의 큰따옴표는 교재의 둥근 따옴표(“ ” ‘ ’)를 그대로 쓴다 (곧은 `"` 금지).
- 교재 차시에 ‘스스로 점검해요’나 ‘오늘의 한 문장’이 없으면 그 블록을 넣지 않는다 (예: 13차시). 다른 쪽 문장을 끌어오지 않는다.
- `**굵게**`는 activity의 `instruction`·`situation`에서도 된다. FreeWrite는 `table`과 `fields`를 함께 쓸 수 있다 (표 아래에 칸).
- 그림은 쓰지 않는다. 비유 카드는 `icon`(아래 목록)으로 대신한다.

## 파일
| 파일 | 내용 |
|---|---|
| `content/prompt/levels.json` | 학교급 이름·부제·차시 제목 |
| `content/prompt/{level}/lesson-NN.json` | 차시 (NN = 01~13) |
| `content/prompt/{level}/cards.json` | 부록 — 바로 쓰는 말/문장/요청문 카드 (`CardsFile`) |
| `content/prompt/{level}/glossary.json` | 부록 — 낱말/개념 사전 (`GlossaryFile`) |
| `content/prompt/{level}/pledge.json` | 약속/협업 원칙 (`PledgeFile`) |
| `content/prompt/lab/{level}/{id}.json` | 실험실 시나리오 (`LabScenario`) |
| `content/prompt/stories/lesson-NN.json` | 차시를 여는 이야기 (`StoryFile`, 학교급별 문체 3가지 + 삽화) |
| `content/prompt/{level}/teacher-guide.json` | 교사용 지도서 앞부분 — 지도 원칙·평가 계획 (`TeacherGuideFile`) |
| `content/prompt/rules/*.json` | 실험실 점검 규칙 |

`level` = `elementary` | `middle` | `high`

## 차시 파일 (Lesson)
```json
{
  "level": "middle", "lesson": 7, "title": "…", "subtitle": "…(차시 표지의 작은 제목)",
  "source": "원문 4장 / 중학 워크북 7차시", "minutes": 45,
  "review": "완료",               // 또는 남은 검토 내용
  "goals": ["이번 시간에 배울 것 1", "…"],
  "blocks": [ … 교재에 나오는 순서대로 … ]
}
```
minutes: 초등 40, 중학 45, 고등 50.

### 교사용 내용 (`teacher`, 교사용 지도서에서 그대로)
```json
"teacher": {
  "goal": "학습 목표 문장", "prep": "준비물",
  "flow": [{ "step": "도입", "min": 5, "activity": "…", "note": "지도 유의점" }],
  "questions": ["핵심 발문"],
  "answers": ["활동 1: …(예시 답안 그대로)"],
  "tip": "지도 팁", "background": "교사를 위한 배경 지식",
  "extension": ["확장 활동 아이디어"],
  "faq": [{ "q": "학생들이 자주 하는 질문", "a": "답" }]
}
```
수업 흐름 표는 `-layout` 텍스트에서 칸이 심하게 섞이므로, 반드시 해당 쪽을 `-layout` 없이 뽑아 단계·시간·활동·유의점을 맞춘다. 맞추기 어려우면 `note`에 `TODO(검토)`.

### 블록 종류
| type | 교재 요소 | 필드 |
|---|---|---|
| `think` | 생각 열기 | `questions: string[]` |
| `story` | 이야기 (장면이 여럿이면 scenes 여러 개) | `title`, `intro?`, `scenes: [{ title?, lines: [{ speaker?, text }], words?: [{ term, def, example? }] }]` — speaker 없으면 서술 문단. 장면 사이 '낱말' 상자는 그 장면의 `words` |
| `explain` | 알아보기 | `title`, `body?: string[]`(문단), `steps?: string[]`(번호 목록), `table?: { headers, rows }`, `dialogue?: [{speaker,text}]`, `after?: string[]`(표·대화 뒤 문단) — 표시 순서: body → steps → table → dialogue → after |
| `words` | 오늘의 낱말 (따로 모인 상자) | `words: [{ term, def, example? }]` |
| `analogy` | 생활 속 비유 | `title`, `body: string[]`, `icon?` |
| `remember` | 꼭 기억해요 | `items: string[]` |
| `promise` | 약속 상자 | `title`, `items: [{ title, body }]`, `note?` |
| `roleplay` | AI 역할 놀이 (초·중) | `title`, `body?: string[]`, `steps?: string[]`, `minutes?` (타이머 기본값) |
| `activity` | 활동 1~3 | `n`(숫자 또는 "연습"), `title`, `instruction?`, `situation?`(상황 상자), `component`, `props` |
| `selfcheck` | 스스로 점검해요 | `items: string[]` |
| `todaySentence` | 오늘의 한 문장 | `text` (따옴표 없이) |
| `note` | 나의 생각 노트 | `prompt` |

`icon`: shirt(옷) · map(길) · scissors(미용실) · cake(케이크) · game(게임 세이브) · baton(인수인계/이어달리기) · house(모델하우스) · camera(사진) · book(책) · chef(요리) · puzzle · compass · bridge · sprout · flag · clock · scale(저울) · note(메모)

## 활동 컴포넌트와 props

공통: 예시 답이 교재(교사용 지도서 포함)에 있으면 꼭 넣는다 → 학생이 "예시 답 보기"로 펼쳐 본다.

### FreeWrite — 자유 쓰기 (가장 흔함)
```json
{ "fields": ["칸 이름", "…"], "rows": 2, "examples": ["칸별 예시 답", ""], "example": "전체 예시 답",
  "dialogue": [{ "speaker": "AI", "text": "…" }],           // 활동 위에 보여 줄 대화(선택)
  "table": { "rowsLabel": "애매한 말", "rows": ["“간단하게”"], "cols": ["나의 기준", "짝의 기준"] } }  // 표 형태(선택) — fields와 함께 쓰면 표 아래에 칸이 나옴
```

### MatchPairs — 낱말 ↔ 뜻 잇기
`{ "pairs": [{ "term": "프롬프트", "def": "AI에게 건네는 질문이나 부탁" }], "example": "예시 답(선택)" }`

### CompareTable — 원한 것 vs 만든 것 ○/×
`{ "leftLabel": "선생님의 조건", "rightLabel": "AI의 첫 결과물", "rows": [{ "want": "…", "got": "…", "answer": "o"|"x", "reason": "예시 이유" }] }`

### Classify — 항목을 칸으로 나누기 (SortExtras · MisVsDiff · ReasonTags 도 같은 컴포넌트)
```json
{ "categories": [{ "id": "mis", "label": "오해" }, { "id": "diff", "label": "의견 차이" }],
  "items": [{ "text": "상황 문장", "answer": "mis", "note": "예시 이유(선택)" }],
  "withReason": true,        // 항목마다 '이유' 칸
  "multi": false,            // 한 항목에 여러 칸 고르기 허용
  "lenient": false,          // true면 맞음/틀림 대신 "예시 답"으로만 보여 줌 (정답 하나를 고집하지 않는 활동, 예: 이유 이름표)
  "tip": "활동 위 작은 안내(선택)", "example": "교재 예시 답 전체(선택)" }
```
`answer`는 문자열 또는 문자열 배열(여러 답 가능). 교재에 정답이 없으면 `answer` 생략 → 비교 없이 고르기만.
이름표(10차시)는 `lenient: true` (교사용 지도 팁: 정답 하나를 고집하지 않음).

### RewriteVague — 막연한 부탁 고치기 (규칙 기반 피드백)
`{ "items": ["더 좋게 해 줘."], "example": "…", "focus": "scope" }` — 상황에 맞춰 한 문장 쓰기는 `items: ["(내 부탁 문장)"]`. `focus: "scope"`는 범위 지키기 중심 점검.

### RestateCheck — 되말하기 판별
`{ "items": [{ "text": "…", "restate": true, "why": "…" }], "meanings": { "phrase", "question", "options": [], "after" } }`

### FourLines — 네 줄/네 칸 만들기
`{ "example": { "problem", "criteria", "boundary", "done" }, "labels": { "problem": "① 무엇을", … }, "boundaryLabel": "하지 않을 것", "topic": true, "topicLabel": "주제", "assemble": true, "closing": "부탁 끝에 붙일 오늘의 한 문장" }`
`labels`로 학교급별 칸 이름을 바꾼다 (초등 '네 칸': 교재 용어 그대로).

### MarkPassage — 글에서 확인할 곳 표시하기 (7차시 '밑줄 긋기')
```json
{ "chunks": [{ "text": "부산 해운대 해수욕장은 매년 6월 1일에 문을 열고,", "verify": true, "where": "해운대구청 누리집" },
             { "text": " 근처에 …", "verify": false }],
  "example": "…" }
```
글을 조각(chunks)으로 나눠 이어 붙인 것이 원문과 같아야 한다. 학생이 조각을 눌러 밑줄 → '어디서 확인할까요?' 칸이 생김.

### VerifyTable — 검증 표 (확인할 사실 / 확인한 곳 / 결과)
`{ "rows": ["미리 채울 사실(선택)"], "count": 3, "cols": ["확인할 사실", "어디서 확인할까요?", "결과"], "results": ["맞음", "틀림", "확인 못 함"], "example": "…" }`

### FormFields — 이름 붙은 칸 채우기 + 문장 조립 (ChoiceRecord · RestartSix · CloseFive · HonestyChecklist 도 같은 컴포넌트)
```json
{ "fields": [{ "key": "chosen", "label": "① 고른 것", "placeholder": "…", "example": "…" }],
  "template": "지난번에 정한 건 이거야.\n목표: {goal}\n…",   // {key} 자리에 칸 내용이 들어감. 비면 그 줄은 빠짐
  "templateLabel": "새 대화에 붙여 넣을 문장",
  "checklist": ["체크 항목(선택)"],
  "situation": "상황(선택)" , "example": "전체 예시(선택)" }
```
- ChoiceRecord(다섯 줄 선택 기록), CloseFive(마무리 다섯 질문)는 `template` 없이 칸만.
- RestartSix(재시작 여섯 줄)는 `template`으로 새 대화에 붙여 넣을 문장을 만든다. 템플릿 문장은 그 학교급 11차시 '오늘의 한 문장'으로 시작한다.
- HonestyChecklist(9차시 AI 사용 밝히기)는 `checklist` + 칸 + `template`. 템플릿 문장은 교재의 'AI 사용 안내' 예시 형식을 따른다(교재에 없으면 template 생략).

### ProjectSteps — 13차시 종합 프로젝트 워크시트
```json
{ "steps": [{ "title": "1단계 — 주제 정하기", "desc": "…", "component": "FourLines", "props": { … } }],
  "rubric": { "title": "자기·친구 평가", "criteria": ["네 줄을 분명히 썼다", "…"], "scale": ["잘함", "보통", "노력"], "who": ["나", "친구"] },
  "print": true }
```
각 단계 `component`는 위 컴포넌트 중 하나. 인쇄 버튼이 A4로 워크시트를 낸다.

## 부록 파일 예
```json
// cards.json
{ "level": "middle", "title": "바로 쓰는 문장 카드", "intro": "…",
  "groups": [{ "title": "결과물을 받기 전", "cards": [{ "text": "…", "lesson": 1, "when": "작업을 시작할 때" }] }] }
// glossary.json
{ "level": "middle", "title": "낱말 사전", "words": [{ "term": "되말하기", "def": "…", "lessons": [1, 5] }] }
// pledge.json
{ "level": "middle", "title": "AI 사용 약속", "intro": "…", "items": [{ "title": "…", "body": "…" }], "source": "워크북 13차시 …" }
```

## 실험실 시나리오 (LabScenario)
기존 예: `content/prompt/lab/middle/busan-climate.json`. 2단계에 더해진 필드:
```json
"starterLabel": "서윤이처럼 한 줄로 시작하기",
"verify": { "intro": "…", "facts": [{ "text": "바로잡은 결과물 속 확인할 사실", "where": "어디서 확인할지 예" }] },
"extras": { "proposal": "AI의 추가 제안 문장", "options": [{ "id": "take", "label": "받는다", "effect": "1장, 30초 늘어남" }, { "id": "skip", "label": "이번엔 뺀다", "effect": "…" }] },
"choiceExample": { "chosen", "why", "dropped", "unsure", "revisit" },
"closeExample": { "problem", "done", "enough", "gap", "reopen" }
```
- 숨은 조건(`hidden`)과 첫 되말하기는 교재 이야기를 그대로 쓴다. 응답 문장(슬라이드 목록 등)은 새로 써도 되지만 `review`에 `TODO(검토)`로 밝힌다.
- **실제처럼 보이는 숫자·통계·가게 이름·날짜를 지어내지 않는다.** 숫자가 필요하면 "(숫자는 기관 자료로 직접 확인 필요)"처럼 쓴다.
- `pick`: 네 줄 요소 수(0~4)에 따라 응답 고르기 — `[{min:4,"good"},{min:2,"partial"},{min:0,"plain"}]`.
- `correctionChecks`: 바로잡는 말에서 찾을 숨은 조건 (정규식).

## 차시를 여는 이야기 (StoryFile)
```json
{ "lesson": 6, "source": "수필 『다 된 줄 알았다』 4장 「…」에서",
  "image": "lesson-06", "imageAlt": "…", "imagePrompt": "Canva 삽화 설명(영문)",
  "levels": {
    "elementary": { "kicker": "이야기로 여는 6차시", "title": "…", "paragraphs": ["…"], "closing": "…" },
    "middle": { … }, "high": { … } } }
```
- 그림 파일은 `public/img/prompt/{image}.webp` (1200×800). 1차시만 `image2`·`image2After`(몇 번째 문단 뒤)로 두 번째 그림.
- 문체: 초등 “선생님은 …했어요” 쉬운 해요체(750~1,000자) / 중학 1인칭 해요체(1,000~1,300자) / 고등 수필 원래 반말 문체(1,200~1,500자). 세 버전 모두 같은 장면.
