5. **미정 사항**: 사이트 하단 출처 문구 최종본, 먼저 만든 `prompt-engineering-guide.web.app` 사이트를 지울지, 실제 AI 연결(4단계), 시나리오 추가 여부·검토자.
6. **다음 시작점**: 사용자 확인 → 2단계: 중학 7~13차시, 초등·고등 13차시 이관, 나머지 활동 컴포넌트(VerifyTable·MisVsDiff·HonestyChecklist·ReasonTags·ChoiceRecord·RestartSix·CloseFive·ProjectSteps), 낱말 사전·말 카드·약속, 실험실 검증~마무리 단계.
