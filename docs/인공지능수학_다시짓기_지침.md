## 2. 레슨 파일 만드는 법
- 현재 파일이 있으면 읽고 좋은 예제·문제는 살려서 **전체를 더 친절하게 다시 쓴 완성본**을 Write 도구로 같은 경로에 저장한다(새 레슨이면 새로 만든다).
- **JSON 은 반드시 Write 도구로 쓴다.** 셸 heredoc·파이썬 heredoc 은 역슬래시를 망가뜨린다. JSON 안에서 수식의 역슬래시는 두 번(`\\times`, `\\frac`).
- 필수 필드 전부(id, unit, order, title, subtitle, minutes, story, question, prereq, sections, terms, aiStory, practice, project, summary). `title` 은 `content/aimath/units.json` 과 같아야 한다. `order` 는 과제에서 지정한 값.
- 분량 목표
  - `story` 8~12문단(1300자 이상), 대화 중심. 새봄고 AI랩 인물(서하·도윤·하은·지후·유 선생님·비트)이 나오고, 이야기 속 사건이 오늘 배울 개념의 필요를 만든다. 서하의 "왜?"가 개념 질문으로 이어진다.
  - `prereq`("먼저 알고 가요") 4~6장: 이 레슨이 기대는 중학교·고1 수학을 짧게 복습. 카드마다 말로 풀기 + 숫자 예 하나.
  - `sections` 4~6개. 섹션마다 ① 왜 필요한가(동기, 비유) ② 말로 설명 ③ 식으로 ④ 숫자 예 순서. 식 변형은 한 단계씩 쓰고 한 줄도 건너뛰지 않는다. 섹션마다 callout: `aha`("한 줄 정리"), 필요하면 `warn`(자주 하는 실수), `tip`, `try`. 개념 본문(검사기가 세는 '개념 글자 수')은 6000자 이상. 새 용어는 처음 나올 때 풀어 쓰고 `term` 블록으로 정의한다.
  - `example` 6개 이상(쉬운 것 → 어려운 것), 풀이는 모든 단계. 표(table)와 목록(list)을 적절히 쓴다.
  - 체험 도구(`widget`)는 과제에서 지정한 것을 설명 직후에 두고 caption 에 "이렇게 해 봐요: ① … ② … ③ …" 형식으로 조작·관찰 안내를 쓴다.
  - `terms` 12~16개, `aiStory` 5~7문단(AI가 이 수학을 어디에 쓰는지, 역사·사람 이야기. **불확실한 연도·인명은 쓰지 않거나 "전해져요/알려져 있어요"로 완화**), `project` 단계 7~8개 + think 3개, `summary` 7~8줄.
  - `minutes` 는 현실적으로 55~75.
- 문제(`practice`) 36~45개, 구성 순서:
  1. 개념 확인(level 1, 가볍게 3~5개)
  2. **기초력 UP · 유형 이름**: 같은 유형을 숫자만 바꾼 비슷한 문제 3~4개씩, 유형 4~6가지(계산 연습). level 1~2.
  3. 쉬운 응용(level 2~3)
  4. **실력 UP**(여러 단계 결합, level 3~4)
  5. 도전(level 5, 서술형 open 은 레슨 전체에서 3개 이하)
  - 문제 id 는 `<레슨id>-q01` 형식으로 이어서. 객관식·숫자·OX 는 힌트 2개와 풀이 필수. 객관식은 정답이 정확히 하나여야 하며 "모두 옳다/해당 없음" 류 보기는 피한다. 숫자 답은 소수면 tolerance 와 단위를 명시한다.
  - 천재 문제지의 '유형'(예: 벡터 크기 구하기, 행렬 성분 읽기, 상대도수로 확률 구하기, 추세선 예측·오차, 접선 기울기, 경사하강법 이동 방향)은 반영하되 문제 문장은 새로 쓴다.
- 모든 계산 정답과 예제 풀이는 python 으로 검산한다.
- 검사: `node scripts/check-aimath.mjs --strict <파일>` 이 오류 0·경고 0 이어야 한다.

## 3. 단원 파일(`unit.json`) 만드는 법
- `why` 4~5문단, `opening`(단원을 여는 이야기) 8~10문단 대화 풍부, `stories` 4편(각 kicker + 제목 + 문단 6~9개: ① 이 수학의 역사·사람 ② 현실 속 사례 ③ 흔한 오해 바로잡기 ④ "만약 이게 없다면?" 상상 이야기 등 단원에 맞게), `future`(수학! 미래를 꿈꾸다) 5~6문단.
- `test`: 기존 종합 문제 15~20개를 유지·보완하고, 끝에 **학력진단평가 A회·B회**를 붙인다(각 8문제: 객관식 6 + 단답 `number` 2. `group` 은 '학력진단평가 A회'/'학력진단평가 B회', id 는 `uN-dA01`~`uN-dA08`, `uN-dB01`~`uN-dB08`, level 1~4 고루, 단원의 모든 레슨 범위 포함). open 은 기존 종합에서 3개 이하.
- 이야기의 역사·사실 주장은 확실한 것만. 불확실하면 쓰지 않는다.
