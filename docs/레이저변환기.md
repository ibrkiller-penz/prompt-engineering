# 레이저 이미지 변환기 (`public/laser/index.html`)

**이 파일이 원본이다.** (2026-10-08, 옛 원본 `26_레이저-이미지변환` 폴더는 폐기)
고치면 `npm run deploy` 로 https://penedu.web.app/laser/ 에 올라간다. 파일 하나(HTML)라서 더블클릭만으로도 열리고, 레이저 PC에 복사해 써도 된다.

- 시작 화면 → 워크플로우(재료별 시작 설정) / 이미지 변환. 주소 끝 `#convert` 는 시작 화면 건너뛰기.
- 워크플로우 데이터는 파일 안의 `MATS`·`WORKFLOWS` 에 있다(새 재료는 여기에 더한다). 가죽·코르크·유리·알루미늄·스테인리스·타일의 숫자는 시작값이며 실제 각인으로 검증하지 않았다.
- 내 워크플로우는 브라우저 `localStorage`(`laserprep.presets.v1`)에 저장하고, 공유 코드는 `LW1:` + base64(JSON).
- 시험 카드: 50×30 mm, 농도 10단계·선 굵기 0.1~0.5 mm·글자·원. DPI 목록별 ZIP.
- 사진은 브라우저 밖으로 나가지 않는다(외부 요청 없음). 새 기능을 넣을 때도 외부 주소를 부르지 않는다.

## 재료 특징 · 설정 이유 (2026-10-08)
- `MATS[].trait` = 재료의 특징, `WORKFLOWS[].why` = 그 재료에서만 해당하는 이유(선택). 나머지 이유(DPI·디더링·반전·톤·선명도 등)는 `whyList()` 가 설정값에서 자동으로 만든다. 값을 바꾸면 설명도 따라 바뀐다.
- 설명은 일반적인 레이저 각인 경험칙이며 실제 각인으로 검증한 것이 아니다. 새 재료를 더할 때도 `trait`·`why` 를 함께 쓴다.

## 현장 팁 · 최대 농도 (2026-10-08)
- `TIPS[재료id]` = 재료별 현장 팁(시작 화면·사이드바에 표시). 유리 팁은 Epilog·JP Plus·Graphics Pro·Boss Laser 안내와 LightBurn 포럼 글을 참고했고(주방세제·젖은 키친타월, 300 DPI, 최대 농도 70~80%, Jarvis, 곡면, 마무리 닦기), 나머지 재료의 팁은 일반 지침이다. 직접 겪은 팁이 생기면 여기에 더한다.
- `maxInk`(최대 농도, %): 가장 어두운 곳도 점을 그 비율만 찍어 점 사이를 벌린다(유리 워크플로우 75). `processGray()` 의 디더링 직전에 `lo + g*m` 으로 적용.
