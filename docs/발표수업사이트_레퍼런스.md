## 1. 무엇을 하는 사이트인가

교사가 전자칠판·TV(16:9, 1920×1080)에 띄워 설명하는 발표용 사이트. 학생 조작 기능은 없다.

| 화면 | 내용 | 조작 |
|---|---|---|
| 표지 | 제목·연도·[시작] | Enter/→ |
| 배경 | ① 신분 피라미드 + 신분 카드 3장(인구·토지 막대, 특권·세금) ② 혁명의 원인 3가지 | Space로 하나씩 강조, → 다음 장 |
| 연표 | 1789~1799 가로 축, 사건 17개, 시기 색 띠 4개, 아래 상세 카드(날짜·설명·명화·왜 중요한가) | ←/→ 사건 이동, Home/End |
| 사료 | 카드 5개 → 읽기 모드(왼쪽 번역문, 오른쪽 배경·출처) | Enter 열기, Space 형광펜, Q 생각해 보기, C 비교 표(s4), Esc 목록 |
| 정리 | 의의·한계(삽화) + 생각해 볼 질문 | Space로 질문 하나씩 |

공통: 1~5 화면 바로 가기, F 전체 화면, 커서 3초 뒤 숨김, 우측 하단 진행 표시("연표 5/17"), 애니메이션 0.3초 이내, 스크롤 없음(한 화면 = 슬라이드 한 장), 인터넷 없이 동작(글꼴·그림 모두 로컬, `dist/index.html` 더블클릭으로도 열림).

## 2. 다른 자료로 바꿔 쓰는 법 (핵심)

**코드는 그대로 두고 데이터와 그림만 바꾸면 된다.**

| 바꿀 것 | 파일 |
|---|---|
| 표지 문구, 배경(신분·원인), 정리(의의·한계·질문) | `src/data/background.json` |
| 연표 시기·사건 | `src/data/timeline.json` (`periods[]`, `events[]`: id, dateISO, date, title, period, summary, why, image, caption) |
| 사료 | `src/data/sources.json` (`paragraphs[]`, `highlights[]`, `glossary{}`, `context`, `sourceNote`, `questions[]`, s4만 `compare[]`) |
| 그림 | `public/images/events/`, `public/images/sources/`, `public/images/illust/` |

- `highlights`·`glossary` 키는 `paragraphs` 안에 **글자 하나 틀리지 않고** 있어야 형광펜·밑줄이 붙는다.
- `node scripts/check-assets.mjs` 로 그림 경로·용량을, 빌드로 JSON 오류를 확인한다.
- 화면 구성 자체(예: 배경을 신분 대신 다른 도식으로)를 바꾸려면 `src/pages/<화면>.jsx` 만 고치면 된다. 키 조작 계약은 `docs/DEV_CONTRACT.md`(`usePageKeys`, `setProgress`).
- 디자인 기준: `docs/DESIGN.md`, `src/styles/tokens.css`(미색 바탕 + 삼색 포인트, 본문 ≥28px, 제목 ≥48px, `--u` 비례 단위).

## 3. 만든 방법 (팀 구성 워크플로)

사용자 지시로 **기획팀·디자인팀·삽화팀·개발팀(각 팀장 1 + 팀원 5) + 총괄기획자**로 나눠 만들었다.

1. 총괄: Vite+React 뼈대, `docs/BRIEF.md`(고정 id·데이터 형식·삽화 화풍) 작성
2. 기획팀: 연표 작성 + 날짜 교차 검증(`docs/plan/timeline_검증.md`), 사료 새 번역(프랑스어 원문 → 직접 번역), 배경·정리 문구, 위키미디어 퍼블릭 도메인 그림 수집, 화면 기획서(`docs/PLAN.md`), 삽화 의뢰서
3. 디자인팀(‖ 삽화팀 동시): 토큰·레이아웃·화면별 시안(`docs/design/mock-*.html`) → `DESIGN.md`·`tokens.css`·`base.css`
4. 삽화팀: 캔바 AI로 삽화 → 캔바 디자인 「프랑스혁명 수업 삽화」(DAHYDWpTT9Q)에 쪽마다 붙여 PNG로 내보내기
5. 개발팀: 팀장이 뼈대·계약 → 팀원 5명이 화면별 병렬 구현 → 팀장 통합·체크리스트(`docs/CHECKLIST.md`)

### 배운 점 (다음에 그대로 적용)
- **개발팀은 디자인만 끝나면 바로 시작**한다. 삽화는 자리표시(「삽화 준비 중」)로 두고 도착하는 대로 반영.
- **캔바 generate-image는 한 번에 한 장씩.** 동시에 여러 장 요청하면 계정 전체가 `quota_cooldown` 에 걸린다.
- 캔바 결과는 200px 미리보기만 바로 받을 수 있다. 원본 크기는 디자인에 `add_page`(원본 크기) → `insert_fill` → commit → `export-design(png)` 으로 받는다.
- 세트 그림(아이콘 3장 등)은 첫 장 MEDIA ID를 `imageReferences` 로 넘기면 화풍이 맞는다.
- 캔바가 막히면 기다리지 말고 직접 SVG로 그려 같은 파일명으로 넣는다(제3신분 아이콘이 그 예 — 원본 `docs/illust-source/estate-third.svg`).
