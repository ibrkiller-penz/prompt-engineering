# u2 레슨 검토 (읽기 전용 검토, 수정 안 함)

| 레슨id | 위치 | 문제 | 제안 |
|---|---|---|---|
| u2_2_4 | 4계단 · 발전 과정 목록 (Transformer → GPT-1 → BERT(2019) → GPT-3) | BERT 논문은 2018년 공개(학회 발표는 2019년). 같은 목록의 GPT-1(2018)보다 뒤로 읽혀 오해 소지 | `BERT(2018)`로 고치거나 '(교과서 표기 2019, 논문 공개는 2018)' 주석 |
| u2_2_1 | 6계단 · 학습 결과 설명(에포크 10번째 0.9909) 과 비교표(딥러닝 훈련 정확도 0.992) | 같은 모델의 마지막 훈련 정확도가 0.9909와 0.992로 달라 보임(검증 정확도와 혼동 가능) | 0.9909를 '약 0.991'로 쓰고 표와 맞추거나, 표의 값이 evaluate 결과라 약간 다를 수 있다는 한 줄 추가 |
| u2_1_5 | 5계단 · 회귀 실습 '결과는 R² = 1.0' | 붓꽃 꽃받침 길이를 선형 회귀로 예측하는데 R²가 정확히 1.0은 매우 이례적(보통 0.8대). 교과서 그대로인지 확인 필요 | 실행 결과 재확인 후 '약 0.9x'로 정정하거나 '교과서 결과 값' 표시 |
| u2_2_2 | 4계단 · 텍스트 투 이미지 서비스 목록(달리2, Bing 이미지 크리에이터) | 서비스 구성이 빠르게 바뀌어 낡을 수 있는 정보 | '교과서 집필 당시 예시이며 서비스는 바뀔 수 있어요' 문구 추가 |
| u2_2_4 | 4계단 · 형태소 분석 예시 (The / small / dog …) | 영어 단어 띄어쓰기 나누기 예이며 '형태소' 분석(한국어는 조사·어미 분리)과 결이 다름 | 한국어 예('먹었다' → 먹/었/다)를 곁들이거나 '단어 단위로 나눈 예'라고 표시 |
| u2_A | 5계단 · 단원 정리 문제 번호 | '선 긋기'가 10~13번인데 O,X(1~3), 단어 고르기(4~6), 빈칸(7~9)보다 먼저 나와 번호 순서가 뒤바뀜 | 선 긋기를 맨 뒤로 옮기거나 번호를 1~4로 다시 매김 |

핵심 3줄
1. 사실 오류로 볼 만한 곳은 BERT 연도(2018 vs 2019) 하나이고, 나머지는 수치 표기 불일치(0.9909/0.992, R² 1.0)와 번호 순서 정도예요.
2. 계산(소프트맥스, MSE, 파라미터 수, 울타리값, 정밀도·재현율·F1, 합성곱 연산)은 모두 직접 검산해 맞았어요.
3. 서비스·사이트 예시(달리2, Bing, 뤼튼 등)는 시간이 지나면 낡을 수 있으니 안내 문구를 권해요.
