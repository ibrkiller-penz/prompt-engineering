# 화면 위치 흔들림 수정 · 학생용 담당(S)

- 범위: aimath-next, aibasic-next 의 `src/student/**`(같은 수정을 두 프로젝트에 적용). 공용 `src/styles/*`·`src/shared/ui/*` 는 건드리지 않았고, 모든 CSS 는 `html[data-site="student"]` 범위(`student.css` 맨 아래 '위치 고정' 블록)에 넣어서 교사 화면에는 영향이 없어요. `src/teacher` 는 손대지 않았어요.
- 바꾼 파일(두 프로젝트 같음): `src/student/shell/Shell.tsx`(TopBar·ActionBar·PageHead), `src/student/pages/Unit.tsx`, `src/student/styles/student.css`.
- 측정: Playwright(chromium, 세로 스크롤바 보이게), `vite build --mode student` 결과(dist-s)를 정적 서버 7200(수학)·7201(기초)로 서빙. 카드 넘기기 전 구간은 수학 79단계(이야기→먼저 알고 가요→개념1~6→정리→문제→레슨 개요, 지금 콘텐츠 기준)·기초 51단계를 `다음`으로 끝까지 넘기며 매 단계 재었어요. 단계 수는 보고서의 137·81과 달라요(그때는 카드 수가 달랐던 것으로 보이고, 같은 경로·같은 단추로 지금 전 구간을 쟀어요).
- 검증 스크립트: `npx tsc --noEmit -p .`, `node scripts/check-css.mjs`, `node scripts/check-es.mjs` 두 프로젝트 모두 통과. `npm run verify` 는 안 돌렸어요.
