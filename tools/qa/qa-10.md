## 이상 없음 (한 줄)

- 밝기(밝게·어둡게·칠판) 변경: 4개 빌드 × 5개 화면 × 글자 0~3 전부에서 요소 위치·크기 차이 0. 밝기 변경으로 배치가 바뀌지 않음.
- 헤더 높이는 글자 크기와 무관하게 고정: 학생 48px(375·320), 교사 오늘 수업 141px(1280), 칠판 무대 48px(1280) · 72px(1920). 라우트끼리도 같음.
- 글자 크기 변경은 본문만 밀림(예: 교사 오늘 수업 제목 y 359 → 427 → 480, 글자 1→2→3). 상단 바·탭·반 칩·화면 설정 단추 위치는 그대로.
- 가로 스크롤(document scrollWidth > clientWidth) 없음, 텍스트 상자 밖으로 넘친 글자 없음 (측정한 전 상태).
- 실제 설정 UI 경로: 학생 `#/me`에서 크게·어둡게 → 홈 이동 → 새로고침, 교사 화면 설정에서 글자 크게·칠판 → 화면 이동 → 새로고침 모두 값 유지, 헤더·제목 위치 동일.
- 단계 넘기기: 학생 레슨 카드 '다음' 2회 후 상단 바·행동 띠·이전/다음 단추 위치 그대로.

## 미확인

- 줄 간격(lh) 옵션, 대비 높이기, 움직임 줄이기 옵션은 측정하지 않음.
- 학생 레슨 카드·문제의 다음 장·정답 공개 이후 모든 단계는 일부만 확인. 칠판의 장면 이동 후 위치는 측정하지 않음.
- 교사 '차시 찾기', '출력', '진도', '결과' 화면은 대상 밖이라 측정하지 않음.
- 실기기 터치, 모바일 키보드가 올라온 상태, 320px보다 좁은 폭은 미확인.
- 칠판 장면 제목 칸(위 표 5번)이 의도된 숨김인지 여부 미확인.
