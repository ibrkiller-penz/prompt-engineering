## 이상 없는 항목 (측정 전 라우트 공통)
- 상단 바 높이·y, 하단 탭 y·높이, 행동 띠 y·높이, 진행 레일 높이·y: 모든 라우트에서 같은 폭 기준 최빈값과 1px 이내. 어긋남 0건.
- 가로 스크롤: 14,872건 전부 scrollWidth ≤ clientWidth. 0건.
- 요소 겹침(형제·바끼리): 0건. (자동 점검에서 잡힌 "겹침"은 부모-자식 쌍, 즉 `.s-loc`과 그 안 칩, `.grow`과 `.s-pos` 쌍으로 오탐이라 제외)
- 화면 밖 요소: 실제 화면 요소 0건. 측정에 잡힌 것은 MathML 숨김 복사본(`.katex-mathml`, clip 처리)이라 제외.
- 맨 아래 스크롤 시 본문이 바에 가려짐: 0건 (/, /u/1, /l/u1-1, 카드, 퀴즈, 오답노트, 내 기록 직접 확인).
- 하단 탭 글 줄바꿈: 없음. 탭 라벨은 숫자 칩 아래 한 줄. "2줄" 신호는 숫자칩과 글자를 함께 센 오탐.
- 단계 넘기기: 막힘 0건, 페이지 오류 0건. 정답 확인·공개 단추 뒤 위치도 같음.

## 미확인
- 글자 크기 설정을 키웠을 때의 줄바꿈·겹침 (data-fs 변경 안 함).
- 가로 방향과 낮은 화면 높이 (max-height 480px 규칙).
- 본문 안쪽 상자(수식·표)가 자체적으로 잘리는지: 바·칩·단추 밖 본문은 자동 점검 범위 밖.
- 실제 터치 스와이프 카드 넘기기와 정답 입력 뒤 자동 진행 (버튼 클릭 기준으로만 걸음).
- 교사 빌드(dist-t)는 이번 범위 밖.
