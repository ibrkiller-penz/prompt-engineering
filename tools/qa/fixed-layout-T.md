# 고친 위치 흔들림: 교사용 (담당 T)

수정 범위는 두 프로젝트(aimath-next, aibasic-next)의 `src/teacher/**` 만이에요. 공용 CSS와 `src/student` 는 건드리지 않았어요.
측정은 Playwright, 세로 스크롤바 15px 보임. 두 프로젝트 모두 같은 값이었어요. 아래는 수학 기준이고 기초도 같아요.
`npx tsc --noEmit -p .`, `check-css`, `check-es` 는 두 프로젝트 모두 통과했어요. `npm run verify` 는 돌리지 않았어요.

## 못 고친 것·남은 것

| 항목 | 이유 |
|---|---|
| 오늘 수업(#/) 제목 위치 (y 410, x 같음 104.5) | 표지형 머리라 다른 화면과 y 가 다른 것은 의도된 구조로 보고 그대로 둠. 폭·좌우 여백은 같아졌어요 |
| 인쇄 화면(#/print) 제목·폭 | 종이 미리보기 구조(전체 폭)라 범위 밖으로 둠 |
| 1500 → 1501 에서 머리가 두 줄(141) ↔ 한 줄(73)로 바뀜 | 주문한 규칙(1501 이상 한 줄)이에요. 같은 폭 구간 안에서는 라우트·반 개수와 상관없이 고정 |
| 폭 구간 경계(1100/900)에서 탭 글자·간격이 한 단계 바뀜 | 탭 4개를 윗줄에 담으려고 폭에 따라 줄인 것이라 줄 수·높이는 그대로 |
| 1024×768 칠판 위쪽 192px 빈 띠 | 4:3 화면에서 16:9 무대를 꽉 채울 수 없어서 생김. 바닥 정렬로 아래 도구띠가 붙고 위쪽이 빔 |
| 칠판 문제 보기 가리기/힌트 열기 등 단계별 펼침 변화 | 지시대로 의도된 동작으로 두고 건드리지 않음 |
| 수업 끝 단추 라벨/설명 글자 위치 | 설명이 17px 두 줄이라 다른 장면(한 줄, 같은 위쪽 시작)보다 설명 글자 아래쪽이 좀 더 내려와요. 단추 크기·라벨 위치는 같음 |
| 칩 줄 스크롤바 숨김 | 마우스로는 칩 줄을 밀기 불편할 수 있음(터치·트랙패드·Shift+휠은 됨). 반 7개 이상일 때 해당 |
