## 이상 없음 (한 줄씩)

- 두 빌드 · 1920·1600·1440 · 모든 라우트: 상단 바 높이·탭 4개·반 칩·화면 설정 단추의 좌표가 같음 (1920: tabs x=323, klass x=1567 y=7, gear x=1738 y=12. 1600: klass x=1247. 1440은 위 줄바꿈 항목 참조). 두 빌드의 헤더 좌표도 같음.
- 두 빌드 · 전 라우트: 요소끼리 겹침 없음 (ov=[]), 가로 스크롤 없음 (scrollX=0, 뷰포트 밖 요소 0개). 하단 탭바는 세 폭 모두 숨김 (데스크톱 보기).
- aimath · flow, 2차시 전환: 헤더 불변. 본문 높이만 5117 → 6021 (1920). 1440은 5437 → 6691.
- aibasic · flow, 2차시 전환: 헤더 불변 (1920: 본문 3463 → 3624, 1440: 3880 → 3862).
- 두 빌드 · flow, 50분 단추와 장면 켜기·끄기 스위치: 헤더·제목 위치 불변.
- 두 빌드 · pick, 문제 갈래 칩 전환: 헤더 불변. 본문 높이만 줄어듦 (9273 → 1316 등).
- 두 빌드 · pick, 칠판 바구니 담기: 헤더 불변.
- 두 빌드 · print, '끝 확인' 탭·'정답지로 보기': 헤더 불변. 종이 높이만 바뀜 (aibasic 1920: 2315 → 1290 / 1987).

## 미확인

- '다음' 단추, 정답 확인, 공개 동작: 칠판 무대(#/board)는 이 브리프의 라우트 목록 밖이라 미확인. 준비 화면에는 다음 단추가 없음.
- 행동 띠·진행 표시·하단 탭바의 실제 위치: 데스크톱 폭 셋에서는 탭바가 숨겨져 있고 행동 띠·진행 표시는 이 화면에 없음. 휴대폰 폭은 범위 밖.
- pick 화면의 '2차시' 단추: 이 화면에 차시 전환 단추가 없어서 클릭 검사 실패 (시도 2회). 2차시 칩 '이 차시 소제목만'은 미클릭.
- 반 칩이 여럿 있을 때의 줄 수: 새 프로필이라 반이 하나도 없는 상태만 측정. 반 여러 개 상태는 미확인.
- dist-s(학생용) 두 빌드: 이번 검수 범위 밖.
- 두 빌드의 1600 폭 전 라우트 스크린샷: 측정값만 있고 눈으로 본 것은 1920·1440 위주.

## 요약

이상점 7개: 점프 5건 (가로 점프 1건 · 세로 점프 2건 · 인쇄·오늘 수업 제목 위치 차이 2건), 줄바꿈 1건, 미세 1건.
가장 심한 3개:
1. 가로 점프 240px (1920), 80px (1440): 차시 찾기·준비 한 장·반별 진도·손들기 결과 ↔ 수업 흐름·문제 고르기 사이에서 제목과 본문이 왼쪽으로 튐. 원인은 flow.css:2, pick.css:2 의 `max-width:1760px`.
2. 세로 점프 49px: 반별 진도·손들기 결과(머리글 없음, 제목 y=93) ↔ 차시 찾기(y=133)·수업 흐름(y=142). 같은 화면 틀인데 머리글 유무 때문에 제목 위치가 달라짐.
3. 세로 점프 15px: 수업 흐름(y=142) ↔ 문제 고르기(y=127). 머리글 글자 크기와 아래 여백이 두 화면에서 다름 (flow.css:4 / pick.css:4-5).

헤더 자체는 두 빌드·세 폭 모두에서 라우트 사이 흔들림이 없음. 1440에서 헤더가 두 줄로 바뀌는 것은 모든 라우트에서 동일하게 적용됨 (줄바꿈 항목).
