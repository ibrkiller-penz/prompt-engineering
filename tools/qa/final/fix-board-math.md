# aimath-next 교사용 칠판 고침 (SN3 고침 권장 항목)

## 전수 검사 스크립트
`node scripts/check-board-fit.mjs [--lessons=u1-1,u3-1] [--fs=0..3]` (단독 실행, verify 에는 넣지 않음). 먼저 `npx vite build --mode teacher` 가 필요하다. 레일에서 문제 장면만 골라 열고 '다음'으로 끝 단계까지 눌러 가며 `.bdq` 안에서 `scrollHeight>clientHeight` 인 스크롤 영역, 무대(0~1080×0~1920) 밖 요소, 카드 글자 28px 미만(글자 작게 단계 제외)을 잰다. 위반이 있으면 종료 코드 1. 포트 기본 7801.
