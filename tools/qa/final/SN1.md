## 확인한 범위
- 홈, 단원 1, 레슨 u1-1(이야기 11장, 먼저 알고 가요 6장, 개념 6개 소제목 전체 카드, 정리 3장)을 다음 단추로 끝까지 넘겼다. 가로 넘침은 없다(scrollWidth 375). 콘솔 오류, 페이지 오류, 요청 실패, HTTP 4xx 는 모두 0건이다.
- 계단 문제 9문제의 숫자 답, 고르기, OX 를 풀었다. 오답(적은 답 표시와 오답 해설), 힌트 1과 2, 풀이 확인하기, 같은 문제를 이어서 다시 확인해 정답 처리, 결과 화면을 확인했다. 풀이를 먼저 본 뒤 맞힌 문제는 '풀어 봄'으로 처리된다.
- 새로고침 뒤 localStorage(aimn:s1:q, last, read, seen)와 홈의 '이어서 하기'(문제 위치), 홈의 맞힌 문제 수, 단원 화면 진행 1%와 기본 문제 2/36, 내 기록의 맞힌 문제 수가 유지됐다.
- 틀린 문제는 오답노트 '아직'과 '복습 중' 탭에 들어간다. 복습 기한을 과거로 바꾼 뒤 #/review 를 풀면 '오늘 복습 끝!'이 나오고 다음 간격(3일)으로 저장된다.
- 사전 첫 화면(304개 용어, 120개만 표시 안내), 내 기록(설정·기록 파일·기록 지우기 단추 표시)은 화면 내용만 확인했다.

## 확인하지 못한 것
- 레슨 '완료' 표시와 홈·단원·내 기록의 완료 수, 단원 마무리 도전의 별 배지. 위 배포 막음 문제 때문에 u1-1 은 완료 조건에 닿지 못했고 더 풀기까지 다 풀어 보지는 않았다. 이 부분은 미확인.
- 사전 검색(초성 검색), 기록 파일 저장과 불러오기, 기록 지우기 동작, 읽기 설정(글자 크기·어두운 화면)이 새로고침 뒤 유지되는지.
- 오답노트 '다시 풀기' 인라인 동작, 졸업 탭, 체험 카드 위젯 조작(건너뛸게요 등).
- u1-1 이외 레슨의 카드 흐름. 확인 카드가 1장인 점만 u1-2 와 u2-1 의 개념 1에서 확인했다. 단원 2~5 화면과 응답 카드(#/card)도 보지 않았다.
- 실제 휴대폰과 Chrome 80 실기. Playwright 크로미움 375x812 로만 봤다.
