## 확인한 범위
- 빌드: 수학 학생(9501)·교사(9502), 기초 학생(9503)·교사(9504), 허브(9505). 학생은 375×812(터치), 교사·허브는 1920×1080 (허브는 375 도).
- 학생 화면: 홈, 단원, 레슨, 카드(이야기·개념), 퀴즈, 오답노트, 복습, 사전, 내 기록, 응답 카드, 개인정보 — 두 빌드 모두 Tab 순회(25회), 포커스 표시, 이름 없는 조작, 44px 미만 대상 점검. 포커스가 안 보이거나 화면 밖으로 나가는 곳 0건. 이름 없는 실제 조작 0건(측정 도구가 낸 거짓 양성은 직접 확인해 제외).
- 교사 화면: 오늘, 차시 찾기, 진도, 손들기 결과, 준비, 흐름, 문제 고르기, 인쇄, 개인정보 — 수학 빌드. 포커스 표시 모두 있음. 문제 고르기의 문제 미리보기 버튼은 높이 34px(교사 PC 화면이라 허용 범위).
- 칠판: 수학·기초 `#/board/<lid>?p=1&s=0` 에서 → 8번, Space, ←, Tab 20회, Esc. 키가 장면을 넘기고 포커스 테두리 5~6px 로 뚜렷함. 페이지 오류 0건, 가로·세로 스크롤 없음(1920×1080 딱 맞음). 하단 키 안내(← → Home End)는 aria-hidden 이라 읽어 주지는 않으나 동작은 정상.
- 색 대비: 자동 계산(WCAG 4.5/3:1) 으로 위 화면 14곳 점검, 부족한 글자 0건.
- 브랜드 표식 이미지(상단 아이콘): 학생·교사·칠판 모두 `alt=""` + `aria-hidden` 으로 장식 처리, 바로 옆에 사이트 이름 텍스트가 있어 적절함(문제 없음). 허브에는 이미지 없음.
- 움직임 줄이기: 두 빌드 motion.css 에 `prefers-reduced-motion` 규칙이 있고, 내 기록에 '움직임 줄이기' 설정이 있음(소스 확인만).

## 확인하지 못한 것
- Chrome 80 실기기: `:focus-visible` 대신 `html.kbd :focus` 규칙을 쓰는 것을 소스로 확인했고, 최신 Chromium 에서는 동작을 봤다. Chrome 80 에서의 실제 표시는 미확인.
- 기초 교사용의 칠판 외 화면, 기초 학생 퀴즈의 모든 문제 유형(OX·숫자패드·서술형)의 키보드 조작은 일부만 확인. 수학·기초 칠판의 모든 장면(체험 도구·판서·타이머·가림막·확대) 별 키보드 동작은 미확인.
- 움직임 줄이기가 실제로 애니메이션을 멈추는지 화면으로는 미확인.
- 화면 읽기 프로그램 실제 음성 출력은 미확인(이름 속성만 점검).
- 색 대비는 텍스트만 점검, 이미지·그림 속 글자와 비활성 상태 버튼은 미확인.
