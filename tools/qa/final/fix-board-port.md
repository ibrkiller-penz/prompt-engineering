# fix-board-port: 수학 칠판 고침을 기초 칠판에 이식 + 도구띠 단추 폭 고정 (두 프로젝트)

범위: `aibasic-next/src/teacher/board/{tools.tsx,Stage.tsx,scenes.tsx,board.css}`, `aibasic-next/src/teacher/styles/{board,frev-board}.css`, `aimath-next/src/teacher/board/tools.tsx`, `aimath-next/src/teacher/styles/frev-board.css`. 학생용·flow·shell·print 소스·aimath 의 그 밖의 칠판 파일은 손대지 않음. 기초에만 있는 지문 문제 2열(`.bdq-cols`)·코드 블록 규칙은 그대로(겹치는 규칙 없음). git 은 읽기 전용 diff 만 썼다.
재현은 최신 Chromium 1920x1080(playwright)이고, 기초 "전" 수치는 이식 전 빌드로 잰 값이다.

## 고친 것 (전 → 후)

### (1) 수학 고침의 기초 이식 (먼저 재현해서 있는 것만)

| 항목 | 재현 | 전 | 후 | 방법 |
|---|---|---|---|---|
| 판서 켠 채 접힘 카드 위에 긋기 | 있음. `#/board/u1_1_1?p=1&s=12`(접힘 카드 2개) 판서 켜고 카드 위 드래그 | 닫힌 카드 2→1(카드가 열림), 되돌리기 비활성(선 없음) | 닫힌 카드 2→2, 되돌리기 활성(선이 그려짐) | `board/board.css` 끝에 `.bd-stage.is-inking` 동안 `.bd-open` pointer-events:none, 띠·`.bd-all` z-index 해제(수학과 같은 규칙) |
| 판서 켠 도구띠 '나가기'·'판서 끄기' 겹침 | 있음. 판서 클릭 | 나가기 60px, 판서 끄기 66px(x 130), 펜 묶음 1087px + 되돌리기 160 + 모두 지우기 190 이 띠를 넘쳐 flex 축소 | 나가기 149px, 판서 끄기 179px(x 219, 안 옮겨짐), 되돌리기·모두 지우기 그림 단추 64px, 펜 묶음 끝 1275px < 이전 단추 1308px(겹침 0), 글자 잘림 0 | `tools.tsx` 되돌리기·모두 지우기에 `is-act`, `frev-board.css` 에 수학과 같은 도구띠 규칙(왼쪽 도구 `flex:0 0 auto`, 그림 단추 64px) |
| '먼저 알고 가요' 쪽 나눔에서 걸쳐 반만 보이는 카드 | 기본 글자(레슨 26×1·2차시, 4168 단계 전수)에서는 **0건**(기초는 기본 글자에서 쪽 나눔 자체가 안 생김). 글자 크게 1단계(`fs=2`)부터 있음: u3_2_1 1차시 3번 장면에서 ④ 카드가 도구띠 위에 걸려 보이고 '이어서 1/2쪽' 표시를 가림 | ④ 카드(윗부분 807~911px)가 쪽 이름 위에 겹쳐 보임 | 걸린 카드는 가려지고 '이어서 ▾ 1/2쪽'이 온전히 보임(사진 비교 확인) | `scenes.tsx` SceneBody 에 `clipBottom`+`.bd-scene-clip`(clip-path) 수학과 같은 방식, `board.css` 에 `.bd-scene-clip` |
| '더 보기' 팝업이 장면 이동 시 닫힘 | 코드상 있음(닫는 때는 판서 켤 때뿐). 고친 뒤 확인 | 장면 주소 이동 후에도 열림 | 열고 `s=5` 이동 → 닫힘 | `BoardToolbar` 에 `sceneKey` prop+effect, `Stage.tsx` 가 `inkKey` 를 넘김 |
| 칠판 문제 인쇄물 | 있음. 기초는 문제 6~8개+지문이라 원래 2~3쪽이 정상이지만 QR 안내만 마지막 쪽에 외톨이로 남는 경우가 다수 | 26레슨×2차시 52개 중 3쪽짜리 18개, QR 만 있는 마지막 쪽 8개(u1_1_1/p1, u1_2_2/p1·p2, u2_1_2/p1, u2_2_4/p1·p2, u3_2_3/p2, u4_3/p1) | 3쪽짜리 1개, QR 외톨이 1개(u3_1_2/p2) | `styles/board.css` 끝 `@media print`: 머리·핵심 질문·문제·보기·QR 간격만 줄임, 문제 줄간격 1.4, QR 25→17mm. 흑백·A4·글자 크기 규칙 유지. `pdftotext` 로 쪽별 낱말 수 확인 |

### (2) 이름이 바뀌는 도구 단추 폭 고정 (수학·기초 공통, H5 지적)

| 항목 | 전 | 후 | 방법 |
|---|---|---|---|
| 확대 켜기('확대 끄기') | 확대 x721 w126 → w179, '더 보기' x802 → x855(53px 밀림) | 확대 w179 일정(켜고 꺼도 같음), '더 보기' x908 일정 | `BarTool` 에 `alts`: 가능한 이름을 같은 칸에 겹쳐(안 보이는 쪽 투명) 폭을 가장 긴 이름 기준으로 맞춤. `frev-board.css` `.bd-tool-swap` |
| 판서 켜기('판서 끄기') | 판서 w126 → 66(눌림) / 수학 179 | 판서 x219 w179 일정(켜도 안 옮겨짐) | 같은 방식 |
| 타이머('타이머' ↔ '4:59' 숫자) | 폭이 글자 따라 변함 | w149 일정(켬·초 흐름 중 동일) | 같은 방식(숫자 쪽은 '00:00' 기준) |
| 가림막 | 이름 고정이라 폭 일정 | w149 일정(변화 없음, 점검만) | 변경 없음 |

두 프로젝트 모두 1920x1080, 장면 3번: 나가기 x24 w149 · 판서 x219 w179 · 타이머 x406 w149 · 가림막 x563 w149 · 확대 x721 w179 · 더 보기 x908 w156 이고, 확대 켜기(클릭 확대까지)·끄기, 가림막, 타이머 실행 중, 판서 켜기·끄기 사이에 값이 같다. (기본 상태 폭이 조금 넓어져 '더 보기'가 802→908 로 옮겨 있지만 켜고 꺼도 안 움직인다.)

### (3) check-css

`cd aibasic-next && node scripts/check-css.mjs` 는 이 작업을 시작했을 때 이미 통과였다(`styles/board.css`·`board/board.css` 에 `column-gap`/flex `gap` 없음, 다른 에이전트가 먼저 고친 것으로 보임). 내가 넣은 규칙에도 `gap` 은 없고(두 프로젝트 모두 통과), 따라서 바꾼 배치 없음.

## 검증
- 두 프로젝트: `npx vite build --mode teacher` 통과, `npx tsc --noEmit -p .` 통과, `check-css` 통과, `check-es` 통과, `node --test tests/teacher/*.test.ts` 65개 통과.
- `node scripts/check-board-fit.mjs`: aimath(기본 글자, 레슨 20·문제 장면 284·공개 1514단계) 위반 0, aibasic(레슨 26·차시 47·문제 장면 355·공개 2040단계) 위반 0건.
- `node scripts/shots.mjs --only=t --all-scenes --no-save`: aibasic 장면 1154개·3745단계, aimath 장면 1437개·5420단계, 콘솔 오류·가로 넘침 0, 모든 장면 896px 이내.
- `npm run verify` 는 돌리지 않음.

## 못 고친 것
| 항목 | 이유 |
|---|---|
| 기초 `u3_1_2` 2차시 칠판 문제 인쇄물의 마지막 쪽에 QR 안내만 남음(52개 중 1개) | 문제 8개가 2쪽에 꽉 차서 QR 이 약 10mm 모자란다. 간격·QR 을 더 줄이면 글자나 QR 크기 규칙을 건드려야 해서 멈춤. `break-after:avoid` 로 마지막 문제와 같이 넘기는 시도는 Chromium 에서 안 먹었음(인쇄 마크업은 이번 범위 밖) |
| 기초 인쇄물이 1쪽이 되지는 않음 | 기초는 문제 6~8개+지문·코드라 내용상 2쪽이 정상(수학 5문제와 다름). QR 외톨이만 줄임 |
| 접힘 카드 반만 보이는 증상은 기본 글자에서 재현되지 않았음 | 기초는 기본 글자에서 쪽 나눔이 안 생겨 증상 없음. 글자 크게에서만 있어 그때를 위해 같은 방식으로 이식함. 글자 크게 전 장면 전수 검사는 하지 않고 대표 3개 레슨(u1_1_1, u3_2_1, u2_1_3)으로 재현·확인 |
| 1366x768·Chrome 80 실기기 | 최신 Chromium 1920x1080 만 확인 |
