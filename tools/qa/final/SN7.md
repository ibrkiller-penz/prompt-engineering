## 확인한 범위
- 학생용(dist-s, 375×812, 포트 9701): 단원 1~5 소개 화면, 홈·사전·오답노트·복습·내 기록·개인정보·응답 카드, 레슨 20개 전체 — 레슨 화면 + 카드 넘기기 끝까지(레슨당 약 68~100장, 총 약 1700장) + 이어서 나오는 연습 문제 화면 + 'q'·'q/more' 화면.
- 교사용(dist-t, 1920×1080, 포트 9702): 오늘·차시 찾기·반별 진도·손들기 결과·개인정보, 단원 평가 5개, 레슨 20개의 흐름·문제 고르기·준비·인쇄(칠판/퇴장/숙제) 화면, 칠판은 레슨마다 → 키로 모든 공개 단계·장면을 끝까지(레슨당 90~170 상태).
- 각 화면에서 검사한 것: `**`, `$`, `[object`, undefined, NaN, null, 준비 중, TODO, 날것 LaTeX 명령, HTML 엔티티, 마크다운 제목·백틱, KaTeX 오류 요소, 깨진 이미지, 페이지 가로 넘침, 표가 화면 밖으로 나감, 본문 비어 있음, 짧은 카드(40자 미만). 콘솔 오류·페이지 오류 0건.
- 원본 content/aimath 전체: 짝 안 맞는 `$`·`**`, 빈 문자열, undefined/NaN 0건. 단원 소개글(why·opening·stories 4개·future)은 5개 단원 모두 비어 있지 않음.
- 수식: 카드에서 KaTeX 로 그려짐 확인(예: u4-2 개념2 카드 8곳, 단원 1 화면 7곳). 날것 `$` 는 어느 화면에도 남지 않음.

## 확인하지 못한 것
- 실제 휴대폰/전자칠판(Chrome 80) 에서의 모양. 최신 Chromium 으로만 봄.
- 화면을 눈으로 본 것은 5장뿐(나머지는 글자·치수 자동 검사). 그림(SVG) 내용이 맞는지, 위젯(체험 도구)이 실제로 작동하는지는 안 봄(글 기준으로 '준비 중' 문구만 확인, 레슨 화면에선 0건).
- 칠판 u1-4 먼저 알고 가요 장면의 높이 초과가 실제로 잘리는지.
- 문제 풀이·정답 확인 흐름, 교사용 인쇄 미리보기의 실제 종이 배치, 허브·인공지능 기초 빌드(내 담당 아님).
- 해요체/해라체 혼용은 원본 일부만 문장 규칙으로 훑음 → 전수 아님.
