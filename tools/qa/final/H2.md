## 확인하지 못한 것 / 참고

- 칠판 질문 화면 `#/board/<lid>/q/<qid>`, 도구 화면 `#/board/<lid>/tool/<wid>`, 끝 화면 `#/board/<lid>/end` 는 측정하지 않음 (미확인). 준비 화면 목록에 없어서 제외.
- 칠판 무대의 '정답 확인'·'공개' 단추는 칠판 장면 넘기기로만 확인했다(4단계). 질문 장면의 공개 단추 전후는 미확인.
- 기초 빌드 1067×768 칠판 첫 측정 한 번은 로딩 대기 시간 부족으로 빈 값이 나왔다. 대기 시간을 늘려 다시 재어 같은 위치(바 y 706, 높이 62)를 확인했다. 측정 방법 문제이며 화면 문제 아님.
- 화면 설정 시트(모달), 인쇄 화면의 인쇄 미리보기는 측정하지 않음 (미확인). 인쇄 화면 자체의 준비 화면 배치는 측정함.
- 서버: 8201(수학 dist-t), 8202(기초 dist-t) 두 개만 띄웠다. 측정이 끝난 뒤 내가 띄운 PID만 종료한다.
