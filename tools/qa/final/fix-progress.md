# fix-progress — 학생용 진도·완료 계산 (aimath-next, aibasic-next)

## 원인 확인
- 이 작업 트리에서는 카드 덱(deck.logic.ts buildDeck)이 sectionChecks[i] 의 모든 id 를 한 장의 확인 카드(qids)로 만들고, Cards.tsx CheckCard 가 그 id 를 모두 보여 준다. 그래서 SN1 의 '읽음 5/6' 은 재현되지 않았다(수학 u1-1 개념 4 의 확인 카드에 q04·q05 가 함께 나온다). 읽음 계산(status.logic.ts sectionDone)과 카드 덱이 같은 id 목록을 쓰므로 plan 생성 규칙·저장 키·plan.json 은 바꾸지 않았다.
- aibasic-next 도 같은 구조다(26개 레슨 모두 2개짜리 소제목이 있음). 덱·읽음 모두 일치해서 코드 수정은 필요 없었다.
- 회귀 방지로 tests/student/deck.test.ts 를 두 프로젝트에 추가했다(모든 레슨에서 확인 카드 id 목록 = plan.sectionChecks).

## 고친 것
1. 처음 푼 계단 문제 결과 화면의 '지난번보다 N문제 더 맞혔어요' (Quiz.tsx, 두 프로젝트): 세트를 열 때 풀어 본 문제(tried)가 0개면 문장을 숨긴다. 전: 첫 시도 1문제 맞히면 '지난번보다 1문제…' 표시 → 후: 표시 안 함(이전 기록이 있고 더 맞히면 '지난번보다 1문제 더 맞혔어요' 계속 표시, 확인함).
2. 레슨 화면 로딩 중 '이야기가 없는 레슨이에요' (Lesson.tsx, 두 프로젝트): 레슨 조각이 오기 전(steps 없음)에는 '불러오는 중이에요…' 로 표시. 청크 요청을 700ms 지연시켜 30회 표본·MutationObserver 로 확인: 전 구간에서 그 문구가 나오지 않음.
3. CSS·Me.tsx 는 건드리지 않았다.
