# SN6: aibasic-next 학생용(dist-s) 화면에 그려지는 글 점검

| 심각도 | 위치 | 증상 | 재현 방법 | 추정 원인 |
|---|---|---|---|---|
| (배포 막음) | 없음 | 해당 사항 없음 | - | - |
| 참고 | dist-s 이야기 카드(`/l/u1_1_1/s/story/N` 등), 375px | 이야기 단계는 "~했다/~이다"(해라체 서술), 개념 카드는 "~해요"(해요체)로 한 레슨 안에서 섞임. 일부 개념 카드 요약 줄과 OX 문제 지문(예: u1_A 문제, u4_2 OX 문항)도 "~이다/~한다". | 아무 레슨의 story 카드와 c1 카드를 비교 | 이야기는 1인칭 소설체 의도로 보임. 문제 지문(문어체)과 해설(해요체) 혼용은 원본 교과서 문장 유지 추정. 미확인(의도 여부) |
| 참고 | 개념 카드 u1_1_2 c3/1 등 | 도식 요약 줄이 "~구현한다"로 끝나 주변 해요체와 다름 | `/#/l/u1_1_2/s/c3/1` | 위와 같음 |

## 확인한 범위
- 빌드: aibasic-next/dist-s, 포트 9601, 뷰포트 375x812, Playwright. 레슨 26개 전부.
- 레슨마다 이야기·선수 지식·개념·정리 카드를 끝까지 넘기며(총 약 1,650 화면) 본문 텍스트 추출 후 검사한 항목은 다음과 같다.
  - `**`, 백틱, `\$`, `&lt;`/`&gt;`/`&amp;`, `[object Object]`, undefined/null: 0건.
  - NaN: 3곳(u2_1_3 c3, u4_1_2 c3). 모두 pandas 결측치를 설명하는 정상 문장이다.
  - 조사 오류('인공지능가' 등): 0건. 정규식 후보는 전부 "A가", "FP가" 같은 정상 표현이었다.
  - 깨진 이미지(naturalWidth 0): 0건.
  - 가로 넘침(scrollWidth > 폭): 0건.
  - 빈 카드(텍스트 40자 미만): 0건.
  - 4xx/5xx 응답, requestfailed, pageerror: 0건.
- 문제 1,198개(choice 918, OX 280) 원본 JSON 전수 검사:
  - 정답 번호가 보기 범위 밖인 문제: 0건. 보기 중복: 0건. 해설 누락: 0건.
  - 해설에 "정답은 N번"이 적힌 경우 정답과 불일치: 0건.
  - OX 해설의 첫머리 "틀/거짓"과 정답 불일치로 걸린 1건(u2_1_5-q10)은 해설 전체를 읽으니 모순이 아니었다.
- 문제 화면(/q, /q/more)과 용어 사전(/dict) 텍스트도 같은 검사를 통과했다.

## 확인하지 못한 것
- 표 칸 어긋남·코드 블록 잘림은 시각 확인 없이 가로 넘침과 텍스트로만 봤다. 표와 코드는 가로 스크롤 영역으로 처리될 수 있어 스크린샷 대조가 필요하다. 미확인.
- 해설 내용이 정답과 의미상 모순인지는 정규식 수준만 봤다. 사람이 읽는 샘플링은 못 했다.
- 문제 화면 크롤은 첫 보기를 눌러 확인까지 진행하는 단순 방식이라, 수치 입력형·정오답 피드백 문구는 별도로 보지 않았다.
- 1920x1080 환경(교사용)과 dist-t는 범위 밖이다.
