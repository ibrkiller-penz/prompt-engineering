근거: H7(위치 글 잘림), SN2(코드 블록·표·오답 문구). 범위: src/student/**, 학생 CSS(`html[data-site="student"]`), src/shared/ui/*. 교사 쪽·verify 는 건드리지 않음.

## 고친 것 (전 → 후)

1. 카드 위치 글(.s-pos) 잘림
   - 전: 수학 u1-1 한 레슨, 글자 크기 1단계, 폭 320·360·375·390 에서 위반 56건(prereq 카드 '먼저 알고 가요 n/7' 말줄임). 칸 폭 320 83px · 360 84px · 375 99px · 390 114px, 글자가 필요한 폭 123px.
   - 후: 두 프로젝트 전수 검사 위반 0 (아래 표).
   - 방법: (a) 폭 ≤420px 에서 '이전' 단추를 아이콘만 남김(48×48, aria-label 유지, title 추가), (b) 위치 글만 '먼저 알기 n/7' 로 짧게(상단 바 제목은 '먼저 알고 가요' 그대로), (c) 폭 ≤339px 에서는 행동 띠 단추 글자를 16px 로 고정하고 다음 단추 폭을 136px 로 고정(글자 크기 2~3단계에서 다음 단추가 152px 로 커져 320px 에서 위치 글 칸이 72px 가 되던 것을 막음). 다음 단추 폭은 폭마다 한 값(320 136 · 360~412 137, 글자 2~3단계는 360 이상 152), 행동 띠 y 667 고정.
   - 알아 둘 것: 기존 `@media (max-width:374px) .s-next{min-width:max(118px,6.6em)}` 는 더 센 규칙(`.s-actionbar .s-next`)에 가려 원래부터 적용되지 않았음(건드리지 않음).
   - 수정 파일: src/student/shell/CardDeck.tsx, src/student/pages/Cards.tsx, src/student/styles/student.css (양쪽 프로젝트).
2. 기초 코드 블록 · 표 코드 칸 (aibasic-next 만)
   - 코드 블록: 줄이 넘칠 때 오른쪽 끝 그림자 + 머리줄에 '옆으로 밀어요 →' 표시(넘칠 때만, 창 크기·글자 크기 변화에도 다시 잼). 안쪽 가로 스크롤이고 figure 에 data-noswipe 가 이미 있어 카드 넘기기와 부딪치지 않음. 예 `#/l/u2_2_1/s/c5/3`: 줄 폭 593 > 339, 표시 나타남(375px 촬영 확인). 칠판(is-board)은 줄바꿈이라 해당 없음.
   - 표 안 코드: `.ui-icode` 를 표 안에서 줄바꿈 금지(`google.colab`·`files.upload()` 가 한 덩어리로 보임). 코드 때문에 설명 칸이 한 글자 폭으로 찌그러지지 않게 코드가 든 표는 설명 칸 최소 9em → 모자라면 표 안쪽 가로 스크롤 + 기존 '옆으로 밀어서 나머지 칸을 봐요 →' 힌트(예 `#/l/u2_1_3/s/c2/3`: 표 418 > 343, 페이지 가로 스크롤 없음). `overflow-wrap:anywhere` 는 쓰지 않음.
   - 수정 파일: src/shared/ui/CodeBlock.tsx, StackTable.tsx, ui.css.
3. 틀렸을 때 안내 문구 (양쪽)

   - 수정 파일: src/shared/ui/QuestionCard.tsx (`wrongTip` 에 4번째 인자 type, 양쪽).

## 전수 증명 (scripts/check-card-fit.mjs, 각 프로젝트에 추가, verify 에는 넣지 않음)
`npx vite build --mode student` 후 `node scripts/check-card-fit.mjs [--port=7951] [--fs=0,1,2,3] [--widths=...] [--lessons=...]`. 모든 레슨의 모든 카드를 '다음' 으로 끝까지 넘기며 폭 320·360·375·390·412 × 글자 크기 0·1·2·3 = 20조합.

| 프로젝트 | 레슨 | 조합 | 총 측정 단계 | .s-pos 및 자식 말줄임 | 글자가 상자·단추 밖 | 행동 띠 y | 다음 단추 x·폭 | 이전 단추 x·폭 | 최소 터치 | 페이지 가로 스크롤 | 위반 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 수학 | 20 | 20 | 29,960 | 0 | 0 | 667 한 값 | 조합마다 한 값 | 16 · 48 | 48px | 없음 | 0 |
| 기초 | 26 | 20 | 18,760 | 0 | 0 | 667 한 값 | 조합마다 한 값 | 16 · 48 | 48px | 없음 | 0 |

(수학 카드는 1회 순회 1,498단계, 기초 938단계. 다음 단추 폭: 320 136 · 360~412 137, 글자 2~3단계의 360 이상 152. 카드가 들어오는 움직임 중의 일시 넘침은 가라앉은 뒤(450ms) 다시 재서 판단.)

그 밖의 검증(양쪽): `npx tsc --noEmit -p .` · check-css · check-es · `node --test tests/student/*.test.ts`(40개) 통과. 빌드 `npx vite build --mode student` 후 위 검사. `npm run verify` 는 돌리지 않음.

## 못 고친 것 · 남은 점
- 퀴즈·복습·더 풀기 화면의 위치 글('3 / 9문제')과 다음 단추 라벨('다음 문제' 등)은 전수 검사에 넣지 않음(요청 범위는 카드). 이들도 같은 이전 단추 규칙을 받아 아이콘만 남지만, 다음 단추 폭이 '다음 문제'일 때 고정인지는 따로 재지 않음.
- 폭 ≤420px 에서 '이전' 단추의 글자가 사라짐(요청대로). 퀴즈·복습의 '이전 문제' 같은 라벨도 아이콘만 보임(aria-label·title 은 유지).
- 글자 크기 2~3단계에서 360px 이상은 다음 단추가 137→152px 로 커지는 것은 그대로(조합 안에서는 한 값이라 위치는 안 흔들림).
- 코드 블록이 아주 긴 줄은 여전히 안쪽에서 밀어야 읽힘(표시만 추가, 줄바꿈은 코드 읽기를 위해 허용하지 않음). 표의 코드 칸이 길면 표가 가로로 길어짐.
- 상단 바 제목 '먼저 알고 가요' 의 360px 말줄임(H7 #3), 실기기·iOS Safari·높이 568 화면은 미확인.
- 오답 문구는 문구만 확인했고 화면(오답 상태)을 사람이 눌러 보지는 않음. 유형이 'open'(서술형)은 보통 자기 점검 흐름이라 오답 문구가 거의 안 나옴.
