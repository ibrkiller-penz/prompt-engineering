## 확인한 범위 (375×812, 터치, Playwright Chromium)
- 홈 → 단원(#/u/1) → 레슨 개요 → 카드 전체(이야기·개념·끝 확인·정리) → 계단 문제 → "더 풀기" 6세트 → 오답노트 → 복습 → 사전(초성·낱말 검색, 없는 검색어) → 내 기록 → 저장 내용 안내 → 응답 카드까지 실제로 눌러 가며 확인했다.
- 학습을 끝까지 해 본 레슨은 Ⅰ-1-1이다. 이야기부터 정리까지 40장을 넘기고, 끝 확인 포함 문제 41개를 풀었다(27개 정답). 레슨이 "완료"로 바뀌고, 개념 5/5·기본 문제 41/41, 단원 1/5 20%, 홈의 레슨 1/26 4%, 다음 레슨 안내까지 맞게 갱신됐다. 완료 조건 문구도 일관된다.
- 저장 유지: 새로고침, 다른 레슨 중간(카드 위치)에서 홈으로 갔다 와도 "이어서 하기" 링크가 마지막 카드로 간다. 오답 개수·맞힌 개수가 유지된다. localStorage 키는 aibn:s1:q·pos·last 만 확인했다.
- 복습: 브라우저의 Date 를 하루 뒤로 돌려 확인했다. 홈에 "오늘의 복습 5문제"가 뜨고, 5문제를 풀면 하루 5문제 상한대로 끝 화면이 나온다. 틀린 문제는 "내일 다시"로 표시되고 오답노트에 다시 본 횟수가 오른다.
- 26개 레슨 전체의 카드 덱을 자동 순회하며 페이지 가로 넘침(scrollWidth>375), 가려진 요소, 깨진 문구(undefined·NaN·{{·태그 조각)를 검사했다. 페이지 가로 넘침 0건, 가려진 요소 0건, 깨진 문구 0건이다. (`NaN`이 잡힌 3곳은 결측치 설명의 정상 본문이다.) 콘솔 오류·경고 0건, 4xx 응답 0건이다.
- 없는 단원(#/u/5)과 없는 레슨 주소는 "찾는 화면이 없어요 · 홈으로 가요"로 정상 안내된다.
- 표는 카드 안에서 폭에 맞게 접혀 보인다(가로 잘림 없음). 코드 블록은 위 고침 권장 건 외에는 문제가 없다.

## 확인하지 못한 것
- Ⅰ-1-1 외의 25개 레슨은 완료까지 직접 풀지 않았다. 카드 덱 순회와 가로 넘침 검사만 했다. 숫자 입력·글쓰기형 문제 화면은 이 레슨에서 나오지 않아 눌러 보지 못했다(미확인). 다른 레슨의 지문·표가 있는 문제 화면은 "더 풀기"로 전수 확인하지 못했다.
- 카드 덱의 오른쪽으로 밀기(이전 카드로 가기)는 한 번 시도해서 이전 카드로 가지 않았다. 설계상 기능이 없는지는 미확인이다. 다음 카드(왼쪽으로 밀기)는 정상이다.
- 홈의 "다음 레슨" 안내가 이어서 하기 레슨 다음 레슨을 가리킨다("이어서 하기: Ⅰ-1-2" / "다음 레슨: Ⅰ-2-1"). 의도된 동작인지는 미확인이다.
- 복습 3일·7일 뒤 간격과 "졸업"(3번 연속 정답)은 시험하지 않았다. 기록 파일 저장·불러오기, 기록 지우기, 읽기 설정(글자 크기·어두운 화면)의 휴대폰 화면은 눌러 보지 않았다.
- 실제 휴대폰·iOS Safari 는 확인하지 못했다. Chromium 에뮬레이션(375×812, 터치)만 사용했다. 소스·빌드는 수정하지 않았다.
