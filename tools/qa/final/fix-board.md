# fix-board: aibasic-next 교사용 칠판 배포 막음 수정 (SN4 후속)

범위: `aibasic-next/src/teacher/board/{Question.tsx,board.css}`, `src/teacher/styles/{board.css,frev-board.css}`, 검사 스크립트 `aibasic-next/scripts/check-board-fit.mjs`(새 파일, verify 에는 안 넣음). aimath-next·flow·shell·today·pick·학생용·허브는 손대지 않음. git 사용 안 함.
"전" 숫자는 SN4 보고서 값(수정 전 빌드를 따로 보관하지 않아 같은 도구로 재지 못함), "후" 숫자는 이번 도구로 잰 값.

## 못 고친 것 · 주의

| 항목 | 내용 |
|---|---|
| 제시문 문제에서 힌트·정답·풀이를 열면 배치가 바뀜 | 제시문(왼쪽)·보기(오른쪽) 2열에서 신문식 2단으로 바뀌어 보기 ④⑤ 가 오른쪽 칸 위로 넘어갈 수 있음. 글자 28px 을 지키며 제시문+보기 5개+정답·힌트 2·풀이를 한 화면에 담는 면적이 모자라(최악 장면 약 1.5배 쪽) 안쪽 스크롤 없이 가려면 이 방식이 필요했음 |
| 제시문 문제의 정답 칸 | "정답: ①" 번호만 보임(보기 글 되풀이 생략). 보기 칸에 ✓ 정답 표시와 초록 테두리는 그대로 |
| 칠판 글자 배율(`--fs-scale`)을 키운 경우 | 검사는 기본 배율(1) 기준. 배율을 키우면 일부 제시문 장면이 다시 넘칠 수 있음 |
| 수업 끝 '지문 앞부분 보기'를 눌러 숙제 목록을 펼친 상태 | 펼치면 오른쪽 칸 안에서 스크롤됨(기본 상태가 아니라 검사 대상 밖) |
| 1366x768, Chrome 80 실기기 | 최신 Chromium 1920x1080 으로만 확인. Chrome 80 에서 안 쓰는 기능만 쓰도록 check-css 로 점검(multicol·`display:flow-root`·`:not()` 은 80 지원) |
| u3_2_1 표 데이터 | 왼쪽 칸 문구가 행마다 반복되는 것은 콘텐츠 문제라 손대지 않음(SN4 참고 항목) |
| 같은 도구로 잰 "전" 숫자 | 수정 전 빌드를 따로 두지 못해 SN4 값을 "전"으로 적음 |
