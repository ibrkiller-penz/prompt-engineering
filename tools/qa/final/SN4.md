## 확인한 범위
- 반 추가(2-3, 2-4, 길이 10자, 입력 중 요소 재생성 후 재입력), 오늘 수업, 차시 찾기(검색·0건), 수업 흐름(u2_1_3), 문제 고르기, 준비 한 장(2개 레슨, 2차시), 수업 마치기 → 반별 진도 '끝' 표시, 손들기 결과(빈 상태), 인쇄(화면 + PDF: 문제·끝 확인·숙제, A4), 저장 내용 안내, 없는 주소·없는 레슨 안내 화면. 1920x1080 과 1366x768 둘 다 가로 넘침 없음, 콘솔 오류·실패한 요청 0건.
- 칠판 수업: 26개 레슨 전부, 차시마다 처음부터 끝(수업 마치기 직전)까지 → 키로 모든 장면·공개 단계. 개념·표·그림·코드·제시문 문제 포함. 각 단계에서 가로 넘침, 안쪽 스크롤, 본문 밖으로 나간 요소, 코드·표 글자 크기(28px 기준) 측정. 두 폭의 결과 종류와 개수는 같음(칠판이 1920x1080 을 비율로 줄임; 1366 에서 글자는 화면상 0.71배).
- 표 글자는 28px 를 지킴(TH/TD 위반 0). 위반은 위 코드 두 종류뿐.

## 확인하지 못한 것
- 칠판 체험 도구(`/board/:lid/tool/:wid`) 개별 동작, 문제 크게 보기 화면의 모든 문제, 판서(펜)·확대·가림막·타이머·전체화면 동작.
- 학생 휴대폰 화면은 담당 밖. 전자칠판 Chrome 80 실기기 동작은 미확인(Chromium 최신으로만 시험).
- 손들기 결과에 숫자가 쌓인 상태, 반 삭제, 70분·50분 시간 선택의 장면 구성. 인쇄는 Chromium PDF 로만 확인.
- 이 목록의 '풀이 칸 잘림' 개수는 걸러 센 값이라 정확한 총합은 미확인. 수업 끝 장면 `.bd-end-period` 넘침은 눈으로 보지 못함(수치만).
