## 확인한 범위
- 로컬 서빙(포트 10001, aiworld 폴더 루트) 후 Playwright(chromium)로 폭 320·375·768·1280·1920 확인.
  - 카드 10개 모두 렌더링. 열 수는 320~768 에서 1열, 1280·1920 에서 2열.
  - 가로 스크롤 없음(documentElement.scrollWidth == clientWidth, 카드 오른쪽 끝이 폭 안쪽).
  - 카드 안 요소의 글자 잘림 없음(scrollWidth 초과 요소 0).
  - 최소 글자 크기 13.6px.
  - 위치 안정: 로드 직후와 폰트 로딩 + 0.8초 뒤의 카드 위치·크기가 5개 폭 모두 동일.
  - 폰트 400·700 로드됨(500 은 쓰는 곳 없어 미로드). 404·요청 실패 0건. 파비콘 3종과 폰트가 모두 로컬에서 200.
- 카드 링크 10개의 href 를 읽고 라이브 curl 로 확인. 모두 200: aimaths, aimatht, aibasics, aibasict, ai-study-science, ai-study-math/mathplay/, penedu/history/, 2027tech, 2027dongnae, watchpeter.
- 링크 대상 title 대조(카드 설명과 일치): 인공지능 수학, 인공지능 수학·교사용, 인공지능 기초, 인공지능 기초·교사용, 온라인 과학 체험(설명 "4개 층 48가지"가 대상 meta 와 일치), 기술·가정 배움터, 손목 컨트롤러 시뮬레이터(대상 meta 와 일치).
- firebase.aiworld.json: site aiworld, public aiworld, html no-cache. 정상.
- firebase.ai-study-math.json: "/" 만 https://aiworld.web.app/ 으로 302. 하위 경로는 rewrite 로 유지됨. 라이브 확인: ai-study-math.web.app/ 는 302 -> aiworld.web.app/, /?x=1 은 302 로 쿼리 제거(참고), /mathplay/ 와 /aibasic/ 은 200 으로 유지.
- 파비콘 3종(svg·32·180 png) 파일이 aiworld 폴더에 있고 head 에 link 3개가 있음. 라이브 aiworld.web.app 에서도 200.
- Chrome 80 호환: min()·clamp() 는 Chrome 79+ 지원이라 문제 없다고 판단(실제 Chrome 80 으로는 미실행).

## 확인하지 못한 것
- 실제 Chrome 80, 실기기 휴대폰.
- 링크 대상 사이트 내부 동작(이 검수 범위 밖).
- ai-study-math 설정의 public "dist" 폴더는 저장소에서 찾지 못함(빌드 산출물 위치 미확인). 배포 시 dist 가 있어야 함.
- ai-study-hub/index.html(루트 사본)은 카드 2 이후 일부가 aiworld 판과 다름(예: 인공지능 기초 카드가 /aibasic/). 이번 대상이 아니라 내용 검증 안 함.
