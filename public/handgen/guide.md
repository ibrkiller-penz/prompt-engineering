# 작업지시서: 「[주제]」 학생용 학습 사이트

> **사용법**
> 1. 아래 [대괄호]를 내 주제로 고칩니다. (주제, 대상, 부품, 단계, 용어 등)
> 2. 이 문서 전체를 AI(Claude Code 등)에게 주고 이렇게 말합니다.
>    "이 작업지시서대로 진행해. 9절의 단계마다 끝나면 멈추고 보고해."
> 3. 보고를 받을 때마다 9절 점검표로 확인하고 "다음 단계 진행해"라고 말합니다.
>
> 본보기 사이트: https://penedu.web.app/handgen/site/ (손발전기)
> 본보기 파일: `public/handgen/site/index.html` (파일 하나로 모든 기능이 들어 있음)

## 0. 목표
- [종이 키트 / 실험 / 활동] 설명서를 **학생이 혼자 보고 따라 만들 수 있는 웹사이트**로 만든다.
- 구성: 만들기 절차 + 교육과정 기초자료 + 원리 교육 자료 + 애니메이션 영상(목소리·음악) + 퀴즈 + 인쇄·내려받기 학습지.
- 대상: [중·고등학생]. 스마트폰으로 보면서 손으로 작업한다. (한 손에 부품을 든 상태)
- 성공 기준: 처음 보는 학생이 휴대폰만 보고 끝까지 만든다.

## 1. 저작권 원칙 (반드시)
- 원본 설명서의 **문장·그림·레이아웃·색 구성을 복제하지 않는다.** 사실 정보(부품 이름·개수·길이·순서)만 쓰고 문장은 전부 새로 쓴다.
- 모든 그림은 **직접 그린 SVG**. 사진·스캔·트레이싱 금지.
- 제조사명·상표·로고 금지. 바닥글에 "키트 설명서를 참고해 교사가 재구성한 학습 자료" 표기.
- 배경음악은 코드로 만든 소리, 목소리는 직접 만든 mp3만 쓴다. (남의 음원·효과음 금지)
- "원본과 똑같이"를 요구받으면 **같은 부품은 같은 색·모양으로 통일**하는 것으로 해결하고, 원본 그림 자체는 따라 그리지 않는다.

## 2. 교육과정과 내용 정확성
1. **2022 개정 교육과정**에서 이 주제의 성취기준을 검색한다. (국가교육과정정보센터 ncic.kice.re.kr, 보조로 교사 공유 정리본)
2. 아래를 표로 정리한다: 학교급·과목·단원 / 성취기준 코드와 전문 / **성취기준 해설(어디까지 다루는지)** / 이 활동과의 관계(핵심 연계·선수 개념·확장).
3. 해설이 "다루지 않는다"고 한 내용(예: 계산 법칙)은 본문에서 빼고 **"더 알아보기(교육과정 밖)" 박스**로 분리한다.
4. 교육과정이 개정되며 단원이 옮겨졌는지 확인한다. (예: 전자기 유도는 중학교 → 고1 통합과학2로 이동)
5. 원본 설명서에 부정확한 설명이 있으면 바로잡고, 무엇을 어떻게 고쳤는지 기록한다.
6. 핵심 용어 6~8개를 먼저 확정한다: [용어 목록]. 사이트 전체에서 이 용어만 쓴다.
7. 모든 교육과정·과학 내용에 **"교사 확인 필요"** 표시를 붙이고, 출처 링크를 바닥글에 둔다.

## 3. 사이트 구성 (한 페이지 스크롤 + 위쪽 고정 메뉴)
메뉴: 준비물 · 만들기 · 안 켜질 때 · 기초자료 · 원리 · 영상 · 퀴즈 · 학습지

| 구역 | 내용 | 확인할 것 |
|---|---|---|
| 히어로 | 흥미를 끄는 제목, 움직이는 SVG 그림, [만들기 시작] 버튼 | 첫 화면에서 무엇을 만드는지 보인다 |
| 준비물 | 부품 카드(아이콘+이름+개수), 누르면 체크 | 카드가 줄을 빈칸 없이 채운다 |
| 만들기 | [4~6]단계 카드, 이전/다음, 진행 막대, 단계 번호 버튼 | 아래 '만들기 단계 카드 형식'을 지킨다 |
| 안 켜질 때 | 자주 틀리는 것 5개 + 해결법 (접었다 펴기) | 쉬운 것부터 순서대로 |
| 기초자료 | 교육과정 표, 핵심 용어 카드, 에너지 전환 그림, 핵심 수치 표, 자가진단, 생활 속 예 | 2절 내용이 모두 들어간다 |
| 원리 | 4칸 그림 설명 + **슬라이더 실험**(정성적 모형) + 더 알아보기 박스 | 경향을 보는 모형임을 밝힌다 |
| 영상 | 영상 A(조립), 영상 B(원리) | 5절 규칙 |
| 퀴즈 | 5문항, 선택 즉시 정답·해설, 점수, 다시 풀기 | 오답에도 해설이 나온다 |
| 학습지 | 인쇄 + 한글(.hwpx) + 워드(.docx) 내려받기, 교사용 정답본 | 6절 규칙 |

### 만들기 단계 카드 형식
각 단계는 아래 6가지를 모두 넣는다.
1. **제목**: 동사로 끝낸다. ("링을 끼우고 자석 넣기")
2. **그림 1장**: 지금 손으로 하는 동작이 보이고, 움직이는 화살표가 방향을 알려 준다.
3. **문장 2~3줄**: 한 문장에 동작 하나. 길이·개수는 숫자로. (예: 12~13mm, 5~6바퀴)
4. **⚠️ 주의 1개**: 다치거나 망가지는 것만.
5. **✅ 확인 3~4개**: 눈으로 보고 "예/아니오"로 답할 수 있는 문장. 학생이 체크하며 넘어간다. (이 기기에만 저장)
6. **⏱ 걸리는 시간**: "약 N분".

규칙: 단계 4~6개, 한 단계 5분 안팎, 단계 순서는 실제 작업 순서와 같다.

## 4. 그림 (SVG)
- 외부 이미지 없음. 모든 그래픽은 SVG.
- **한 개의 그리기 함수**(`tube(옵션)`)가 모든 단계 그림과 영상 장면을 만든다. 옵션만 바꿔 쓰므로 모양과 색이 자동으로 통일된다. 새 주제는 이 함수를 [새 부품 그림 함수]로 바꾼다.
- 부품 색은 한 번 정해 끝까지 쓴다: [부품별 색 표]
- 색은 CSS 변수(`:root`)로만 쓴다. 다크 모드에서도 읽혀야 한다.
- 모든 그림에 대체 텍스트(`aria-label`)를 쓴다.
- 부품이 "아직 없는 상태 → 들어오는 상태"가 보이게 그린다. (예: 마개는 처음엔 떠 있다가 나중에 닫힌다. 자석은 관 밖에서 시작해 입구로 들어간다.)

## 5. 영상 (애니메이션 + 목소리 + 음악)
영상은 **"문장 하나 = 동작 하나"** 구조로 만든다. 긴 해설을 한 번에 얹지 않는다.

1. **대본 쓰기**: 영상 A(조립) [10~14문장], 영상 B(원리) [8~10문장]. 한 문장은 짧게(1~2절), 한 문장에 동작 하나.
2. **mp3 만들기**: 문장마다 mp3 1개. 무료 신경망 음성(edge-tts, 한국어 SunHi 여성 / InJoon 남성), 속도 -6%.
   - 읽기 어려운 말은 읽는 대로 적는다. (LED → "엘이디", 12~13mm → "십이에서 십삼 밀리미터")
   - 만든 뒤 각 mp3 길이를 `durations.json`에 저장한다.
3. **장면 연결**: 장면마다 `{mp3 id, 자막, 그림 함수}`. 장면 길이는 **mp3 길이 + 0.8초로 자동 계산**한다. (손으로 맞추지 않는다)
4. **그림 함수** `draw(p, t, T)`: `p`는 장면 진행(0~1), `T`는 영상 전체 시간. 이어지는 움직임(왕복 등)은 `T`로 계산해 장면이 바뀌어도 끊기지 않게 한다. 장면이 끝날 때의 모습 = 다음 장면이 시작할 때의 모습.
5. **자막**: 자막 글 = 읽는 문장. 큰 글씨(18px 이상), 단계 이름표(1단계 등) 표시.
6. **배경음악**: 코드로 만든 잔잔한 화음. 목소리보다 작게(볼륨 약 0.2). 🎵 버튼으로 끌 수 있다.
7. **조작**: 재생/일시정지, 처음부터, 🎵음악 켜기/끄기, 🗣목소리 켜기/끄기, 재생 위치 바. 일시정지 후 재생하면 **그 문장 처음부터** 다시 시작한다.
8. **목소리 대체**: mp3가 안 나오면 브라우저의 한국어 음성으로 읽는다.
9. **반드시 지킬 장면 논리** (본보기에서 학생이 헷갈렸던 곳)
   - 아직 일어나지 않은 일을 미리 보여 주지 않는다. (마개를 닫기 전엔 마개가 떠 있다)
   - 부품이 걸쳐 있거나 겹쳐 있으면 안 된다. (자석이 관 입구에 걸쳐 시작하는 것 금지)
   - 이동하는 물체는 끝에서 끝까지 실제로 간다. (왕복하는 자석이 관 끝까지)
   - 멘트에 나온 말은 그 순간 화면에 보여야 한다.

## 6. 학습지 (인쇄 + 파일)
1. 내용: 용어 빈칸, 에너지 전환 쓰기, **관찰 기록표**, 탐구 질문 3개, 생각 넓히기, 자기평가. 맨 위에 성취기준과 이름·학년반번호 칸.
2. 화면에서 보이는 학습지는 **인쇄 전용 스타일**을 따로 쓴다. (A4, 여백 14~16mm, 표 테두리 있음, 쓰는 칸 높이 확보, 나머지 화면 요소 숨김)
3. 파일 만들기: 스크립트 하나로 학생용·교사용 **워드(.docx)와 한글(.hwpx)** 를 만든다. (문항은 스크립트 한 곳만 고치면 됨)
4. 교사용 정답본은 정답을 초록색 굵은 글씨로 넣는다. 화면에도 "정답 보기" 버튼.
5. 한글 파일은 `.hwpx` (한글 2014 이상). 파일 안내 문구를 학습지 위에 쓴다.

## 7. 디자인
- **모바일 우선**: 본문 18px 이상, 버튼 높이 48px 이상(엄지로 누름), 가로로 밀리지 않기.
- **여백은 넉넉하게** (본보기 수치): 본문 줄간격 1.85, 구역 위아래 64px, 카드 안쪽 22~24px, 카드·표 사이 16~20px, 제목 위 여백 2.4em, 표 칸 안쪽 14×16px. 답답하다는 말이 나오면 이 수치부터 키운다.
- 색: [남색 + 노랑] 포인트, 다크 모드 지원. 글자와 배경 대비 4.5:1 이상.
- 접근성: 키보드로 모든 버튼 사용, 포커스 표시, `prefers-reduced-motion`(움직임 줄이기)이면 장식 애니메이션 정지.
- 로그인·개인정보 수집 없음. 체크·진행 단계만 `localStorage`에 저장(저장 실패해도 동작).

## 8. 기술과 배포
- 시작은 **파일 하나**(HTML+CSS+JS), 외부 이미지 없음.
- 폴더 예: `사이트/` (`index.html` 안내, `together/` 같이 해보기, `site/` 완성 사이트, `audio/` 멘트 mp3, `worksheet/` 학습지 파일, `guide.md` 이 작업지시서)
- 만들기 도구(만들 때만 필요): 멘트 mp3 = `python scripts/make-narration.py`, 학습지 파일 = `python scripts/make-worksheet.py`
- 배포: Firebase Hosting (정적). 허브 사이트의 꼭지 목록에 카드를 한 개 더한다.
  - 카드 필드: 제목(메인에서 보이는 이름), 태그, 설명 3~4줄, 이동 글자("안내 보기 →"), 주소.
  - 주소는 바로 완성 사이트가 아니라 **안내 페이지**로 연결한다. (안내 → 같이 해보기 → 완성 사이트)

## 9. 진행 순서 (단계마다 멈추고 보고)
각 단계가 끝나면 **무엇을 만들었는지, 확인할 점, 모르는 점**을 보고하고 기다린다.

1. **원고**: 교육과정 검색 결과 표, 용어, 만들기 단계 문장, 퀴즈 5문항, 학습지 문항, 영상 대본 → **교사 검토 대기**
2. **그림**: 부품 아이콘, 단계 그림, 영상 장면 프레임 → 확인
3. **페이지 구조**: 히어로~안 켜질 때~기초자료
4. **원리·실험·퀴즈·학습지**
5. **영상 A·B**: mp3, 장면, 음악, 조작 버튼
6. **검토와 배포**: 아래 점검표 → 휴대폰 점검 → 배포

### 점검표 (보고 때마다 확인)
- [ ] 저작권: 원본 문장·그림 복제 0, 제조사명·로고 없음, 바닥글 문구 있음
- [ ] 교육과정: 성취기준 코드·해설 정리, "다루지 않는 내용"은 심화 박스, 교사 확인 표시, 출처 링크
- [ ] 단계 카드마다 그림·문장·주의·확인·시간이 있다
- [ ] 같은 부품은 모든 그림에서 같은 색·모양이다
- [ ] 영상: 멘트와 화면이 일치한다. **모든 장면의 중간·끝 프레임을 한 화면에 모아 눈으로 확인**한다. (걸침·미리 보임·끝까지 안 감 같은 오류 찾기)
- [ ] 영상: 일시정지·재개·음악 끄기·목소리 끄기·위치 이동이 된다
- [ ] 퀴즈 채점·해설, 학습지 인쇄·파일 열림(한글·워드)이 정상
- [ ] 휴대폰 너비(375px)에서 가로로 밀리지 않고 글씨·버튼이 충분히 크다
- [ ] 키보드 이동, 움직임 줄이기, 다크 모드 확인
- [ ] 콘솔 오류 없음

## 10. 완료 기준
- 스마트폰만 보고 학생이 끝까지 따라 만들 수 있다
- 원본 문장·그림 복제 0
- 과학 용어가 교육과정 해설과 일치한다
- 영상 A·B가 멘트·음악과 함께 재생되고, 퀴즈 채점, 학습지 인쇄·파일이 정상 동작한다
- 점검표 전체 통과
