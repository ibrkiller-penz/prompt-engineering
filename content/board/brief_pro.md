# 프로용 작업지시서(토큰 적게): 시간표 단말 만들기 — 7인치

> **사용하는 분에게**: Claude Pro 처럼 사용량이 넉넉하지 않을 때 쓰는 짧은 판이에요.
> 되풀이되는 일은 **키트의 스크립트가 알아서** 하고, AI는 **막혔을 때만** 불러요. AI에게 이 글을 붙여 넣고 "프로로 하자"라고 하세요.
> 로그인·비밀번호는 AI가 대신하지 않아요.

## 1. 내가 직접 하는 순서 (AI 없이)

1. 키트(`penedu-board-7inch-starter.zip`)를 **영문 폴더**에 풀어요. 예: `C:\dev\board-kit`
2. 보드를 **‘UART’** 라고 적힌 USB-C 단자에 **데이터 케이블**로 꽂아요.
3. PowerShell 을 열고 한 줄 실행해요.
   ```
   powershell -ExecutionPolicy Bypass -File C:\dev\board-kit\7inch\tools\quick_start.ps1
   ```
   스크립트가 차례로 물어보며 진행해요: 프로그램 확인 → 보드 종류(7인치 / 7인치 B) → 샘플 자료 → Firebase 올리기(로그인은 직접) → 내 값(학교 코드·위치) → 빌드(처음 25~45분) → 보드 찾기 → 굽기 → 단축키 도우미(선택).
4. 보드 화면 **[설정] → [찾기]** 에서 학교 와이파이(2.4GHz)를 고르고 비밀번호를 직접 넣어요.
5. 멈추면 화면의 **빨간 X 줄 몇 개만** AI에게 붙여 넣고 "고쳐 줘"라고 해요. 다른 설명은 길게 하지 않아도 돼요.

## 2. AI에게 (프로 규칙)

- 키트의 `7inch/CLAUDE.md`(짧은 안내판)와 `7inch/docs/지시서_프로.md` 만 읽는다. 자세한 사실이 필요할 때만 `docs/지시서_맥스.md` 의 해당 장을 연다.
- `firmware/src/main.cpp`(약 180KB)는 통째로 읽지 않는다. 찾기로 필요한 함수만.
- 사용자가 붙여 넣은 오류 줄로 판단하고, 한 번에 고치고, 한 번 빌드·확인한다. 보고는 3줄 이내.
- 화면 설정(흔들림 대책)은 손대지 않는다. 그쪽 문제면 맥스용으로 바꾸자고 말한다.
- 빌드는 `tools\build_board.ps1` 로만 한다(결과 몇 줄만 보여 주고 전체 기록은 `build.log`).

## 3. 자주 하는 작은 일

| 하고 싶은 일 | 하는 법 |
|---|---|
| 내 값(주소·학교 코드·위치) 바꾸기 | `quick_start.ps1` 다시 실행 |
| 교시 시작 시각 | AI에게 "교시 시각을 08:30, 09:30 … 으로 바꿔 줘" (`PERIOD_START` 한 줄) |
| 내 시간표 올리기 | 자료 형식(키트 `common/tools/data-format.md`)에 맞춰 `common/site/public/board/` 에 넣고 다시 올리기 |
| 단축키로 여는 프로그램 | `tools/deck_helper.ps1` 의 표만 고치기(보드는 다시 굽지 않아도 돼요) |

## 4. 토큰을 아끼는 말 습관

- "전부 확인해 줘" 대신 **"빌드하고 굽고 30초만 확인해 줘"** 처럼 한 번에 묶어서.
- 사진·긴 기록을 통째로 붙이지 말고 **빨간 줄 몇 개만**.
- 한 대화가 길어지면 새 대화를 열고 "프로로, 지금 ○○ 단계"라고 시작하면 덜 써요.
