# 안내판: 교실 알림판 4인치 (Waveshare ESP32-S3-Touch-LCD-4 V4.0)

> **도우미(Claude)에게** — 이 파일은 일부러 짧다(대화마다 다시 읽히므로 토큰을 아낀다).
> 대화 처음에 한 번만 묻는다: **"프로(토큰 적게)로 할까요, 맥스(자세히)로 할까요?"** 사용자가 이미 말했으면 묻지 않는다.
> - **프로** → `docs/지시서_프로.md` 만 읽는다. 스크립트가 일하고, AI는 막혔을 때만.
> - **맥스** → `docs/지시서_맥스.md` 를 읽는다. AI가 한 단계씩 같이 한다(자세한 사실·금지 사항·단계표).
> 사용자는 프로그래머가 아니다. 쉬운 한국어로 말하고, 전문 용어는 한 줄 풀이를 붙인다.

## 어느 쪽이든 꼭 지킬 것
1. 로그인·비밀번호·열쇠·와이파이 비밀번호는 **사용자가 직접**. 묻지도, 파일에 쓰지도 않는다.
2. **화면 설정은 바꾸지 않는다**: `firmware/platformio.ini` 의 `custom_sdkconfig`, `main.cpp` 의 RGB 패널 박자(16MHz·20/10/10·10/10/10)·완충 버퍼·`ST7701_INIT`. (이유: 맥스 지시서 5장)
3. 빌드·업로드는 **`tools\build_board.ps1` 로만**(경로에 한글이 있으면 직접 빌드가 실패한다). 보드를 지우거나 0x0 에 통째로 굽는 일은 **먼저 묻는다**(저장한 와이파이가 지워진다).
4. **밝기 값은 거꾸로**(0 = 가장 밝음, 255 = 꺼짐). 255 를 쓰지 않는다 — USB 를 완전히 뽑아야 돌아온다.
5. 시리얼은 **시간 제한**을 두고 읽기만(`python tools\serial_log.py --port COMx 20`). 보드를 리셋하지 않는다(부저가 계속 울린 적 있음).
6. 교사 **실명** 등 개인정보는 공개 주소(Firebase)에 올리지 않는 쪽을 권한다. 화면 글자는 한글 2,350자(KS X 1001) 안에서만.

## 토큰 아끼기(프로·맥스 공통)
- `firmware/src/main.cpp` 는 **통째로 읽지 않는다**. 찾기(grep)로 필요한 함수만 연다.
- `build_board.ps1` 은 결과 몇 줄만 보여 준다. 전체 기록은 빌드 폴더의 `build.log` — 실패했을 때 오류 부분만 본다.
- 확인은 한 번에 묶는다(빌드 → 굽기 → 기록 20초). 같은 확인을 되풀이하지 않는다.
- 문서도 필요한 장만 연다(맥스 지시서: 2장 하드웨어 · 4장 빌드 · 5장 화면 · 8장 코드 안내).
