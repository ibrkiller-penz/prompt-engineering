# 프로용 작업지시서(토큰 적게): 교실 알림판 7인치

**원칙**: 되풀이되는 일(설치 확인 · 샘플 자료 · Firebase 올리기 · 내 값 넣기 · 빌드 · 굽기)은 **스크립트 하나**가 한다.
AI는 ① 스크립트가 멈췄을 때 **오류 몇 줄**을 보고 고치거나 ② 사용자가 원하는 **작은 수정**만 한다.
더 자세한 사실이 필요하면 `docs/지시서_맥스.md` 의 해당 장만 골라 읽는다(2장 하드웨어 · 4장 빌드 · 5장 화면 · 8장 막히는 곳).

## 1. 사용자가 직접 하는 순서 (AI 없이)

1. 키트를 **영문 폴더**에 푼다. 예: `C:\dev\board-kit` (한글·빈칸 폴더는 빌드가 멈춘다)
2. 보드를 **UART** 라고 적힌 USB-C 단자에 데이터 케이블로 꽂는다.
3. PowerShell 을 열고 한 줄 실행:
   ```
   powershell -ExecutionPolicy Bypass -File C:\dev\board-kit\7inch\tools\quick_start.ps1
   ```
   스크립트가 차례로 묻고 진행한다: 프로그램 확인 → 보드 종류 → 샘플 자료 → Firebase 올리기(**로그인은 직접**) → 내 값(학교 코드·위치) → 빌드(처음 25~45분) → 보드 찾기 → 굽기.
   이미 끝난 단계는 건너뛴다. 여러 번 돌려도 된다.
4. 보드 화면 **[설정] → [찾기]** 에서 와이파이를 고르고 비밀번호를 직접 넣는다.
5. 멈추면 화면의 **빨간 줄(X 줄) 몇 개만** AI에게 붙여 넣고 "고쳐 줘"라고 한다.

## 2. AI가 할 일 (프로)

- 사용자가 붙여 넣은 오류 줄로 판단한다. 필요한 파일만 찾아서 연다(통째로 읽지 않기).
- 한 번에 고치고 **한 번** 빌드·확인한다. 보고는 3줄 이내.
- 단계마다 되묻지 않는다. 사용자가 정해야 하는 것(값·허락)만 묻는다.
- 고칠 곳이 **화면 설정(흔들림)** 이면 손대지 말고 "맥스용으로 바꿔서 하자"고 말한다.

## 3. 자주 하는 작은 일

| 하고 싶은 일 | 하는 법 |
|---|---|
| 내 값(사이트 주소·학교 코드·위치·수능 날짜) 바꾸기 | `quick_start.ps1` 다시 실행, 또는 `firmware/include/board_config.local.h` 고치고 `build_board.ps1 -Port COM번호` |
| 교시 시작 시각 | `main.cpp` 의 `PERIOD_START` (점심 "12:30"·"13:30" 도 함께) |
| 내 시간표 올리기 | `../common/tools/data-format.md` 모양으로 `../common/site/public/board/` 에 넣고 `firebase deploy --only hosting` |
| 단축키로 여는 프로그램 | 탭덱(`common/deck-helper/탭덱.exe`) 작업 표시줄 아이콘 → [단축키 꾸미기…]에서 고친다(보드는 다시 굽지 않아도 된다) |
| 교장실 모드 | 볼 시간표에서 [교장]·[교감]. 일정 사이트 주소는 `board_config.local.h` 의 `SCHEDULE_URL` |

## 4. 자주 막히는 곳 (짧게)

| 증상 | 해결 |
|---|---|
| 빌드가 `CMake Error` | 키트를 영문 폴더로 옮기고 `build_board.ps1` 로 빌드 |
| 보드를 못 찾음 | UART 단자 · 데이터 케이블 · 다른 USB 구멍 |
| `port is busy` | 탭덱이 포트를 쥐고 있음 → `%TEMP%\deck_helper.stop` 파일을 만들고 다시, 끝나면 지운다 |
| 화면이 떨리거나 밀림 | 1분 안에 저절로 돌아오면 정상. 계속되면 맥스용으로 |
| 화면에 '설정 필요' | 그 값이 비어 있음(정상). 필요하면 `quick_start.ps1` 다시 |
