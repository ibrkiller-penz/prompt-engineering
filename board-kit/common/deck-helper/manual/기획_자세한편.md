# 기획서 — 단축키 도우미 설명서 2부 「자세한 설명서(과정편)」

> 만드는 것: `사용설명서.html` 뒤쪽에 이어 붙이는 **2부**. 1부(지금 14쪽 간단편)는 "무엇이 있나"를 알려 주는 **찾아보기용**이고,
> 2부는 "처음 받는 날부터 보드에서 단추가 열릴 때까지"를 **순서대로 따라 하는 책**이다. 읽는 사람 = 컴퓨터를 잘 모르는 교사.
> PDF: `python manual/make_manual_pdf.py` (HTML 하나 → `단축키도우미_사용설명서.pdf`, 쪽 그림 `manual/preview/pNN.png`).

## 0. 먼저 알아 둘 것(작가 공통)

### 0-1. 1부와 겹치지 않게 나누는 법
| 1부(간단편)가 하는 일 | 2부(과정편)가 하는 일 |
|---|---|
| 기능 목록·표(하는 일 6가지, 아이콘 방식 6가지, 기호표, 키보드표) | 그중 **하나를 골라 실제로 끝까지** 해 보기. 표는 다시 싣지 않고 "1부 6장 표"처럼 가리킨다 |
| "무엇을 누르면 무엇이 된다" 한 줄 | **누르기 → 보이는 것 → 확인하기 → 안 되면** 네 단계 |
| 화면 설명 | 화면 그림에 **번호·빨간 동그라미**를 넣어 손가락으로 짚듯이 |

- 2부의 장 번호는 1부와 섞이지 않게 **"2부 0장 ~ 2부 14장"**으로 쓴다. 본문에서 1부를 가리킬 때는 "1부 7장".
- 2부 첫 쪽은 **구분 쪽**(어두운 바탕, 1부 표지와 같은 `.cover` 모양): 제목 "자세한 설명서 — 처음부터 따라 하기", 그림 `00_과정편표지.png`, 아래에 2부 차례.

### 0-2. 장 하나의 틀(모든 장 똑같이)
```html
<section>
  <h2><span class="no">2부 4</span>따라 하기① 빈 칸에 ‘한글’ 넣기</h2>
  <div class="goal"><b>이 장의 목표</b> …한 줄…</div>
  <p class="small">걸리는 시간 약 5분 · 필요한 것: …</p>
  <ol class="steps">
    <li><b>누르기</b> … → <b>보이는 것</b> …
        <figure class="w72"><img src="img2/NN_이름.png"><figcaption>…</figcaption></figure></li>
  </ol>
  <div class="check"><b>잘 됐는지 확인</b> …</div>
  <div class="fail"><b>이렇게 안 되면</b><ul><li>증상 → 할 일</li></ul></div>
</section>
```
- 새로 더할 CSS(작가 A가 맨 처음 `<style>` 끝에 넣는다): `.goal`(파란 테두리 상자), `.check`(초록 왼쪽 띠 #1f9d55, 바탕 #eaf7ef), `.fail`(=`.warn` 색), `.part`(구분 쪽). 나머지는 기존 `.steps .tip .note .warn .btn .key figure.w72/.w64/.half .two` 를 그대로 쓴다.
- 단추 글자는 `<span class="btn">…</span>`, 키는 `<span class="key">Ctrl</span>`, 쳐 넣는 글자는 `<code>…</code>`.

### 0-3. 글쓰기 규칙(꼭)
1. 한 문장에 한 가지. 문장 끝은 "~해요/~예요" (1부와 같은 말투).
2. 영어 낱말 금지. 키 이름(Ctrl·Shift·Alt·Win·Enter·Tab·Esc·F1~F24·Delete)·제품 이름(한글, 엣지, 크롬, 파워포인트, Windows, 캔바 등)과 **화면에 그대로 보이는 글자·쳐 넣는 값**(`https://www.neis.go.kr`, `explorer.exe`, `#+s`)만 예외. 쳐 넣는 값은 꼭 `<code>`로 감싸고 "이 글자를 그대로 쳐요"라고 쓴다.
3. 전문 용어는 처음 나올 때 괄호 풀이: 작업 표시줄(화면 맨 아래 막대), 알림 영역(작업 표시줄 오른쪽 끝, 시계 옆), 대상(무엇을 열지), 경로(파일이 있는 자리 주소), 압축 파일(여러 파일을 하나로 묶은 파일).
4. 단추·메뉴 글자는 **아래 0-5 표의 글자를 그대로**. 표에 없는 글자를 쓰려면 소스에서 찾아 확인하고, 못 찾으면 쓰지 않는다.
5. 실명·학교 이름·전화번호·실제 포트 이름(예: COM5) 금지. 연결 알림 괄호 안 글자는 "컴퓨터마다 달라요"라고만 쓴다.
6. 소리 나는 동작(소리 끄기 등)과 키 보내기는 **글로만 설명**하고, 작가가 직접 실행하지 않는다(사용자 도우미 끄기·COM 포트 열기·키 보내기 금지).

### 0-4. 그림 규칙
- 파일: `manual/img2/NN_이름.png` (NN = 00~55, 아래 장별 표 번호 그대로).
- **[자름]** = `exe/preview/*.png`(또는 표에 적은 원본)에서 픽셀 영역 `(왼, 위)-(오른, 아래)`를 잘라 표시를 더한 것. 원본 크기 그대로 자르고, 작은 창(11~14번 그림)은 2배로 키운다.
- **[그림]** = 윈도 화면·인터넷 창·보드 모양·순서도처럼 **실제 화면 사진이 없는 것**. 사진처럼 흉내 내지 말고 **간단한 도형 + 글**로 그린다(둥근 네모, 회색 테두리, 흰 바탕, 글꼴 에스코어 드림 `exe/fonts/SCDream4.otf`). 윈도 로고·브라우저 로고 등 상표 그림은 넣지 않는다.
- 표시 약속(모든 그림 같게):
  - 빨간 동그라미 = 둥근 네모 테두리 `#e5484d`, 굵기 4px, 영역보다 6px 크게.
  - 번호 = 지름 30px 파란 원 `#3b6fe0` + 흰 숫자(1부 `.steps` 번호와 같은 색). 동그라미 왼쪽 위 바깥에 붙인다. 본문 단계 번호와 같은 숫자를 쓴다.
  - 화살표 = 빨강 `#e5484d` 굵기 5px, 끝 삼각형.
  - 강조 바깥을 어둡게 할 때 = 검정 45% 덮개(필요한 그림에만 표에 적음).
- 그림 만들기는 파이썬(PIL) 한 파일 `manual/make_img2.py` 로 모은다(작가마다 자기 번호 함수만 추가). **원본 그림은 고치지 않는다.**
- 주의: `exe/preview` 그림은 다른 작업에서 **다시 만들어지는 중**이다(오늘 08:50에 15~18번이 새로 생기고, 위 띠에 `설명서` 단추가 더해졌다). 자르기 직전에 그림을 한 번 열어 아래 좌표가 맞는지 확인하고, 어긋나면 고친 좌표를 이 문서에 적는다.

### 2부 0장 시작 전에 준비할 것 (작가 A)
**목표**: 보드·케이블·컴퓨터 세 가지를 갖추고, 어느 단자에 꽂을지 안다.
1. 보드가 7인치인지 4인치인지 본다(화면 크기, 단추 칸 모양 2줄×8칸 / 4줄×4칸). → 1부 4장 "칸 번호" 참고만.
2. 케이블: **데이터 케이블**(자료를 주고받는 선)이어야 한다. 충전만 되는 선은 안 된다. 구별법: 휴대폰을 꽂았을 때 컴퓨터에 휴대폰 이름이 보이면 데이터 케이블.
3. 꽂을 단자: 7인치는 ‘UART’ 글자가 적힌 단자, 4인치는 USB-C 단자.
4. 컴퓨터: 윈도 컴퓨터, 인터넷 연결(받을 때만), 빈 USB 구멍 하나.
5. 시간: 처음부터 10장까지 약 30분.
- 확인: 준비물 체크 표(□ 보드 □ 데이터 케이블 □ 인터넷 되는 윈도 컴퓨터).

### 2부 1장 도우미 받고 깔기 (작가 A)
**목표**: 도우미를 깔고, 알림 영역(시계 옆)에 알림판 아이콘이 생긴 것을 본다.
1. 인터넷 창(엣지나 크롬)을 연다 → 맨 위 주소 칸을 누른다 → `penedu.web.app/deck` 를 그대로 친다 → Enter → 도우미 받는 쪽이 보인다. [03]
2. `도우미 받기`를 누른다 → 오른쪽 위에 받은 파일 목록이 보인다. "흔하지 않은 파일" 같은 경고가 보이면 `…`(점 세 개) → `유지`. [04] (확인 못 한 글자라 "브라우저에 따라 글자가 달라요" 붙임)
3. 받은 파일 목록에서 `파일 열기`를 누르거나, 탐색기 → `다운로드` 폴더에서 받은 압축 파일을 두 번 누른다 → 안에 `교실알림판_도우미.exe` 가 보인다 → 두 번 누른다(압축은 풀지 않아도 돼요). [05]
4. 파란 "Windows의 PC 보호" 창이 뜨면 `추가 정보` → `실행`. 서명(만든 사람 확인 표시)이 없는 프로그램이라 처음 한 번만 나와요. [06]
5. 오른쪽 아래에 풍선 알림 "설치했어요. 컴퓨터를 켤 때 저절로 켜져요." 가 뜬다.
6. 작업 표시줄 오른쪽 끝 `^`(숨은 아이콘 보기)를 누르면 **회색** 알림판 아이콘이 보인다. 자주 쓰려면 이 아이콘을 끌어서 `^` 밖 작업 표시줄에 놓는다. [07]
- 확인: 회색 아이콘이 보이면 성공(회색 = 아직 보드를 찾는 중, 정상).
- 안 되면:
  - 두 번 눌러도 아무 일이 없음 → `^` 안에 이미 아이콘이 있는지 본다(이미 켜져 있을 수 있어요).
  - 학교 백신이 막음 → 백신의 ‘예외(허용)’ 목록에 `교실알림판_도우미.exe` 를 넣는다(정보 담당 선생님께 부탁).
  - 컴퓨터를 다시 켠 뒤 아이콘이 없음 → 시작 메뉴에서 ‘교실알림판 도우미’를 누른다.
- 1부 2장과 겹침 주의: 1부는 4줄 요약. 여기서는 그림 5장으로 한 단계씩.

### 2부 2장 보드 꽂고 연결 확인 (작가 A)
**목표**: 아이콘이 초록이 되고, 보드 단추로 탐색기가 열리는 것을 본다.
1. 보드를 켜고 단축키 화면을 연다 → 아래 줄에 "컴퓨터 도우미를 기다리는 중 …" 이 보인다. (보드에서 단축키 화면 들어가는 법은 보드 설명서를 따름 — 확인 필요 표시)
2. 데이터 케이블로 보드(7인치는 UART 단자)와 컴퓨터를 잇는다.
3. 5초쯤 기다린다 → 알림판 아이콘이 **초록** → 풍선 "7인치 알림판과 연결됐어요 (…)" (괄호 안은 컴퓨터마다 달라요). [08]
4. 아이콘을 오른쪽 클릭 → 메뉴 맨 위 회색 줄이 `연결됨: 7인치(…)` 인지 본다. 메뉴 항목 이름도 함께 익힌다. [09]
5. 보드 아래 줄이 "✓ 컴퓨터와 연결됨 · 단추를 누르면 프로그램이 열립니다" 로 바뀐다. [10]
6. 보드의 1번 칸 `탐색기`를 누른다 → 컴퓨터에 탐색기(폴더 창)가 열린다.
- 확인: 초록 아이콘 + 보드 아래 초록 글 + 탐색기 열림, 셋 다.
- 안 되면:
  - 회색 그대로 → 메뉴 맨 위가 "알림판을 찾는 중 — 7인치는 UART 단자 …" → 단자·케이블 바꿔 보기 → 그래도 안 되면 2부 12장 순서도 가.
  - 주황 → 메뉴의 `잠깐 멈추기(보드 굽기 전에)`가 켜져 있어요. 한 번 눌러 끈다.
  - 보드 쪽만 안 바뀜 → 보드 오른쪽 아래 새로 고침(⟳) 단추를 누른다.

### 2부 3장 꾸미기 창 처음 열기 (작가 A)
**목표**: 꾸미기 창을 열어 다섯 구역을 알아보고, 칸 하나를 골라 ▶ 눌러 보기까지 해 본다.

4. 1번 동작을 누르고 아래 `고른 동작`에서 `프로그램 열기`, 대상 칸을 지우고 `powerpnt` 를 친다(파워포인트). `다음 동작까지 기다리기`에서 `2초`. [33]
5. `+ 동작 더하기` → 2번 동작이 생긴다 → `사이트 열기`, 대상 `https://www.neis.go.kr`, `자세히…` → `엣지` → `확인`. 기다리기 `1초`.
6. `+ 동작 더하기` → 3번 동작 → `컴퓨터 기능` → 목록에서 `소리 끄기·켜기`.
7. 차례 바꾸기는 `위로`/`아래로`, 빼기는 `빼기`(빨간 단추).
8. `▶ 차례대로 해 보기` → 파워포인트 → 나이스 → 소리 꺼짐을 눈으로 확인 → 소리는 키보드 소리 단추로 다시 켠다.
9. `확인` → 칸 설정 아래 "3가지: 1) 열기 · powerpnt → 2) 사이트 · https://www.neis.go.kr → 3) 기능 · 소리 끄기·켜기". [35]
10. 아이콘: `아이콘 바꾸기 ▾` → `글자` → ‘수’.
- 작가 B 확인할 것: `+ 동작 더하기`를 눌렀을 때 새 동작의 처음 하는 일(DeckDialogs.cs 330~420줄)과, 컴퓨터 기능 목록이 어떤 모양(펼침 목록인지)인지 소스로 확인해 4~6번 글을 맞춘다.

- 안 되면:
  - "2번째 동작이 비어 있어요. [동작 차례 고치기]에서 채워 주세요." → 그 동작의 대상을 채운다.

**주는 사람**
1. 꾸미기 창 `더보기 ▾` → `내보내기…` [49]
2. "단축키 설정 내보내기" 창 → 왼쪽에서 `바탕 화면` → 파일 이름은 `알림판_단축키_(오늘 날짜).zip` 그대로 → `저장`. [50]
3. 맨 아래 "내보냈어요: …" → 바탕화면에 파일이 생긴다.
4. 이 파일을 메신저·메일에 붙여 보낸다(파일을 풀지 않고 그대로).
5. 보내기 전 확인: `글자 넣기` 칸에 전화번호·주소 같은 개인 정보가 있으면 비우고 내보낸다.
**받는 사람**
6. 받은 파일을 바탕화면에 저장한다(풀지 않는다).
7. 꾸미기 창 `더보기 ▾` → `가져오기…` → "단축키 설정 가져오기" 창 → 바탕 화면 → 파일 → `열기`.
8. 저장 안 한 고친 내용이 있으면 "저장하지 않은 고친 내용이 있어요. 가져오면 지금 16칸이 바뀌고 …" → `예`.
9. 맨 아래 "가져왔어요. 확인하고 [저장하고 보드에 보내기]를 누르세요. (이 컴퓨터에 없는 프로그램 칸은 대상을 고쳐 주세요)"
10. 칸마다 `▶ 눌러 보기`로 확인 → 안 열리는 칸은 4장처럼 대상을 고친다 → `저장하고 보드에 보내기`(10장). [51]
- 같은 방법으로 **내 컴퓨터 지켜 두기**: 컴퓨터를 바꾸거나 학교 컴퓨터가 초기화될 때를 위해 내보낸 파일을 USB 메모리에 보관.
- 안 되면:
  - "알림판 단축키 설정 파일이 아니에요(deck.json 이 없어요)." → 압축을 푼 폴더가 아니라 받은 파일 그대로를 고른다.
  - "가져오지 못했어요: zip 파일이 깨져 있어요" → 다시 받는다.
  - 가져왔는데 보드가 그대로 → `저장하고 보드에 보내기`를 아직 안 눌렀어요.

### 2부 12장 문제 해결 순서도(증상별) (작가 C)
**목표**: 증상을 고르고, 예/아니요를 따라가면 할 일이 나온다.
- 첫머리: **기록 보기** 쓰는 법 — 아이콘 오른쪽 클릭 → `기록 보기` → 메모장이 열림 → Ctrl+End로 맨 아래 → 마지막 몇 줄을 읽는다. 자주 보이는 줄: "포트 열어 봄: …"(보드를 찾아봄), "알림판 확인: … (7인치)"(연결 성공), "알림판 아님(답 없음, 1분 뒤 다시)", "열기: …"(단추 눌림), "열기 실패: … (까닭)". [55]
- 순서도 가 — **아이콘이 회색에서 안 바뀌어요** [52]: 작업 표시줄에 아이콘이 있나? (아니요 → 시작 메뉴 ‘교실알림판 도우미’ → 그래도 없음 → 백신 예외) → 주황인가? (예 → `잠깐 멈추기` 끄기) → 7인치를 UART 단자에 꽂았나? → 데이터 케이블인가(휴대폰 시험)? → 다른 USB 구멍 → 기록에 "포트 열어 봄"이 있나? (아니요 → 컴퓨터가 보드를 못 봐요: 7인치는 CH343 드라이버(장치를 쓰게 해 주는 작은 프로그램)가 필요할 수 있어요 → 정보 담당께) → "알림판 아님(답 없음…)" → 1분 기다림 → 그래도 → 보드 프로그램이 예전 것.
- 순서도 나 — **보드 단추를 눌러도 안 열려요** [53]: 보드 아래 줄이 "컴퓨터와 연결됨"인가? (아니요 → 가) → 꾸미기 창에서 그 칸 `▶ 눌러 보기`가 되나? (아니요 → 대상 고치기, 4·5장) → 단축키 칸인가? (예 → 보낼 창을 먼저 눌러 맨 앞에 / Win 조합은 ‘Win 키도 함께’ 체크) → 여러 동작 칸인가? (예 → 기다리기 1~2초 늘리기) → 보드 아이콘이 흐린가? (예 → 도우미가 꺼져 있어요, 시작 메뉴에서 켜기).
- 순서도 다 — **보드에 새 아이콘이 안 가요** [54]: 저장 단추를 눌렀나? → 맨 아래 글이 무엇인가? → 10장 표의 다섯 갈래로.
- 덧붙임 표(짧게): "설정 파일이 깨져 있어 기본값으로 시작해요(원본은 deck.json.broken)." → 내보낸 파일이 있으면 가져오기(11장). / 아이콘 그림이 틀에서 하얗게 → 8장.
- 1부 15장 표와 겹침 주의: 1부는 표 한 장, 2부는 순서도와 "어디를 보면 되는지".

### 2부 13장 자주 묻는 질문 (작가 C) — 그림 없음
묻고 답하기 12개 안팎, 한 답은 2~3문장. 후보:
1. 관리자 권한이 필요한가요? → 아니요.
2. 인터넷이 꼭 있어야 하나요? → 받을 때, 사이트 열기, 사이트 아이콘 받기 때만.
3. 컴퓨터를 끄면 보드는요? → 보드 화면도 꺼지게 알려 줘요(1부 1장).
4. 칸을 바꿀 때마다 보드를 다시 구워야 하나요? → 아니요. 저장하고 보내기만.
5. 7인치와 4인치를 함께 꽂아도 되나요? → 돼요. 맨 아래 글에 둘 다 보여요(“보드: 7인치 … / 4인치 …”).
6. 다른 컴퓨터로 옮기려면? → 11장 내보내기·가져오기.
7. 학교 컴퓨터가 날마다 처음 상태로 돌아가요 → 도우미와 설정이 지워질 수 있어요. 내보낸 파일을 USB 메모리에 두고 다시 깔아 가져오기.
8. 글자 넣기를 쓰면 복사해 둔 것이 바뀌나요? → 네(복사해서 붙이는 방식).
9. 이름은 몇 자까지? → 한글 6자 안쪽. 이모지·한자·특수 기호는 보드에 안 나와요.
10. 보드 단추가 흐리게 보여요 → 도우미가 꺼져 있다는 뜻. 시작 메뉴에서 켜기.
11. 잠깐 끄고 싶어요 / 완전히 지우고 싶어요 → 1부 14장(`끝내기`, `끄기.bat`).
12. 설명서를 다시 보려면? → 꾸미기 창 `설명서 ▾`(F1) 또는 penedu.web.app/deck.
