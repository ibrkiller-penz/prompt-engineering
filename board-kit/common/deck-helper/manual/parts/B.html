과정 6따라 하기② 사이트(나이스) 넣고 브라우저 고르기

이 과정의 목표6번 칸(파워셸)을 ‘나이스’ 사이트를 여는 칸으로 바꿔요. 그리고 엣지로 열리게 정해요.

걸리는 시간 약 5분 · 필요한 것: 꾸미기 창(과정 4), 인터넷 연결

사이트 열기란칸을 누르면 브라우저(인터넷 창)가 열리고, 정해 둔 주소로 바로 가요.
  1. 누르기 보드 모양에서 6번 칸 파워셸을 눌러요.
    보이는 것 6번 칸에 파란 테두리가 생겨요. 아래 칸 설정 위에 “6번 칸”이 보여요.
  2. 누르기 ‘하는 일’ 줄에서 사이트 열기를 눌러요.
    보이는 것 사이트 열기가 파랗게 바뀌어요. 대상 칸 아래에 “사이트 주소를 넣어요. 예) https://www.naver.com”이 보여요.
    알아 두기대상 칸에는 원래 글(powershell.exe)이 그대로 남아 있어요. 다음 단계에서 지워요.
  3. 누르기 대상 칸을 눌러요 → Ctrl+A를 눌러 남은 글을 모두 고르고 → Delete로 지워요 → https://www.neis.go.kr 를 그대로 쳐요.
    보이는 것 대상 칸에 주소가 들어가요. 맨 앞 https:// 까지 빠짐없이 쳐야 해요.
  4. 누르기 ‘이름’ 칸을 눌러 “파워셸”을 지우고 나이스 라고 쳐요.
    보이는 것 이름 칸 옆에 “보드 칸 아래에 나오는 이름이에요.”가 보여요. 보드 모양 6번 칸 아래 글도 ‘나이스’로 바뀌어요.
  5. 누르기 대상 칸 옆 자세히…를 눌러요.
    보이는 것 “사이트 열기 · 자세한 설정” 창이 열려요. 맨 위에 “어느 브라우저로 열까요?”가 있어요.
    누르기 엣지를 눌러요(크롬을 쓰면 크롬) → 확인.
  6. 보이는 것 창이 닫혀요. 대상 칸 아래 글이 “자세한 설정: 엣지”로 바뀌어요. 자세히… 단추에 작은 점이 찍혀요. 점은 “자세한 설정이 있어요”라는 뜻이에요.
  7. 누르기 아이콘을 바꿔요. 지금은 파워셸 그림이 그대로예요. 칸 설정 왼쪽 아이콘 바꾸기 ▾ → 사이트 아이콘 받기를 눌러요.
    보이는 것 잠깐 뒤 나이스 사이트의 작은 아이콘이 들어가요. 인터넷이 있어야 해요.
    다른 길아이콘 바꾸기 ▾ → 모음에서 고르기… → 위 ‘찾기’ 칸에 나이스 를 쳐요 → 그림을 하나 누르고 고르기. 모음 창은 과정 9에서 자세히 봐요.
  8. 누르기 ▶ 눌러 보기를 눌러요.
    보이는 것 엣지가 열리고 나이스 첫 화면이 보여요. 보드가 없어도 돼요. 확인했으면 엣지 창을 닫아요.
더 짧은 길6번 칸을 누른 뒤, 오른쪽 찾기 칸에 나이스 를 쳐요. 목록의 ‘나이스’ 줄을 6번 칸에 끌어 놓으면 이름·주소·아이콘이 한꺼번에 들어가요. 그다음 5번 단계(브라우저 고르기)만 하면 돼요.
잘 됐는지 확인세 가지를 봐요. ① 6번 칸 이름이 ‘나이스’예요. ② 대상 칸 아래에 “자세한 설정: 엣지”가 보여요. ③ ▶ 눌러 보기로 엣지에서 나이스가 열려요.
이렇게 안 되면
  • 엣지가 아닌 다른 인터넷 창이 열려요 → 고른 브라우저가 이 컴퓨터에 없으면 기본 브라우저(늘 쓰는 인터넷 창)로 열어요. 고장이 아니에요.
  • “먼저 사이트 주소를 넣어 주세요.” 창이 떠요 → 3번 단계(주소 넣기)를 먼저 해요.
  • “사이트 아이콘을 받지 못했어요(인터넷 연결을 확인해 주세요). 글자 아이콘으로 둘게요.” 창이 떠요 → 인터넷을 확인해요. 글자 아이콘 그대로 두어도 되고, 모음에서 골라도 돼요.
  • 이름 옆에 빨간 글 “이 글자는 보드에 나오지 않아요: …”가 보여요 → 글 끝에 나온 글자(특수 기호, 그림 문자 등)를 이름에서 빼요.
  • 나이스가 아닌 엉뚱한 쪽이 열려요 → 주소에 틀린 글자가 있어요. 3번 단계를 다시 해요.
개인정보 지키기업무 사이트의 아이디·비밀번호는 칸에 넣지 마세요. ‘글자 넣기’로 비밀번호를 넣게 만들지도 마세요. 로그인은 늘 직접 해요.

과정 7따라 하기③ ‘화면 캡처’ 단축키 눌러서 넣기

이 과정의 목표2번 칸(Claude)을 ‘화면 캡처’ 칸으로 바꿔요. 보드 단추를 누르면 Win+Shift+S가 눌려요.

걸리는 시간 약 5분 · 필요한 것: 꾸미기 창, 키보드

단축키란여러 키를 함께 눌러 일을 시키는 방법이에요. 예를 들어 Ctrl+C는 복사예요. 보드 단추를 누르면 컴퓨터가 이 키를 대신 눌러 줘요. Win+Shift+S를 누르면 화면 일부를 그림으로 찍는 도구가 나와요.
  1. 누르기 보드 모양에서 2번 칸 Claude를 눌러요 → ‘이름’ 칸의 글을 지우고 화면 캡처 라고 쳐요.
    보이는 것 보드 모양 2번 칸 아래 글이 ‘화면 캡처’로 바뀌어요.
  2. 누르기 ‘하는 일’ 줄에서 단축키 누르기를 눌러요.
    보이는 것 대상 칸 옆 단추가 눌러서 넣기로 바뀌어요.
  3. 지우기 대상 칸에는 원래 글(claude:)이 남아 있어요. 대상 칸을 누르고 Ctrl+A → Delete로 지워요.
    보이는 것 대상 칸 아래에 “[눌러서 넣기]를 누르고 키보드에서 단축키를 그대로 눌러요.”가 보여요.
  4. 누르기 눌러서 넣기를 눌러요.
    보이는 것 “단축키 눌러서 넣기” 창이 열려요. 가운데 큰 칸에 “여기서 키를 누르세요”가 보여요.
  5. 누르기 먼저 마우스로 “Win 키도 함께(윈도 키는 이 창에서 잡히지 않아 여기서 켜요)” 칸을 눌러 체크해요.
    까닭 Win 키는 윈도가 먼저 가져가요. 그래서 이 창은 Win 키를 못 받아요. 체크가 Win 키를 대신해요.
  6. 누르기 키보드에서 Shift를 누른 채로 S를 눌러요.
    보이는 것 가운데에 “Win + Shift + S”가 보여요. 그 아래에 “보드에 넣을 글: #+s”가 보여요.
  7. 누르기 확인을 눌러요.
    보이는 것 창이 닫혀요. 대상 칸에 #+s 가 들어가요. 그 아래에 “누를 키: Win + Shift + S”가 보여요.
  8. 누르기 아이콘을 바꿔요. 아이콘 바꾸기 ▾ → 글자를 눌러요.
    보이는 것 이름 첫 글자 ‘화’로 만든 아이콘이 들어가요. 보드 모양 2번 칸도 바뀌어요.
  9. 누르기 ▶ 눌러 보기를 눌러요.
    보이는 것 꾸미기 창이 잠깐 아래로 내려가요. 화면이 살짝 어두워지고, 위쪽에 캡처 도구가 나와요. 지금은 찍지 않을 거라 Esc를 눌러 취소해요. 1~2초 뒤 꾸미기 창이 다시 올라와요.
기호를 직접 쓰고 싶으면#은 Win, ^는 Ctrl처럼 기호로 직접 쓸 수도 있어요. 기호표는 1부 7장에 있어요.
더 짧은 길찾기 칸에 캡처 를 쳐요. ‘컴퓨터 조작’ 묶음의 ‘화면 캡처’ 줄을 2번 칸에 끌어 놓으면 똑같이 들어가요.
잘 됐는지 확인대상 칸 아래에 “누를 키: Win + Shift + S”가 보여요. 그리고 ▶ 눌러 보기를 누르면 캡처 도구가 나와요.
이렇게 안 되면
  • 키를 잘못 눌렀어요 → 창의 다시를 누르고 다시 눌러요.
  • “이 키는 넣을 수 없어요. 다른 키를 눌러 주세요.”가 보여요 → 한/영 키, 한자 키 같은 키는 넣을 수 없어요. 다른 키를 눌러요.
  • 가운데에 “Shift + S”만 보여요 → 5번 단계의 체크를 안 했어요. 체크하면 바로 “Win + Shift + S”로 바뀌어요.
  • 창을 열자마자 가운데에 이상한 글이 보여요 → 3번 단계에서 남은 글을 안 지웠어요. 다시를 누르고 5~6번 단계를 해요.
  • 키보드로 창을 닫고 싶어요 → Ctrl+Enter는 확인, Shift+Esc는 취소예요. 이 창에서 Enter나 Esc만 누르면 그 키가 단축키로 들어가요.
  • 보드 단추로 다른 단축키를 눌렀는데 아무 일이 없어요 → 단축키는 맨 앞에 있는 창에 들어가요. 예를 들어 한글에 Ctrl+S(저장)를 보내려면, 한글 창을 먼저 한 번 눌러 둬요. 화면 캡처는 어느 창에서나 돼요.

과정 8따라 하기④ ‘수업 시작’ 여러 동작 만들기

이 과정의 목표1번 칸 하나로 세 가지 일을 차례대로 하게 만들어요. 파워포인트 열기 → 2초 기다리기 → 나이스 열기 → 1초 기다리기 → 소리 끄기예요.

걸리는 시간 약 10분 · 필요한 것: 꾸미기 창, 파워포인트가 깔린 컴퓨터

  1. 누르기 보드 모양에서 1번 칸 탐색기를 눌러요 → ‘이름’ 칸의 글을 지우고 수업 시작 이라고 쳐요.
    보이는 것 보드 모양 1번 칸 아래 글이 ‘수업 시작’으로 바뀌어요.
  2. 누르기 ‘하는 일’ 줄에서 여러 동작을 눌러요.
    보이는 것 “여러 동작 · 수업 시작” 창이 저절로 열려요. 뒤쪽 칸 설정에는 동작 차례 고치기… 단추가 생겨요. 나중에 이 창을 다시 열 때 이 단추를 눌러요.
  3. 읽기 창 위쪽 목록을 봐요.
    보이는 것 1번 줄에 “열기 · explorer”가 이미 들어 있어요. 이 칸이 원래 하던 일(탐색기 열기)이 첫 동작으로 옮겨진 거예요.
  4. 누르기 1번 줄을 눌러요. 아래 ‘고른 동작’에서 프로그램 열기가 파란지 봐요 → 대상 칸의 글을 지우고 powerpnt 를 그대로 쳐요(파워포인트를 여는 이름이에요) → ‘다음 동작까지 기다리기’ 줄에서 2초를 눌러요.
    보이는 것 1번 줄이 “열기 · powerpnt”로 바뀌어요.
  5. 누르기 + 동작 더하기를 눌러요.
    보이는 것 작은 메뉴가 펼쳐져요. ‘프로그램 열기 · 사이트 열기 · 단축키 누르기 · 글자 넣기 · 컴퓨터 기능’ 다섯 줄이에요.
    누르기 사이트 열기를 눌러요.
    보이는 것 1번 줄 바로 아래에 2번 줄 “사이트 · (비어 있어요)”가 생겨요. 아직 비어 있어서 주황 글로 보여요.
    누르기 아래 대상 칸에 https://www.neis.go.kr 를 그대로 쳐요 → 오른쪽 자세히… → 엣지 → 확인. 기다리기는 처음부터 1초로 골라져 있어요. 그대로 둬요.
  6. 누르기 2번 줄이 골라진 채로 + 동작 더하기 → 컴퓨터 기능을 눌러요.
    보이는 것 3번 줄 “기능 · 바탕화면 보기”가 생겨요. 아래 대상 칸 자리에 “바탕화면 보기”라고 적힌 펼침 단추가 보여요.
    누르기 그 펼침 단추를 눌러요 → 목록에서 소리 끄기·켜기를 눌러요.
    보이는 것 3번 줄이 “기능 · 소리 끄기·켜기”로 바뀌어요.
  7. 읽기 목록을 다시 봐요. 1번 줄 오른쪽에 “↓ 2초 뒤”, 2번 줄 오른쪽에 “↓ 1초 뒤”가 보여요.
    • 차례가 틀렸으면 → 줄을 누르고 위로나 아래로.
    • 잘못 넣은 줄이 있으면 → 그 줄을 누르고 빨간 빼기.
  8. 누르기 ▶ 차례대로 해 보기를 눌러요.
    보이는 것 파워포인트가 열려요 → 2초 뒤 엣지에서 나이스가 열려요 → 1초 뒤 소리가 꺼져요.
    소리를 다시 켜려면 키보드의 소리 끄기 단추를 누르거나, 작업 표시줄(화면 맨 아래 막대) 오른쪽의 스피커 그림을 눌러 켜요(화면에 따라 조금 다를 수 있어요). 파워포인트와 엣지 창은 닫아요.
  9. 누르기 창 아래 확인을 눌러요.
    보이는 것 창이 닫혀요. 칸 설정 아래에 “3가지: 1) 열기 · powerpnt → 2) 사이트 · https://www.neis.go.kr → 3) 기능 · 소리 끄기·켜기”가 보여요.
  10. 누르기 아이콘을 바꿔요. 아이콘 바꾸기 ▾ → 글자.
    보이는 것 ‘수’ 글자 아이콘이 들어가요. 보드 모양 1번 칸도 바뀌어요.
잘 됐는지 확인칸 설정 아래에 “3가지: …” 요약이 보여요. 그리고 ▶ 눌러 보기를 누르면 세 가지가 차례대로 일어나요.
이렇게 안 되면
  • “2번째 동작이 비어 있어요. [동작 차례 고치기]에서 채워 주세요.”가 떠요 → 동작 차례 고치기…를 눌러 창을 다시 열어요. 주황 글로 보이는 줄을 눌러 대상을 채워요.
  • 나이스가 먼저 뜨고 파워포인트가 그 위를 가려요 → 파워포인트가 뜨는 데 시간이 더 걸려서 그래요. 1번 줄의 기다리기를 2초에서 3초로 바꿔요.
  • “열지 못했어요: …”가 떠요 → 이 컴퓨터에 파워포인트가 없거나 다른 자리에 있어요. 1번 줄을 누르고 찾아보기…로 프로그램을 골라요.
  • + 동작 더하기가 흐려서 안 눌려요 → 한 칸에는 12가지까지만 넣을 수 있어요.
  • 창에서 취소를 눌렀어요 → 그 창에서 고친 것은 모두 사라져요. 동작 차례 고치기…로 다시 열어 4번 단계부터 해요.

과정 9따라 하기⑤ 내 그림·인공지능 아이콘 넣기

이 과정의 목표3번 칸(제미나이)의 아이콘을 내가 만든 그림으로 바꿔요. 그림은 인공지능으로 만들어요.

걸리는 시간 약 10분 · 필요한 것: 꾸미기 창, 그림을 만들어 주는 인공지능(제미나이·캔바 등)

  1. 누르기 보드 모양에서 3번 칸 제미나이를 눌러요.
    보이는 것 칸 설정 왼쪽에 큰 아이콘 상자가 있어요. 그 아래에 아이콘 바꾸기 ▾, 또 그 아래에 “지금: 기본 그림”이 보여요.
  2. 그림 만들기 1부 10장의 “인공지능에게 줄 말”을 그대로 복사해요 → 그림 인공지능(제미나이·캔바 등)에 붙여 넣어요 → [ ] 안의 글만 바꿔요(예: [출석부], [밝은 초록]).
    보이는 것 인공지능이 그림을 만들어 줘요. 받은 그림을 바탕화면에 저장해요. 파일 이름 끝이 .png 면 좋아요.
  3. 끌어 놓기 탐색기를 열고 왼쪽에서 ‘바탕 화면’을 눌러요. 탐색기 창과 꾸미기 창이 함께 보이게 놓아요 → 그림 파일을 마우스로 누른 채, 꾸미기 창 보드 모양의 3번 칸 위로 끌어서 놓아요.
    보이는 것 “이 그림을 3번 칸 아이콘으로 넣을까요?” 물음 창이 떠요.
  4. 누르기 그림에 맞게 골라요.
    • 가운데 기호 하나만 있는 그림 → 예(틀에 넣기). 다른 칸과 같은 어두운 테두리를 씌워 줘요.
    • 테두리와 바탕까지 다 그린 그림 → 아니요(그대로).
    • 넣지 않으려면 → 취소.
  5. 보이는 것 보드 모양 3번 칸의 그림이 바뀌어요. 아이콘 상자 아래 글이 “지금: 그림 파일”로 바뀌어요(‘아니요’를 골랐으면 “지금: 그림 그대로”). 맨 아래 왼쪽에 “3번 칸 아이콘을 바꿨어요.”가 나와요.

다른 길 ① 메뉴로 그림 고르기

아이콘 바꾸기 ▾ → 그림 파일…을 눌러요. “아이콘으로 쓸 그림 고르기” 창이 열려요. 왼쪽에서 ‘바탕 화면’을 누르고 → 그림 파일을 누르고 → 열기. “이 그림을 어떻게 넣을까요?” 물음이 뜨면 4번 단계처럼 골라요.

다른 길 ② 모음 205개에서 고르기

아이콘 바꾸기 ▾ → 모음에서 고르기…를 눌러요. “아이콘 모음에서 고르기” 창이 열려요.

  • 위쪽 ‘묶음’에서 종류를 고르거나, ‘찾기’ 칸에 이름을 쳐서 찾아요.
  • 그림 하나를 누르고 고르기를 눌러요. 그림을 두 번 눌러도 돼요.
  • 아래 “이름·하는 일도 같이 넣기(빈 칸이면 늘 넣음)”는 끈 채로 두세요. 그래야 아이콘만 바뀌어요.
잘 됐는지 확인보드 모양 3번 칸 그림이 내 그림으로 바뀌었어요. 아이콘 상자 아래에 “지금: 그림 파일” 또는 “지금: 그림 그대로”가 보여요.
이렇게 안 되면
  • “이 그림은 열 수 없어요.”가 떠요 → 그림을 이름 끝이 .png 나 .jpg 인 파일로 다시 저장해요.
  • 그림 둘레에 하얀 네모가 보여요 → 그림 바탕이 투명하지 않아서 그래요. 인공지능에게 “배경을 투명하게”를 다시 부탁하거나, 캔바의 ‘배경 제거’를 써요.
  • 보드 칸에서 너무 작거나 흐려 보여요 → 기호 하나만, 굵은 선으로 다시 만들어요. 알맞은 크기와 모양은 1부 10장 표에 있어요.
  • 끌어 놓았는데 물음 창이 안 떠요 → 그림을 칸 바로 위에서 놓았는지 봐요. 안 되면 ‘다른 길 ①’로 넣어요.
그림 쓸 때 지킬 것회사 로고를 그대로 베끼지 마세요. 그 회사 색의 글자 한두 개로 만들면 돼요.

과정 10한 번에 채우기와 아이콘 모양

이 과정의 목표16칸을 묶음으로 한 번에 채워 보고, 아이콘 모양(테마)을 바꿔 봐요. 끝나면 과정 5~9에서 꾸민 칸으로 되돌려요.

걸리는 시간 약 5분 · 필요한 것: 꾸미기 창

먼저 읽어 주세요한 번에 채우기를 하면 지금 16칸이 모두 지워져요. 과정 5~9에서 꾸민 칸도 지워져요. 그래서 1번 단계에서 지금 칸을 파일로 먼저 지켜 둬요.
  1. 지켜 두기 위 띠의 더보기 ▾ → 내보내기…를 눌러요.
    보이는 것 “단축키 설정 내보내기” 창이 열려요. 파일 이름은 ‘알림판_단축키_’ 뒤에 오늘 날짜 네 자리가 붙어 있어요.
    누르기 왼쪽에서 ‘바탕 화면’을 눌러요 → 이름은 그대로 두고 저장.
    보이는 것 맨 아래 왼쪽에 “내보냈어요: …”가 나와요. 바탕화면에 압축 파일(여러 파일을 하나로 묶은 파일)이 하나 생겨요. 내보내기는 과정 12에서 더 자세히 봐요.
  2. 누르기 위 띠의 한 번에 채우기 ▾를 눌러요.
    보이는 것 메뉴 네 줄이 펼쳐져요.
  3. 누르기 수업용 (한글·PPT·발표 넘기기·타이머·소리)를 눌러요.
    보이는 것 “한 번에 채우기” 물음 창이 떠요. “16칸을 아래처럼 바꿀까요? (지금 칸은 지워져요. 저장을 눌러야 보드로 가요)” 아래에 들어갈 칸 이름이 줄지어 보여요.
    누르기 칸 이름을 읽어 보고 예.
  4. 보이는 것 보드 모양 16칸이 수업용으로 바뀌어요. 맨 아래에 “16칸을 채웠어요. …”가 나와요.
    수업용은 모든 칸에 대상이 들어 있어요. 다른 묶음에는 주소가 빈 칸(예: ‘학교 누리집’)이 있을 수 있어요. 그런 칸은 눌러서 대상 칸에 주소를 넣어요. 빈 칸인지 모르겠으면 ▶ 눌러 보기를 눌러 봐요. 비어 있으면 “사이트 주소를 넣어 주세요.” 같은 창이 떠요.
  5. 누르기 위 띠의 아이콘 모양: 기본(다크) ▾를 눌러요 → 여섯 가지(기본(다크) · 따뜻함 · 남색밤 · 밝은종이 · 고대비 · 숲초록) 가운데 따뜻함을 눌러요.
    보이는 것 16칸의 아이콘 색이 바뀌어요. 맨 아래에 “모음 아이콘 16개를 '따뜻함' 모양으로 바꿨어요. 저장하면 보드로 가요.”가 나와요. 위 띠 단추 글은 “아이콘 모양: 따뜻함”이 돼요.
  6. 되돌리기 이제 과정 5~9에서 꾸민 칸으로 돌아가요. 더보기 ▾ → 가져오기…를 눌러요.
    보이는 것 “단축키 설정 가져오기” 창이 열려요.
    누르기 왼쪽 ‘바탕 화면’ → 1번 단계에서 만든 파일 → 열기.
    보이는 것 “저장하지 않은 고친 내용이 있어요. 가져오면 지금 16칸이 바뀌고 고친 내용은 사라져요. 가져올까요?”가 떠요 → 예.
    보이는 것 16칸이 1번 단계 때 모습으로 돌아와요. 맨 아래에 “가져왔어요. …”가 나와요. 아이콘 모양도 처음대로 하려면 아이콘 모양: 따뜻함 ▾에서 기본(다크)를 골라요.
닫기로 되돌리지 마세요닫기 → 아니요(저장 안 함)로 닫으면 한 번에 채우기만 사라지는 게 아니에요. 아직 저장하지 않은 과정 5~9의 칸도 모두 사라져요. 그래서 가져오기로 되돌려요.
잘 됐는지 확인3번 단계 뒤 보드 모양 16칸이 수업용 이름으로 바뀌었어요. 5번 단계 뒤 위 띠 단추가 “아이콘 모양: 따뜻함”이에요. 6번 단계 뒤 16번 ‘한글’, 6번 ‘나이스’, 2번 ‘화면 캡처’, 1번 ‘수업 시작’, 3번 내 그림이 다시 보여요.
이렇게 안 되면
  • 이 컴퓨터에 깔린 프로그램으로를 했는데 원하는 프로그램이 빠졌어요 → 이 컴퓨터에 깔린 것만 넣어요. 빠진 칸은 과정 5처럼 끌어다 넣어요.
  • 아이콘 모양을 바꿔도 그대로인 칸이 있어요 → 모음에서 고른 아이콘만 바뀌어요. 내 그림, 글자 아이콘, 기본 그림은 그대로예요.
  • 묶음마다 어떤 칸이 들어가는지 미리 알고 싶어요 → 1부 5장 표를 봐요.
  • 1번 단계를 안 하고 채워 버렸어요 → 아직 저장하지 않았다면 닫기 → 아니요로 닫으면 마지막으로 저장한 모습으로 돌아가요. 다만 과정 5~9에서 고친 칸은 다시 해야 해요.
