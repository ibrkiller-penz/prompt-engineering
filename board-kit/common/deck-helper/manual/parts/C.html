2부 11다른 선생님께 나누기

이 장의 목표 꾸민 16칸을 파일 하나로 만들어 옆 반 선생님께 줘요. 받은 선생님은 그 파일을 가져와 보드로 보내요.

걸리는 시간 약 5분 · 필요한 것: 내 꾸미기 창, 파일을 보낼 메신저나 메일

주는 사람

보내기 전에 살펴요‘글자 넣기’ 칸에 전화번호나 주소 같은 개인 정보가 있나요? 있으면 그 칸을 먼저 비우고 내보내요. 파일 안에 그 글이 그대로 들어가요.
  1. 누르기 꾸미기 창 위 띠의 더보기 ▾를 눌러요. → 보이는 것 메뉴가 펼쳐져요. 내보내기…를 눌러요.
  2. 보이는 것 “단축키 설정 내보내기” 창이 열려요. 누르기 왼쪽 목록에서 바탕 화면을 눌러요.
  3. 보이는 것 파일 이름 칸에 알림판_단축키_1027.zip처럼 오늘 날짜가 붙은 이름이 이미 들어 있어요. 그대로 두고 저장을 눌러요.
  4. 보이는 것 꾸미기 창 맨 아래에 “내보냈어요: …”가 잠깐 보여요. 바탕화면에 그 이름의 파일이 생겨요.
  5. 누르기 이 파일을 메신저나 메일에 붙여 보내요. 파일을 풀지 말고 그대로 보내요.

받는 사람

  1. 누르기 받은 파일을 바탕화면에 저장해요. 이 파일은 압축 파일(여러 파일을 하나로 묶은 것, 이름 끝이 .zip)이에요. 풀지 마세요.
  2. 누르기 꾸미기 창 더보기 ▾ → 가져오기…를 눌러요.
  3. 보이는 것 “단축키 설정 가져오기” 창이 열려요. 내보내기 창과 모양이 비슷해요. 누르기 바탕 화면 → 받은 파일 → 열기.
  4. 보이는 것 저장하지 않은 고친 내용이 있으면 “저장하지 않은 고친 내용이 있어요. 가져오면 지금 16칸이 바뀌고 고친 내용은 사라져요. 가져올까요?”라고 물어요. 괜찮으면 예.
  5. 보이는 것 16칸이 받은 대로 바뀌어요. 맨 아래에 “가져왔어요. 확인하고 [저장하고 보드에 보내기]를 누르세요. (이 컴퓨터에 없는 프로그램 칸은 대상을 고쳐 주세요)”가 보여요.
  6. 누르기 칸을 하나씩 골라 ▶ 눌러 보기를 눌러요. 열리지 않는 칸은 2부 4장처럼 대상(무엇을 열지)을 고쳐요. 보낸 컴퓨터와 프로그램 자리가 다를 수 있어서 그래요.
  7. 누르기 다 됐으면 저장하고 보드에 보내기를 눌러요(2부 10장).
잘 됐는지 확인받은 선생님의 꾸미기 창 16칸이 보낸 선생님 것과 같아요. 저장하고 보낸 뒤 보드 아래 줄에 “새 단축키를 받았습니다”가 보여요.
이렇게 안 되면
  • “알림판 단축키 설정 파일이 아니에요(deck.json 이 없어요).” → 압축을 푼 폴더를 골랐어요. 받은 파일을 그대로 골라요.
  • “가져오지 못했어요: zip 파일이 깨져 있어요” → 파일이 받는 중에 망가졌어요. 다시 받아요.
  • 가져왔는데 보드는 그대로예요 → 아직 저장하고 보드에 보내기를 누르지 않았어요.

2부 12문제 해결 순서도

이 장의 목표 증상을 고르고, 물음에 ‘예/아니요’로 따라가요. 끝에 할 일이 나와요.

순서도에서 마름모는 물음, 둥근 네모는 할 일이에요. 초록 화살표는 ‘예’, 빨간 화살표는 ‘아니요’예요. 1부 15장 표는 짧은 답이고, 이 장은 어디를 보면 되는지 차례로 알려 줘요.

먼저, 기록 보기

탭덱은 하는 일을 날마다 적어 둬요. 이것을 기록이라고 해요. 막히면 기록의 맨 아래 줄을 보면 까닭을 알 수 있어요.

  1. 누르기 알림 영역의 알림판 아이콘을 오른쪽 클릭 → 기록 보기.
  2. 보이는 것 메모장이 열려요. 한 줄에 하나씩, 앞에 날짜와 시각이 있어요.
  3. 누르기 Ctrl+End를 눌러 맨 아래로 가요. 마지막 몇 줄을 읽어요.
기록에 보이는 글(앞부분)뜻
포트 열어 봄: …보드를 찾아봤어요. 컴퓨터가 보드를 보고 있어요.

‘…’ 자리의 글은 컴퓨터마다 달라요.

가. 알림판 아이콘이 회색에서 안 바뀌어요

  1. 작업 표시줄(화면 맨 아래 막대)에 알림판 아이콘이 없어요 → 시작 메뉴에서 ‘탭덱’을 눌러 켜요. 그래도 없으면 학교 백신(나쁜 프로그램을 막는 프로그램)이 막은 거예요. 예외 목록에 넣어 달라고 해요.
  2. 아이콘이 주황이에요 → 잠깐 멈춘 상태예요. 아이콘 오른쪽 클릭 → 잠깐 멈추기(보드 굽기 전에)를 다시 눌러 꺼요.
  3. 7인치는 ‘UART’라고 적힌 단자(선을 꽂는 구멍)에 꽂았나요? 아니면 바꿔 꽂아요.
  4. 데이터 케이블인가요? 그 선으로 휴대폰을 컴퓨터에 꽂아 사진이 보이면 데이터 케이블이에요. 충전만 되는 선이면 바꿔요.
  5. 컴퓨터의 다른 USB 구멍에 꽂아 봐요.
  6. 기록에 “포트 열어 봄”이 없어요 → 컴퓨터가 보드를 못 봐요. 7인치는 CH343 드라이버(장치를 쓰게 해 주는 작은 프로그램)가 필요할 수 있어요. 학교 정보 담당 선생님께 부탁해요.
  7. 기록에 “알림판 아님(답 없음…)”이 있어요 → 1분 기다려요. 그래도 안 되면 보드 프로그램이 예전 것이에요. 보드 설명서를 보고 새로 구워요.

나. 보드 단추를 눌러도 안 열려요

  1. 보드 아이콘이 모두 흐리게 보여요 → 탭덱이 꺼져 있어요. 시작 메뉴에서 ‘탭덱’을 눌러 켜요.
  2. 보드 아래 줄이 “컴퓨터와 연결됨”이 아니에요 → 순서도 가로 가요.
  3. 꾸미기 창에서 그 칸을 골라 ▶ 눌러 보기를 눌러요. 여기서도 안 열려요 → 대상이 틀렸어요. 2부 4장·5장처럼 대상을 고쳐요.
  4. 단축키 칸이에요 → 단축키는 맨 앞에 있는 창에 들어가요. 보낼 프로그램 창을 먼저 한 번 눌러 두고 보드 단추를 눌러요. Win 키가 들어가면 ‘Win 키도 함께’를 켰는지 봐요(2부 6장).
  5. 여러 동작 칸에서 일부만 돼요 → 앞 프로그램이 뜨기 전에 다음 동작이 와서 그래요. ‘다음 동작까지 기다리기’를 1~2초 늘려요(2부 7장).

다. 보드에 새 아이콘이 안 가요

  1. 저장하고 보드에 보내기를 눌렀나요? 아니면 눌러요.
  2. 눌렀어요 → 꾸미기 창 맨 아래 글을 읽어요. 2부 10장 ‘이렇게 안 되면’ 표에서 같은 글을 찾아요.

2부 13자주 묻는 질문

관리자 권한이 필요한가요?

아니요. 보통 선생님 계정으로 깔고 쓸 수 있어요.

인터넷이 꼭 있어야 하나요?

세 가지 때만 있으면 돼요. 탭덱을 받을 때, ‘사이트 열기’ 칸을 누를 때, ‘사이트 아이콘 받기’를 할 때예요. 나머지는 인터넷 없이 돼요.

컴퓨터를 끄면 보드는 어떻게 되나요?

탭덱이 보드에 알려 줘요. 그러면 보드도 화면을 꺼요(1부 1장).

칸을 바꿀 때마다 보드를 다시 구워야 하나요?

아니요. 저장하고 보드에 보내기만 누르면 돼요. 굽기는 보드 프로그램이 예전 것일 때만 해요.

7인치와 4인치를 함께 꽂아도 되나요?

돼요. 두 보드에 같은 16칸이 가요. 꾸미기 창 맨 아래 글에 “보드: 7인치 … / 4인치 …”처럼 둘 다 보여요.

다른 컴퓨터로 옮기고 싶어요.

내 컴퓨터에서 내보내고, 새 컴퓨터에서 탭덱을 깐 뒤 가져와요(2부 11장).

학교 컴퓨터가 켤 때마다 처음 상태로 돌아가요.

탭덱과 꾸민 설정이 지워질 수 있어요. 내보낸 파일을 USB 메모리에 넣어 두세요. 지워지면 탭덱을 다시 깔고 그 파일을 가져와요.

‘글자 넣기’를 쓰면 복사해 둔 것이 바뀌나요?

네. 글자를 복사해서 붙여 넣는 방식이라, 원래 복사해 둔 내용이 바뀌어요.

칸 이름은 몇 자까지 되나요?

한글 6자 안쪽이 좋아요. 더 길면 끝이 잘려요. 이모지·한자·특수 기호는 보드에 나오지 않아요.

보드 단추가 흐리게 보여요.

컴퓨터의 탭덱이 꺼져 있다는 뜻이에요. 시작 메뉴에서 ‘탭덱’을 눌러 켜요.

잠깐 끄고 싶어요. 아예 지우고 싶어요.

1부 14장을 봐요. 잠깐 끄기는 아이콘 오른쪽 클릭 → 끝내기예요. 지우기는 받은 꾸러미의 끄기.bat을 두 번 클릭해요.

설명서를 다시 보고 싶어요.

꾸미기 창 위 띠의 설명서 ▾ → 설명서 보기(그림과 따라 하기)를 눌러요. F1을 눌러도 돼요. 인터넷에서는 penedu.web.app/deck 에 있어요.
