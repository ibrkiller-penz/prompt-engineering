# 설계서: '단축키 꾸미기' 창 — 스트림덱처럼 (개발팀용 최종본)

작성 2026-10-26 · 팀장. 디자인팀 `설계_디자인팀.md`(겉모습)와 UI팀 `설계_UI팀.md`(배치·동작)를 합치고, 글꼴 담당 보고(`exe\DeckFonts.cs`, `exe\fonts\LICENSE_SCDream.txt`)와 지금 소스(`exe\DeckForm.cs`, `DeckHelper.cs`, `DeckLibrary.cs`, `DeckConfig.cs`, `DeckIcons.cs`)를 확인해서 정했다.
**두 팀 문서와 이 문서가 다르면 이 문서를 따른다.** `설계_단축키꾸미기.md` 7장(옛 창 배치)은 이 문서로 바뀐다. 통신·파일 형식(그 문서 2~6장)은 그대로다.

사용자 요구(그대로): ① 스트림덱 앱처럼(어두운 화면, 가운데 큰 보드 미리보기·둥근 칸, 오른쪽 동작 목록(묶음 접기·찾기·끌어 놓기), 아래 속성 창) — 그림·로고는 베끼지 않고 배치와 느낌만 ② 글꼴은 에스코어 드림 3·4·5 ③ 7인치(2×8)·4인치(4×4) 모양 바꿔 보기.

| 작은 글 | `DeckFonts.Light` | 8.5 | 도움말·경고 한 줄, 개수 알약, 꼬리표, 보드 아래 설명, 처음 도움말 띠 |
| 칸 번호 | `Light` | 7.5 | 칸 왼쪽 위 1~16 |

규칙
1. 글꼴은 **`DeckFonts` 에서만** 얻는다. 받은 Font 는 **Dispose 하지 않는다**(캐시됨). 창 `Font = DeckFonts.Regular(9.5f)` 로 두면 TextBox·메뉴가 물려받는다.
2. 직접 그리는 글자는 모두 `Theme.Text(g, 글, 글꼴, 색, 사각형, 맞춤)` 하나로: 안에서 `g.TextRenderingHint = TextRenderingHint.AntiAliasGridFit` + `StringFormat`(가운데/왼쪽, `StringTrimming.EllipsisCharacter`, 한 줄이면 `NoWrap`). `TextRenderer.DrawText` 는 쓰지 않는다.
3. 글꼴에 없을 수 있는 기호(▶ ▾ ▸ ● ✓ ⇄)는 **글자로 쓰지 않고 그린다**(`Theme.Triangle(g, 사각형, 방향, 붓)`, 점은 `FillEllipse`). 화면 글에 쓰는 기호는 `·` 하나만(KS X 1001 안). 미리보기 그림에서 `·` 가 네모로 나오면 ` - ` 로 바꾼다.
4. 묻는 법은 이미 끝남(`DeckFonts.cs`, `build_exe.ps1`). **.otf 를 .ttf 로 바꾸거나 글자를 줄이지 않는다.** 못 읽으면 `DeckFonts` 가 맑은 고딕으로 대신하고 창은 그대로 뜬다.
5. 사용 조건 지키기: `build_exe.ps1` 에 `/resource:fonts\LICENSE_SCDream.txt,deck.fontlicense` 한 줄을 더하고, 더보기 → **글꼴 안내** 에서 그 글(UTF-8)을 읽기 전용 창(어두운 여러 줄 TextBox, 600×420, [닫기])으로 보여 준다. 첫 줄은 `글꼴: 에스코어 드림 (S-Core)`.

## 7. 보드 미리보기 `BoardView` (`DeckBoardView.cs`)

### 7-1. 배치 계산 (`Layout()` — 크기·모양·도움말 띠가 바뀔 때)

| | 7인치 (2줄×8칸) | 4인치 (4줄×4칸) |
|---|---|---|
| 몸체 안쪽 여백 `pad` | 24 | 16 |
| 칸 사이 `gap` | 12 | 10 |
| 이름 줄 `nameH` (칸 아래) | 20, Medium 9 | 16, Medium 8 |
| 아이콘 그림 | `min(72, 칸 − 16)` 를 칸 가운데 | 같음 |

```
쓸 수 있는 곳: 왼쪽·오른쪽 24, 위 16 + (도움말 띠 보이면 40), 아래 32(보드 설명 줄)
칸 = floor(min( (쓸폭 − 2·pad − (cols−1)·gap) / cols ,
                (쓸높이 − 2·pad − rows·nameH − (rows−1)·gap) / rows ))
칸 = clamp(칸, 40, 112)
몸체 = (2·pad + cols·칸 + (cols−1)·gap)  ×  (2·pad + rows·(칸+nameH) + (rows−1)·gap), 쓸 수 있는 곳 가운데
```
기준 창(940×404)에서: 7인치 칸 약 95(그림 72 그대로), 4인치 칸 약 56(그림 40). 창을 키우면 커진다.
- 칸 사각형 `CellRect(i)`, 이름 줄 `NameRect(i)`, 맞히기 `HitCell(Point)`(칸과 그 이름 줄까지 그 칸) — 모두 모양을 따른다.
- 그림은 `칸 ≥ 88` 이면 72 를 1:1 로(흐림 없음), 작으면 `HighQualityBicubic` 으로 줄여서. 줄인 그림은 `(칸 번호, Tile 참조, 크기)` 로 캐시하고 Tile 이 바뀌면 다시.

- `Changed()`·`MarkDirty()` → `dirty=true` → `UpdateDirty()`: 창 제목 `● 단축키 꾸미기 — 교실 알림판`(저장하면 ● 빠짐), 위 띠 `저장 안 함`, 저장 단추 `Dot`.
- 7인치/4인치·찾기·묶음 펴기·도움말 닫기는 바뀜이 **아니다**.
- 닫을 때 지금 질문 그대로(`저장하지 않은 변경이 있어요. 저장할까요?` 예/아니요/취소).
- `DeckPrefs`: 파일 `Path.Combine(Helper.DataDir, "deckform.ini")`(deck.json 과 따로, UTF-8, `이름=값` 줄). 값: `shape=7|4`, `hint=0|1`, `open=묶음1|묶음2…`, `theme=0~5`(지금 static `libTheme` 시작값). 읽기·쓰기 모두 try/catch(실패해도 창은 뜸). 쓰기는 값이 바뀔 때와 창 닫을 때.
- 처음 모양: ① `host.DeckStatus()` 에 `7인치`/`4인치` 중 하나만 있으면 그것 ② 아니면 `shape` 값 ③ 아니면 7.
- 처음 도움말 띠: `hint` 가 1 이 아니거나, 16칸이 모두 빈 칸이면 보임. 빈 칸 문장은 `비어 있어요. 위의 [한 번에 채우기]로 시작해도 좋아요.` [알겠어요] → `hint=1`, 띠 숨기고 `BoardView.Layout()`.

### 16-1. 지킬 것

### 16-3. DeckPreview.cs
```csharp
static class DeckPreview
{
    public static int Run(string outDir)
    {
        var log = new StringBuilder();
        try
        {
            Application.EnableVisualStyles();
            var h = new Helper(Path.Combine(outDir, "_자료"));
            var f = new DeckForm(h);

            f.SelectCell(10); Pump(f);              Shot(f, outDir, "02_칸고름_7인치.png", log);

            f.SetShape(7); f.PreviewFind("소리"); Pump(f); Shot(f, outDir, "04_찾기_소리.png", log);
            f.PreviewFind(""); f.PreviewEmpty(15); f.SelectCell(15); Pump(f); Shot(f, outDir, "05_빈칸.png", log);
            f.ClientSize = new Size(1080, 600); Pump(f); Shot(f, outDir, "06_가장작은창.png", log);
            f.PreviewDiscard();                            // dirty=false (닫을 때 묻지 않게)
            f.Close(); f.Dispose();
            log.AppendLine("글꼴 에스코어 드림 읽음: " + DeckFonts.Loaded);
            File.WriteAllText(Path.Combine(outDir, "preview.txt"), log.ToString(), new UTF8Encoding(false));
            return 0;
        }
        catch (Exception ex)
        {
            log.AppendLine("실패: " + ex);
            try { File.WriteAllText(Path.Combine(outDir, "preview.txt"), log.ToString(), new UTF8Encoding(false)); } catch { }
            return 1;
        }
    }
    static void Pump(Form f) { for (int i = 0; i < 5; i++) Application.DoEvents(); f.PerformLayout(); f.Refresh(); Application.DoEvents(); }
    static void Shot(Form f, string dir, string name, StringBuilder log)
    {
        using (var whole = new Bitmap(f.Width, f.Height))
        {
            f.DrawToBitmap(whole, new Rectangle(0, 0, f.Width, f.Height));
            Point c = f.PointToScreen(Point.Empty);
            var r = new Rectangle(c.X - f.Left, c.Y - f.Top, f.ClientSize.Width, f.ClientSize.Height);   // 제목 띠 빼고 안쪽만
            using (var inner = whole.Clone(r, whole.PixelFormat)) inner.Save(Path.Combine(dir, name), System.Drawing.Imaging.ImageFormat.Png);
        }
        log.AppendLine(name);
    }
}
```
