# 단축키 꾸미기 창 — 시각 설계 (디자인팀)

> 대상: `exe/DeckForm.cs` 의 '단축키 꾸미기' 창. 참고: 스트림덱 앱의 **배치와 느낌**만(어두운 화면 · 가운데 장치 · 오른쪽 동작 목록 · 아래 속성 창). 그림·로고는 쓰지 않는다.
> 지킬 것: C# 5 문법, WinForms 직접 그리기(OwnerDraw/OnPaint), 통신 줄 형식은 손대지 않음, 지금 있는 기능은 모두 남김.
> 기준 창 크기 **1180 × 720**(ClientSize), 최소 **1000 × 640**.

## 3. 둥근 모서리 반지름

| 대상 | 반지름 |
|---|---|
| 보드 몸체 | 20px |
| 칸(단추) 88px 일 때 | 14px (작아지면 칸 크기 × 0.16) — 타일 자체 반지름(72px에 약 17px)과 비슷하게 |
| 패널 안 카드(속성 창의 아이콘 상자) | 12px |
| 단추·입력칸·찾기 상자 | 6px |
| 동작 목록 줄(마우스 위/고른 줄 바탕) | 6px |
| 작은 알약(7인치/4인치 바꾸기, 묶음 개수 표시) | 높이의 절반(완전 둥긂) |
| 스크롤 손잡이 | 너비의 절반 |

공통 도우미(C# 5):
```csharp
static GraphicsPath Round(RectangleF r, float rad)
{
    var p = new GraphicsPath(); float d = rad * 2;
    p.AddArc(r.X, r.Y, d, d, 180, 90); p.AddArc(r.Right - d, r.Y, d, d, 270, 90);
    p.AddArc(r.Right - d, r.Bottom - d, d, d, 0, 90); p.AddArc(r.X, r.Bottom - d, d, d, 90, 90);
    p.CloseFigure(); return p;
}
```
그릴 때는 늘 `SmoothingMode.AntiAlias`, 1px 선은 좌표에 0.5 더하기(흐림 방지).

## 4. 간격 격자 (8px 단위)

- 기본 단위 **8px**. 쓰는 값: 4(반 칸, 아이콘↔글자 등 아주 가까운 것) · 8 · 12(칸 사이) · 16(패널 안쪽 여백) · 24(보드 몸체 안쪽 여백) · 32.
- 패널 안쪽 여백 16, 속성 창 줄 간격 8, 줄 높이: 입력칸 32 · 단추 32 · 작은 단추 28 · 동작 목록 줄 40 · 묶음 머리 32.
- 위 띠 48 = 위아래 8 + 단추 32. 상태 줄 28.

## 5. 글꼴 — 에스코어 드림 3·4·5

| 단계 | 글꼴 | 크기 | 쓰임 |
|---|---|---|---|
| 제목 | 드림 5 Medium | 13pt | 위 띠 '단축키 꾸미기', 속성 창 첫 줄(고른 칸 이름) |
| 소제목 | 드림 5 Medium | 10.5pt | 동작 목록 묶음 머리, 속성 창 칸 머리('이름', '하는 일') |
| 단추 | 드림 5 Medium | 9.5pt | 모든 직접 그린 단추, 7인치/4인치 알약 |
| 칸 이름 | 드림 5 Medium | 9pt | 보드 미리보기 칸 아래 이름 (4×4 작은 칸이면 8.5pt) |
| 본문 | 드림 4 Regular | 9.5pt | 입력칸 글자, 동작 목록 줄 이름, 메뉴 |
| 작은 글 | 드림 3 Light | 8.5pt | 도움말·경고 한 줄, 상태 줄, 묶음 개수 |
| 칸 번호 | 드림 3 Light | 7.5pt | 칸 왼쪽 위 1~16 |

### 묻어 쓰는 법 (개발팀 참고)
1. **TTF 로 준비**: GDI+ `PrivateFontCollection` 은 CFF 윤곽(.otf 대부분)을 못 읽는다("TrueType 만 지원" 오류). 배포본이 .otf 면 `fonttools`(`otf2ttf`)로 TTF 변환.
2. **크기 줄이기**: `pyftsubset` 으로 KS X 1001 한글 2,350자 + 영문·숫자·기호(U+0020–007E, ·▶▸▾…✓) 만 남긴다 → 한 굵기 약 0.3~0.5MB. 세 굵기 묻어도 exe 가 크게 불지 않는다.
3. `csc /resource:` 로 넣고, 시작할 때 `Assembly.GetManifestResourceStream` → 바이트 → `PrivateFontCollection.AddMemoryFont`(GDI+ 용) **그리고** `AddFontMemResourceEx`(GDI 용, TextBox·TextRenderer 가 보려면 꼭 필요) 둘 다 부른다. 메모리는 프로그램 끝까지 쥐고 있는다(`Marshal.AllocCoTaskMem`, 해제 금지).
4. 굵기마다 따로 된 이름일 수 있으니, 이름 글자로 찾지 말고 **넣은 순서(3→4→5)로 `Families` 를 꺼내** `Fonts.Light/Regular/Medium` 에 둔다. 실패하면 `"Malgun Gothic"` 으로 물러선다(창은 그대로 떠야 함).
5. 글자는 `TextRenderer.DrawText`(GDI) 하나로 통일 — 입력칸과 같은 모양으로 나온다. `UseCompatibleTextRendering = false`.
6. 사용 허락: 에스코어 드림은 상업 포함 무료·묻기 허용 글꼴. 허락 문서(OFL 문구)를 `icons` 옆 `글꼴_사용허락.txt` 로 함께 둔다. (현재 PC 와 프로젝트 폴더에 글꼴 파일이 없음 → 개발팀이 받아서 `exe/fonts/` 에 둘 것)

## 6. 장치(보드) 미리보기

### 보드 몸체
- 둥근 사각(반지름 20), 바탕 `Device`, 1px 테두리 `DeviceEdge`, 안쪽 여백 24.
- 몸체 아래로 부드러운 그림자: 같은 모양을 아래 6px 내려 `#000000` 알파 70 으로 3겹(펼침 2px씩, 알파 70→35→15) 먼저 칠한다.
- 몸체 위쪽 가운데에 작게 `7인치 · 2줄 × 8칸` (드림 3, 8.5pt, `Text3`).
- 미리보기 오른쪽 위에 **알약 바꾸기** `[ 7인치 | 4인치 ]` — 바탕 `Raised`, 고른 쪽만 `Accent` 바탕+흰 글자. 고른 값은 deck.json 이 아니라 사용자 설정(레지스트리 또는 %AppData%)에 기억. 처음 값은 연결된 보드 종류, 모르면 7인치.

### 칸 크기 계산
| 모양 | 칸(정사각) | 칸 사이 | 이름 줄 | 몸체 바깥 크기 |
|---|---|---|---|---|
| 7인치 2×8 | 88 | 12 | 칸 아래 20 | 8·88+7·12+48 = **836** × 2·108+12+48 = **276** |
| 4인치 4×4 | 64 | 12 | 칸 아래 18 | 4·64+3·12+48 = **340** × 4·82+3·12+48 = **412** |

- 창을 줄이면 칸 = `min(기본값, 들어가는 크기)`, 최솟값 56. 칸 순서 i(0~15)는 7인치: `행=i/8, 열=i%8`, 4인치: `행=i/4, 열=i%4` — **번호(=deck.json 순서)는 모양과 상관없이 같다**.
- 칸 안 그림: 타일(72×72)을 칸 안쪽 여백 `(칸-타일)/2` 에 놓는다. 88칸 → 타일 72 그대로(흐림 없음). 64칸 → 타일 56 으로 줄임(HighQualityBicubic).

### 칸(단추) 그리기 — 진짜 단추처럼
순서대로:
1. **그림자**: 칸 모양을 아래 2px 내려 `#000000` 알파 90 으로 칠함.
2. **바탕**: `Key`(#1E222C) 를 둥근 사각으로. 위→아래 아주 옅은 세로 그러데이션(`#232836`→`#1B1F28`)으로 볼록한 느낌.
3. **가장자리**: 1px `KeyEdge`, 그 안쪽 위쪽 테두리에만 1px `#FFFFFF` 알파 14 의 밝은 선(빛 받는 윗면).
4. **타일**: 위 계산대로 가운데.
5. **번호**: 왼쪽 위 안쪽 6px, 드림 3 7.5pt `Text3`. (타일 위에 겹치면 읽기 어려우니 알파 160)
6. **이름**: 칸 **아래** 이름 줄에 가운데 정렬, 드림 5 9pt `Text1`, 한 줄, 넘치면 `…`(EndEllipsis). 이름 검사 경고가 있으면 이름 앞에 `Warn` 색 점(지름 6).

상태별 모습:
| 상태 | 모습 |
|---|---|
| 평소 | 위 1~6 |
| 마우스 위 | 바탕 위에 `#FFFFFF` 알파 10 덮기, 테두리 `#3C4459` |
| **고른 칸** | 바깥 2px `Accent` 테두리(칸 밖으로 3px 띄운 둥근 사각, 반지름+3) + 바깥 빛 `Accent` 알파 40 2px. 이름도 `Accent` 아닌 `Text1` 유지(읽기) |
| 눌림(마우스 누르고 있는 동안·▶ 눌러 보기 할 때) | 그림자 없앰, 칸 전체 1px 아래로, 바탕 `#000` 알파 40 덮기 → 120ms 뒤 원래대로(Timer) |
| 끌고 있는 원래 칸 | 칸 자리를 알파 35% 로 흐리게, 점선 테두리 `Text3` |
| 끌어 놓을 자리(위에 올림) | 테두리 2px `DropTarget`, 바탕 위 `DropTarget` 알파 30 덮기. 칸끼리 바꿀 때는 가운데 `⇄` (드림 5 18pt, 흰색 알파 200) |
| 동작 목록에서 끌어오는 중 | 모든 빈 칸 테두리를 `DropTarget` 알파 120 점선으로 — "여기 놓을 수 있어요" |
| **빈 칸**(Kind=none) | 바탕 `Key` 대신 `#161920`, 그림자 없음(움푹), 테두리 1px 점선 `#353B4D`(DashPattern 3,3). 가운데 `+` (선 두께 2, 길이 칸의 22%, `Text3`). 이름 줄은 비움. 마우스 위면 `+` 가 `Accent` 로 |

끄는 동안 마우스 옆 그림: `DoDragDrop` 은 그대로 쓰고, 끌리는 칸의 타일을 반투명(알파 70%)으로 커서 옆에 따라다니게 하는 작은 테두리 없는 창(`Form`, `ShowInTaskbar=false`, `Opacity=0.8`, `TopMost`)을 `GiveFeedback` 에서 옮긴다. 어려우면 생략해도 됨(선택).

## 7. 동작 목록 (오른쪽 280px)

- 바탕 `Panel`, 왼쪽 1px `Line`. 위에서부터: 머리 '동작' (드림 5 10.5pt, 높이 40) → 찾기 상자(높이 32, 좌우 16) → 목록(나머지).
- **찾기 상자**: 바탕 `Raised`, 반지름 6, 왼쪽 안쪽에 돋보기(지름 10 원 + 4px 손잡이, 선 1.5 `Text3`), 빈 상태 안내 '이름으로 찾기' `Text3`. 포커스 시 테두리 1px `Accent`. 글자 넣으면 오른쪽에 `×` (지우기). 찾는 중엔 묶음을 모두 펴고 맞는 줄만, 맞는 글자는 `Accent` 색.
- 목록은 **한 개의 직접 그리는 컨트롤**(줄들을 리스트로 갖고 OnPaint 에서 보이는 줄만 그림, 스크롤은 8장 방식). ListBox/TreeView 를 쓰지 않는다(어두운 색·높이 조절이 안 됨).

### 묶음 머리 (높이 32)
- 왼쪽 16에 **접힘 화살표**: 10×10 칸에 채운 삼각형, 펴짐 `▾`(아래), 접힘 `▸`(오른쪽). 글자가 아니라 `FillPolygon` 으로 그림, 색 `Text3`(마우스 위 `Text1`). 바뀔 때 90° 회전을 120ms 동안 3단계로(선택).
- 화살표 오른쪽 8에 묶음 이름(드림 5 10.5pt `Text2`), 오른쪽 끝 16 안쪽에 개수 알약(드림 3 8.5pt, 바탕 `Raised`, 글자 `Text3`).
- 머리 아래 1px `Line` 은 없음 — 간격(위 8)으로만 나눈다. 처음엔 '수업'·'발표'·'마이크로소프트' 만 펴 둔다(나머지 접힘). 편/접힌 상태 기억.
- 묶음 순서: 목록.json 의 순서 그대로(마이크로소프트·윈도·어도비·구글·인공지능·한컴·국내·학교·교육·수업·발표·컴퓨터 조작·윈도 도구·스트림덱 기본·모양). 맨 위에 고정 묶음 **'기본 동작'**: 프로그램 열기 / 주소 열기 / 단축키 누르기 / 글자 넣기 / 보드 기능 — 끌어 놓으면 그 하는 일로 바뀐 빈 설정이 되고 속성 창에 포커스.

### 동작 줄 (높이 40)
```
|16| [아이콘 32×32] |12| 이름(드림 4 9.5pt Text1)          |16|
                         하는 일 한 마디(드림 3 8.5pt Text3)  ← 선택: 너비 넉넉하면
```
- 아이콘: 모음의 72 타일을 32 로 줄여 미리 캐시(Bitmap, 처음 펼칠 때 만들기). 둥근 정사각 모양이 이미 타일에 있으니 덧칠 없음.
- 마우스 위: 줄 바탕 `Raised`(좌우 8 띄운 둥근 사각 6). 누른 줄: `AccentSoft`.
- **끌기**: 8px 넘게 움직이면 `DoDragDrop(new DataObject("PeneduAction", key), Copy)`. 보드 칸에 놓으면 그 칸을 모음 항목으로 채움(name·kind·target·아이콘 library). 이미 찬 칸이면 덮어씀 — 놓기 전 칸 위에 '바꾸기' 표시(6장 끌어 놓을 자리).
- **두 번 누르기**: 고른 칸에 바로 채움(끌기 어려운 사람용). 오른쪽 클릭: '고른 칸에 넣기'.
- 줄 위에 마우스를 0.6초 두면 풍선 도움말: 하는 일 설명(예: '워드 프로그램을 엽니다').

## 8. 스크롤바

- 기본 스크롤바(밝은 회색)는 **쓰지 않는다**. 동작 목록·한 번에 채우기 목록 등 직접 그리는 컨트롤 안에 얇은 스크롤바를 그린다.
- 오른쪽 끝에서 4px 안쪽, 평소 너비 6, 마우스가 목록 위에 있을 때 8, 손잡이 위면 10. 길(트랙)은 그리지 않거나 `#FFFFFF` 알파 6.
- 손잡이: 둥근 막대(반지름=너비/2), `Thumb`, 마우스 위/끄는 중 `ThumbHover`. 최소 길이 32.
- 마우스 휠: 한 칸에 줄 3개(120px)씩, 부드럽게(목표 위치로 16ms 타이머로 다가가기, 4~6번에 도착). 끝에 닿으면 멈춤.
- 목록 위아래가 잘릴 때 맨 위/아래 12px 에 `Panel` → 투명 그러데이션(내용이 더 있다는 표시).
- 어쩔 수 없이 표준 컨트롤에 스크롤이 생기면(여러 줄 TextBox) `SetWindowTheme(handle, "DarkMode_Explorer", null)` 로 어두운 스크롤바(윈도 10 1809+).

                        └────────────────────────────────────────────────────────┘

- 위 1줄(높이 32): 고른 칸 표시 `3번 칸 · 워드` (드림 5 13pt `Text1`, 번호 부분 `Text3`).
- **아이콘 상자**: 카드(반지름 12, 바탕 `Raised`), 가운데 타일 96(72를 키울 때는 최근접 아닌 HighQualityBicubic). 그림 파일을 여기에 끌어 놓아도 됨(놓는 중 테두리 `DropTarget` 점선). 아래 작은 단추 '모음에서…'.
- **이름 입력칸**: 높이 32, 반지름 6, 바탕 `Raised`, 테두리 평소 없음 → 마우스 위 1px `Line` → 포커스 1px `Accent`. 표준 `TextBox` 를 `BorderStyle.None`·`BackColor=Raised`·`ForeColor=Text1` 로 두고, 둥근 바탕은 부모 패널이 그린다(TextBox 를 안쪽 좌우 10, 세로 가운데 배치). 오른쪽 안쪽에 글자 수 `4/8` (드림 3 `Text3`).
  - 검사 결과 한 줄(입력칸 아래 4px): 문제없음 `Ok` + ✓, 길이 경고 `Warn`, 쓸 수 없는 글자 `Danger` + '이 글자는 보드에 안 나와요: …'. 경고/위험이면 입력칸 테두리도 그 색.
- **하는 일 / 아이콘 방식 고르기**: 라디오 단추 대신 **알약 무리**(이어 붙인 세그먼트). 높이 28, 각 알약 안쪽 좌우 12, 바탕 `Raised`, 고른 것 `Accent` 바탕+흰 글자, 사이 2px 간격. 드림 5 9.5pt. 키보드: ←→ 로 옮기기, 포커스 시 바깥 1px `AccentHover` 점선.

## 12. 그리기 공통 규칙 (개발팀 체크)

1. 모든 직접 그린 컨트롤: `DoubleBuffered=true` 또는 `OptimizedDoubleBuffer` → 깜박임 없음. 창 `BackColor = Theme.Bg`.
2. 바뀐 칸만 `Invalidate(칸 사각형 넓힌 것)` — 보드 전체를 매번 다시 그리지 않기(호버가 자주 일어남).
3. 마우스 위 상태는 `OnMouseMove`/`OnMouseLeave` 에서 저장 후 바뀔 때만 다시 그림.
4. 높은 화면 배율(125%·150%): `AutoScaleMode.Dpi`, 위 숫자는 모두 96dpi 기준 → `DeviceDpi/96f` 를 곱한다(.NET 4 에서는 `g.DpiX/96`). 타일은 배율 1.25 이상이면 2배 그림(144)에서 줄여 그려 흐림 방지(선택).
5. 기존 그대로 둘 것: `DeckGrid` 의 끌어 바꾸기 데이터 형식 `"PeneduCell"`, 파일·주소·그림 끌어 놓기, 오른쪽 클릭 메뉴 항목, `f.SelectCell/SwapCells/FillFromPath/SetIconFromImage/MarkDirty` 호출 — 그리기만 바꾸고 `HitCell`/`CellRect` 를 모양(2×8 / 4×4)에 맞게 고친다.
6. 새 끌기 형식 `"PeneduAction"`(동작 목록 → 칸)만 더한다.
7. 화면 글은 쉬운 한국어. 영어 낱말 금지(예: 'URL' → '주소', 'Hotkey' → '단축키', 'Favicon' → '사이트 그림').
