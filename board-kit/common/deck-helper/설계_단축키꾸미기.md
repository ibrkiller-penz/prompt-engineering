# 설계: 단축키 꾸미기(컴퓨터에서 칸을 바꾸고 보드로 보내기)

작성 2026-10-26. 세 사람이 동시에 만들 수 있게 **약속(줄 형식·파일·바이트)** 을 먼저 못 박는다.
이 문서와 다르게 만들고 싶으면 먼저 이 문서를 고치고 알린다.

| 담당 | 맡는 것 | 고치는 파일 |
|---|---|---|
| **A 보드** | 받기·저장·켤 때 읽기·그리기·되돌리기 (7인치 먼저, 같은 코드를 4인치에) | `7inch/firmware/src/main.cpp`, `4inch/firmware/src/main.cpp` |
| **B 도우미 통신·아이콘** | 보내기(lock-step)·해시·아이콘 만들기(.bin/.png)·`@deck sN` 처리·기본 그림 16개 | `common/deck-helper/exe/DeckHelper.cs`(통신·아이콘 부분), `build_exe.ps1`, `7inch/tools/export_deck_icons.py`, `7inch/tools/deck_helper.ps1`(옛 판 최소 고침) |
| **C 설정 창** | '단축키 꾸미기' 창(WinForms)·deck.json 읽고 쓰기·글자 검사·끌어다 놓기 | `common/deck-helper/exe/DeckForm.cs`(새 파일; build_exe.ps1 에 추가) |

A↔B 는 3장(줄 약속)과 4장(바이트)만 맞추면 따로 만들 수 있다. B↔C 는 6장(deck.json)과 7장의 함수 이름만 맞춘다.
A 는 B 없이 시험할 수 있게 B 가 먼저 작은 파이썬 보내기(`7inch/tools/deck_push.py`, 9장)를 만든다(반나절 안에).

지켜야 할 것(모두): 화면 설정(PCLK·박자·완충 버퍼·`custom_sdkconfig`) 안 건드림 · 큰 버퍼는 PSRAM 또는 static · 글자 다시 그리기는 받기 끝에 한 번만 · 주석은 짧은 한국어 · git add·커밋 금지 · 화면·창 글은 쉬운 한국어 · C# 은 **C# 5 문법만**(.NET Framework 4 csc) · 보드 이름 글자는 KS X 1001 한글 2,350자+영문.

## 1. 큰 그림

```
[설정 창 C] ─저장─▶ deck.json + icons/cell_N.bin ─▶ [도우미 B] ─UART/USB 줄 단위 base64─▶ [보드 A] ─LittleFS /deck/─▶ 켤 때 읽음
                                                        ▲ '@board ok deck=<해시>' 로 같은지 확인(같으면 안 보냄)
보드 칸 누름 ──'@deck s3'(사용자 설정) 또는 '@deck explorer'(기본)──▶ 도우미가 열고 '@deck ok s3' 답
```

- 칸 번호 **0~15**. 7인치는 8칸×2줄(0~7 윗줄, 8~15 아랫줄), 4인치는 4칸×4줄(0~3 첫 줄). 번호는 `DECK[i]` 와 같다(왼쪽 위부터 읽는 차례).
- 보드는 사용자 설정이 있으면 **이름 16개 + 아이콘 16개**만 바뀐다. 무엇을 여는지는 **컴퓨터 쪽(deck.json)** 이 안다(지금과 같은 원칙).
- 보드는 다시 굽지 않는다. 설정 창에서 [저장하고 보드에 보내기]를 누르면 몇 초~1분 안에 보드 화면이 바뀐다.

## 2. 줄(라인) 약속 — 방향·예시·응답·시간 제한·재시도

모든 줄은 **ASCII**, 끝은 `\n`(보드는 `\r` 도 끝으로 본다). 보드가 보내는 줄은 앞에 `\n` 을 하나 더 붙여도 된다(기록 줄과 섞이지 않게, 지금 `@deck` 과 같음). 도우미는 **줄 앞뒤 공백을 지우고** 비교한다.
보드의 다른 기록 줄(`sync …`, `heap …`)이 사이에 끼어도 도우미는 `@` 로 시작하는 줄만 본다.

### 2-1. 살아 있나 확인(지금 것 + 해시)

| 방향 | 줄 | 뜻 |
|---|---|---|
| PC→보드 | `@pc on` | 5초마다(지금과 같음). **보내기 중에는 아이콘 하나와 다음 아이콘 사이**에만 보낸다(조각 사이에는 안 보냄). |
| 보드→PC | `@board ok` 그리고 다음 줄 `@board ok deck=<해시>` | 새 보드는 **두 줄**을 답한다(첫 줄은 옛 도우미용, 8장). `<해시>` = `/deck/cfg.json` 바이트의 CRC-32 를 **소문자 16진수 8자리**. 사용자 설정이 없으면(내장 16개) `deck=0`. 예: `@board ok deck=3fa9c01e`, `@board ok deck=0` |
| 보드→PC | `@board ok` 한 줄만 | **옛 보드**(이 기능이 없는 펌웨어). 새 도우미는 첫 줄 뒤 **3초** 안에 `deck=` 줄이 안 오면 "보낼 수 없는 보드"로 적고 절대 보내지 않는다. |
| 보드→PC | `@pc?` | [새로 고침] 단추(지금과 같음). 도우미는 바로 `@pc on`. |

도우미 규칙: `deck=` 값이 **자기 deck.json 의 해시와 다르면** 2-3 의 보내기를 시작한다(단, 2-5 의 쉼 규칙). 같으면 아무것도 안 한다. 도우미 쪽에 deck.json 이 없으면(한 번도 꾸민 적 없음) 보드가 `deck=0` 이 아니어도 **보내지 않는다**(보드에 남은 설정을 그대로 둔다; 지우려면 설정 창 [기본값으로]).

### 2-2. 칸을 눌렀을 때

| 방향 | 줄 | 뜻 |
|---|---|---|
| 보드→PC | `@deck s3` | 사용자 설정을 쓰는 중이면 `s`+칸 번호(0~15). |
| 보드→PC | `@deck explorer` | 내장(기본) 16개를 쓰는 중이면 지금처럼 영문 키. |
| PC→보드 | `@deck ok s3` / `@deck fail s3` | 키를 **그대로 되돌려** 답한다(지금과 같음). 보드는 5초 안에 답이 없으면 "컴퓨터 답이 없습니다"(지금 코드 그대로). |

도우미는 `^s([0-9]|1[0-5])$` 이면 deck.json 의 그 칸, 아니면 지금처럼 apps.txt → DefaultApps(옛 보드 호환).

### 2-3. 보내기(lock-step: **한 줄 보내고 답을 받아야 다음 줄**)

| 순서 | 방향 | 줄 | 답(보드→PC) | 도우미 기다림·재시도 |
|---|---|---|---|---|
| ① | PC→보드 | `@deckls` | `@deckls <해시> <c0> <c1> … <c15>` — 칸 16개의 아이콘 CRC-32(소문자 8자리). 내장 아이콘을 쓰는 칸은 `-`. 예: `@deckls 3fa9c01e a1b2c3d4 - - 9e8f7a6b …`(공백으로 나눔, 모두 18개 토막) | 3초, 3번. 끝내 답이 없으면 포기(2-5). |
| ② | PC→보드 | `@deckbegin <해시> <개수>` — `<해시>` 는 이번에 보낼 cfg.json 의 해시, `<개수>` 는 보낼 아이콘 수(0~16, cfg 는 세지 않음) | `@deckbegin ok` / `@deckbusy`(와이파이 받기 중) / `@deckbegin fail <이유>` | 3초, 3번. `@deckbusy` 면 **15초 뒤 다시 ②**(최대 20번 = 5분). |
| ③ | PC→보드 | `@deckitem <칸> <길이> <crc>` — `<칸>` 은 `0`~`15` 또는 `c`(cfg.json). `<길이>` 는 원본 바이트 수(아이콘은 항상 15552), `<crc>` 는 원본 전체의 CRC-32 | `@deckitem ok <칸>` / `@deckitem fail <칸> <이유>` | 3초, 3번 |
| ④ | PC→보드 | `@deckdata <칸> <번호> <base64>` — `<번호>` 는 0부터 조각 차례, `<base64>` 는 원본 **192바이트**(마지막 조각만 짧음)를 표준 base64(`+/=`, 줄바꿈 없음)로 | `@deckdata ok <칸> <번호>` / `@deckdata err <칸> <번호> <이유>` | **2초**, 같은 번호를 3번까지 다시. `err` 도 같은 번호 다시(3번). |
| ⑤ | PC→보드 | `@deckitem end <칸>` | `@deckitem done <칸>` / `@deckitem bad <칸> <이유>`(길이·crc 안 맞음) | 5초. `bad` 면 그 칸을 ③부터 다시(2번까지). |
| ⑥ | PC→보드 | `@deckend` | `@deckend ok <해시>` / `@deckend fail <이유>` | **10초**(보드가 파일 검사 + PSRAM 올리기 + 화면 한 번 그림). |
| 중단 | PC→보드 | `@deckabort` | `@deckabort ok` | 답 안 기다림. |
| 되돌리기 | PC→보드 | `@deckreset` | `@deckreset ok` | 5초, 2번. 보드는 `/deck/*` 를 지우고 내장 16개로 돌아가 화면을 한 번 그린다. 설정 장의 [기본 아이콘으로] 단추도 같은 함수. |

- **보내는 차례**: `@deckls` → 바뀐 아이콘만 ③④⑤ 반복(칸 번호 오름차순) → cfg(`c`) ③④⑤ → `@deckend`. **cfg 는 항상 맨 끝**(아이콘이 다 있어야 cfg 가 가리키는 파일이 있다).
- "바뀐 것만": `@deckls` 의 칸별 crc 와 도우미의 `icons/cell_N.bin` crc 가 다른 칸만 보낸다. 내장 아이콘을 쓰는 칸(deck.json 의 `icon.mode = "builtin"`)은 보내지 않고 cfg 의 `ic` 를 `""` 로 둔다. 해시가 다르면 cfg 는 항상 보낸다.
- **같은 번호가 또 오면**(답이 사라져서 도우미가 다시 보낸 것): 보드는 `번호 == 마지막으로 받은 번호` 일 때 **쓰지 않고** `@deckdata ok` 만 답한다. 번호가 그 밖이면 `@deckdata err <칸> <번호> seq`.
- 보드 쪽 시간 제한: 보내기 중 **30초** 동안 아무 `@deck…` 줄이 없으면 스스로 중단(임시 파일 지움, 안내 줄 "받기를 멈췄습니다", 기록 `deck upload timeout`).
- 보드가 보내기 중 와이파이 받기(sync) 시각이 되면 **받기를 미룬다**(`s_syncReq` 는 그대로 두고, 보내기가 끝난 뒤 처리). 반대로 이미 받는 중이면 ② 에 `@deckbusy`.
- 도우미 창 진행: "아이콘 보내는 중 3/16", 보드 안내 줄: **"아이콘 받는 중 3/16"**(③ 을 받을 때 갱신, cfg 는 "설정 받는 중"), 끝나면 "새 단축키를 받았습니다"(60초 뒤 평소 글로; `s_deckSentAt` 재사용).

### 2-4. 한 줄 길이·버퍼

- 가장 긴 줄: `@deckdata 15 80 ` + base64 256자 = **273자**(+`\n`). 보드 `deckPoll` 의 `buf[32]` 를 **`static char buf[320]`** 으로.
- 7인치 UART(CH343): `Serial.setRxBufferSize(2048)` 를 **`Serial.begin(115200)` 앞에**(뒤에 부르면 안 먹음). 4인치(USB-CDC `HWCDC`)도 같은 함수가 있다 → 같은 자리에 같은 값.
- 보내기 중에는 `deckPoll` 을 **매 바퀴** 부른다: loop 의 `if (ms - lastUsbChk > 200)` 를 `if (s_deckUp || ms - lastUsbChk > 200)` 로(`s_deckUp` = 보내기 중 플래그).
- 어림 시간(7인치 115200bps): 아이콘 하나 = 81조각 × (273B + 답 25B) ≈ 2.1초 + 왕복 지연. 16개 전부 ≈ 40~60초. 4인치 USB 는 훨씬 빠르다(지연은 lock-step 왕복이 대부분).

### 2-5. 실패했을 때(도우미)

- 어느 단계든 재시도를 다 쓰면 `@deckabort` 보내고 기록·풍선 "보드에 보내지 못했어요(다시 해 봅니다)". **60초** 쉬고 다음 `@board ok` 에서 다시 시도. 같은 보드에 **3번** 잇달아 실패하면 멈추고, 설정 창에서 [저장하고 보드에 보내기]를 다시 누를 때까지 안 보낸다(풍선: "도우미 메뉴 '단축키 꾸미기'에서 다시 보내 주세요").
- 보드가 뽑히면(포트 끊김) 세션 폐기. 보드는 30초 뒤 스스로 중단한다.

## 3. 해시·CRC 계산(보드와 도우미가 같은 값)

- 모두 **CRC-32(IEEE, zlib/PNG 와 같은 것)**: 다항식 반사 `0xEDB88320`, 초기값 `0xFFFFFFFF`, 끝에 `^0xFFFFFFFF`, 입력은 **바이트 차례 그대로**(엔디안 생각 없음). 시험값: `"123456789"` → `cbf43926`. 표기는 **소문자 16진수 8자리, 0 채움**.
- 보드: `#include "esp_rom_crc.h"` 의 `esp_rom_crc32_le(0, data, len)` 이 위와 같은 값(이 함수가 안팎 반전을 알아서 한다). 조각마다 누적할 때는 `crc = esp_rom_crc32_le(crc, chunk, n)`(처음 0).
- C#: 256 표 하나 만들어 쓴다(.NET 4 에는 없음). PowerShell 옛 판은 계산 안 함(8장).
- **아이콘 crc** = `.bin` 15552바이트 전체의 CRC-32. **cfg 해시** = `cfg.json` 파일 바이트(UTF-8, BOM 없음, 끝 줄바꿈 없음) 전체의 CRC-32. 보드는 cfg.json 을 **받은 바이트 그대로 저장**하고, 켤 때 그 파일을 읽어 CRC 를 한 번 계산해 둔다(`s_deckHash`, `@board ok` 답에 씀). 보드는 cfg 안의 글자를 정리하거나 다시 쓰지 않는다(쓰면 해시가 깨진다).
- 같은 deck.json 이면 도우미는 **항상 같은 cfg.json 바이트**를 만든다: 키 차례 고정(`v`,`n`,`ic`), 공백·줄바꿈 없음, 한글은 UTF-8 그대로(`\uXXXX` 로 바꾸지 않음), `/` 는 그대로. C# 은 JSON 라이브러리 없이 직접 만든다(`"` `\` 는 `\"` `\\` 로, 0x00~0x1F 는 `\uXXXX`).

## 4. 아이콘 바이트 형식(`.bin`)

- 크기 고정 **72×72**, 머리글 없음, 길이 **15552 = 72×72×3** 바이트. 다른 길이면 보드가 `@deckitem fail <칸> size`.
- 픽셀 차례: 왼쪽 위부터 오른쪽으로, 줄 단위(row-major). 픽셀당 3바이트: `[RGB565 아래 바이트][RGB565 위 바이트][알파 0~255]`(작은 끝). 지금 `deck_icons.c` 의 `LV_IMG_CF_TRUE_COLOR_ALPHA`(LV_COLOR_DEPTH 16)와 **완전히 같은 배열**이라 `data` 포인터만 바꾸면 된다.
- RGB565 변환(도우미): `r5 = r >> 3, g6 = g >> 2, b5 = b >> 3; v = (r5 << 11) | (g6 << 5) | b5; lo = v & 0xFF; hi = v >> 8`. 알파는 그대로(straight alpha, 미리 곱하지 않음).
- 보드: `lv_img_dsc_t` 는 `{ .header = { .cf = LV_IMG_CF_TRUE_COLOR_ALPHA, .always_zero = 0, .reserved = 0, .w = 72, .h = 72 }, .data_size = 15552, .data = <PSRAM 주소> }`.

### 4-1. '다크 사각' 모양(도우미가 그린다 — `make_deck_icons.py` 와 같은 모양)

72×72 를 **4배(288)로 그려 줄인다**(HighQualityBicubic). 그림 안 치수(288 기준): 둥근 모서리 반지름 69(=0.24), 테두리 두께 13(=0.045), 바탕 채움 `(30,34,44)`, 테두리 색 = 그림의 **대표색**(알파>128 이고 채도가 가장 높은 쪽 픽셀 평균; 없으면 `(90,140,255)`), 테두리 안쪽에 같은 색 투명도 90/255 번짐(블러 15) — 번짐은 생략해도 된다(최소: 둥근 사각 + 테두리). 가운데 그림은 **230×230(=0.80) 안에 비율 유지로 맞춤**. 바깥(둥근 모서리 밖)은 알파 0.

- 프로그램 아이콘 가져오기(큰 순서로 시도): ① `IShellItemImageFactory::GetImage(256×256, SIIGBF_ICONONLY)`(COM, `[ComImport]` 인터페이스 선언 — C# 5 에서 됨) ② `SHGetImageList(SHIL_JUMBO=4)` + `IImageList::GetIcon` ③ `Icon.ExtractAssociatedIcon`(32px, 마지막 수단). `.lnk` 는 WScript.Shell 로 `TargetPath`·`IconLocation` 을 풀어 그 대상으로.
- 사이트: 글자 아이콘(이름 첫 글자 1~2자, 흰색, 두꺼운 글꼴 "Malgun Gothic Bold" 크기 110/288)이 기본. [파비콘 받기]는 사용자가 단추를 눌렀을 때만 `https://<호스트>/favicon.ico` → 안 되면 `https://www.google.com/s2/favicons?domain=<호스트>&sz=128`(인터넷이 없으면 글자 아이콘으로).
- 단축키·글자 넣기·내장: 글자 아이콘(이름 첫 글자) 또는 기본 그림 16개 중 고름.
- 사용자 그림 파일(PNG/JPG/BMP/ICO): 그대로 230×230 안에 맞춰 넣는다(투명 PNG 면 바탕이 비친다).

### 4-2. 기본 그림 16개

- `7inch/tools/export_deck_icons.py`(B 가 만듦): `deck_icons.c` 를 읽어 `common/deck-helper/icons/기본/<키>.png`(72×72 RGBA) **와** `<키>.bin`(4장 형식) 16쌍을 만든다. 키는 `DECK[]` 차례: `explorer claude gemini gpt cmd powershell neis naver youtube coolmsg kakao excel ppt close hwp desktop`.
- exe 는 파일 하나로 다니므로(Firebase /deck 압축에 exe 하나) 16개 PNG 를 **묻어 넣는다**: `build_exe.ps1` 에 `/resource:icons\기본\<키>.png,deck.<키>.png`. 처음 켤 때 `%LOCALAPPDATA%\PeneduBoard\icons\기본\` 에 풀어 둔다(이미 있으면 안 씀).
- 설정 창에서 '기본 그림'으로 고르면 `icon.mode="builtin", icon.src="<키>"` 로 저장하고 **아이콘은 보드로 보내지 않는다**(보드 안에 이미 있다). cfg 의 `ic[i]` 에 `"builtin:<키>"` 를 적으면 보드가 그 키의 내장 아이콘을 쓴다(어느 칸에든 아무 키나 됨). `""` 는 "칸 번호 i 의 내장 아이콘"(= 지금 모양 그대로).

## 5. 보드(A)

### 5-1. 파일

| 경로 | 내용 |
|---|---|
| `/deck/cfg.json` | 도우미가 보낸 바이트 그대로. 6-2 형식. |
| `/deck/0.bin` … `/deck/15.bin` | 4장 형식 15552바이트. 내장 그림을 쓰는 칸은 파일이 없어도 된다. |
| `/deck/<칸>.tmp`, `/deck/cfg.tmp` | 받는 중 임시. `@deckitem done` 때 `rename` 으로 바꿔치기(지금 `tt.tmp` 와 같은 방식). 켤 때 남아 있으면 지운다. |

LittleFS 파티션 3.4MB, 전부 써도 250KB. 용량 검사 없이 가되 `open` 실패는 `@deckitem fail <칸> open`.

### 5-2. 켤 때(`setup`, `LittleFS.begin` 뒤·`buildDeck` 앞) — `deckLoad()`

1. `/deck/cfg.json` 없으면 내장(지금과 같음), `s_deckCustom=false`, `s_deckHash="0"`. 끝.
2. 파일을 PSRAM(`s_alloc`) JSON 으로 파싱. `v==1`, `n` 16개, `ic` 16개 아니면 → 기록 `deck cfg bad`, 내장으로(파일은 두되 다음 보내기에 덮인다). 파일 바이트의 CRC-32 → `s_deckHash`(8자리 문자열).
3. 아이콘 저장소: **처음 한 번** `s_deckPix = (uint8_t*)heap_caps_malloc(16 * 15552, MALLOC_CAP_SPIRAM | MALLOC_CAP_8BIT)`(248,832B, PSRAM). `static lv_img_dsc_t s_deckDsc[16]` 는 `data = s_deckPix + i*15552`.
4. 칸 i: `ic[i]` 가 8자리 crc 면 `/deck/i.bin` 을 읽어 `s_deckPix + i*15552` 에 넣고 **CRC 를 다시 계산해 ic[i] 와 비교**(다르거나 파일이 없거나 길이가 15552 아니면 그 칸은 내장 i 로 두고 `@deckls` 에 `-`). `builtin:<키>` 면 그 키의 내장 `lv_img_dsc_t`, `""` 면 내장 i.
5. `s_deckName[16]` 에 이름 복사(`static char s_deckName[16][40]`, UTF-8 잘림 주의: 39바이트에서 멀티바이트 가운데를 자르지 않게 앞에서 글자 단위로).
6. `buildDeck` 은 `DECK[i].icon`/`label` 대신 `deckIcon(i)`/`deckName(i)` 를 쓴다. 이름 레이블 포인터를 **`s_deckLbl[16]`** 에 둔다(나중에 한 번 다시 그리려고).

### 5-3. 받는 중 상태(`deckPoll` 안)

- `static` 변수: `s_deckUp`(bool), `s_deckUpAt`(마지막 줄 시각), `s_deckUpItem`(-1·0~15·16=cfg), `s_deckUpFile`(File), `s_deckUpLen/Want/Crc/Seq`, `s_deckUpN`(이번에 올 개수), `s_deckUpDone`(받은 개수).
- `@deckls`: cfg 가 없으면 `@deckls 0 - - … -`.
- `@deckbegin`: `s_sync != SYNC_IDLE` 면 `@deckbusy`. 아니면 남은 `.tmp` 지우고 `s_deckUp=true`, 안내 줄 "아이콘 받는 중 0/N"(`lock()` 안에서, 지금 `s_deckState` 쓰는 것과 같이).
- `@deckitem`: 임시 파일 열기, `Seq=0`, `Crc=0`. 안내 줄 갱신 "아이콘 받는 중 k/N".
- `@deckdata`: `mbedtls_base64_decode`(`<mbedtls/base64.h>`)로 `static uint8_t dec[256]` 에 풀기 → 파일에 쓰고 `Crc` 누적, `Len` 더함. 번호 검사는 2-3. 디코드 실패 `err … b64`, 쓰기 실패 `err … write`.
- `@deckitem end`: 닫고 `Len==Want && Crc==Want` 면 rename 하고 `done`, 아니면 임시 지우고 `bad`.
- `@deckend`: cfg.tmp 가 `/deck/cfg.json` 으로 바뀌어 있어야 한다(없으면 `fail nocfg`). `deckLoad()` 를 다시 돌려 PSRAM 에 올리고, **한 번만** `lock()` 안에서 `lv_img_set_src(s_deckImg[i], deckIcon(i))` + `lv_label_set_text(s_deckLbl[i], deckName(i))` 16칸, 안내 줄 "새 단축키를 받았습니다". `s_deckUp=false`. 답 `@deckend ok <s_deckHash>`.
- 30초 무응답: `s_deckUp && ms - s_deckUpAt > 30000` → 임시 닫고 지움, `s_deckUp=false`, 안내 줄 "받기를 멈췄습니다 · 도우미가 다시 보냅니다", 기록 `deck upload timeout`. (loop 의 200ms 블록에 넣는다.)
- 보내기 중에 들어온 `@pc on` 은 평소처럼 `s_pcLast` 갱신 + `@board ok deck=…` 답. 보드의 `@deck…` 받는 줄도 `s_pcLast` 를 갱신한다(도우미가 살아 있다는 뜻).
- 보내기 중에는 칸 누름(`onDeck`) 무시하고 안내 줄에 "받는 중입니다 · 잠시 뒤 누르세요".
- `@deckreset`(그리고 설정 장 단추 `[기본 아이콘으로]`): `s_deckUp` 이면 먼저 중단. `/deck/` 파일 전부 지움, `s_deckCustom=false`, `s_deckHash="0"`, 16칸 내장으로 한 번 다시 그림, 답 `@deckreset ok`. 설정 장 단추는 `s_deckCustom` 일 때만 보이게.

### 5-4. 칸 누름

`onDeck`: `s_deckCustom ? Serial.printf("\n@deck s%d\n", i) : Serial.printf("\n@deck %s\n", DECK[i].key)`. 답의 `deckLabel(buf+9)`: `s` 로 시작하고 숫자면 `deckName(그 번호)`, 아니면 지금처럼 키 → 이름.

### 5-5. 와이파이 받기와의 관계

- `s_deckUp` 인 동안 `s_syncReq` 를 처리하는 곳(loop 의 `s_sync == SYNC_IDLE` 분기)은 **건너뛴다**(받기 뒤로 미룸). 1시간 주기 재받기도 같은 조건.
- 받기(SYNC) 중에 `@deckbegin` 이 오면 `@deckbusy`.

### 5-6. 메모리·그리기

- 내부 RAM 은 안 쓴다: 픽셀은 PSRAM, 줄 버퍼·디코드 버퍼는 `static`. JSON 은 `s_alloc`.
- LVGL 가 PSRAM 의 아이콘을 읽는 것은 지금 날씨 아이콘·시간표 JSON 과 같은 방식이라 문제없다(72×72 작음).
- 화면 다시 그리기는 `@deckend` 와 `@deckreset` 에서 **각각 한 번**. 조각마다 그리지 않는다. 안내 줄 갱신은 ③ 마다(16번) — 글자 한 줄이라 괜찮다.

## 6. 도우미 파일 형식

도우미 폴더 = `%LOCALAPPDATA%\PeneduBoard\`(지금 `Dir`). 그 안에 `deck.json`, `icons\cell_0.bin … cell_15.bin`(보드용), `icons\cell_0.png …`(미리보기), `icons\기본\<키>.png|.bin`.

### 6-1. `deck.json`(도우미·설정 창용, UTF-8 BOM 없음, 보기 좋게 들여쓰기 OK)

```json
{
  "v": 1,
  "cells": [
    { "name": "탐색기",  "kind": "app",     "target": "explorer.exe",
      "icon": { "mode": "auto",    "src": "explorer.exe", "crc": "a1b2c3d4" } },
    { "name": "나이스",  "kind": "url",     "target": "https://idp1-pen.neis.go.kr:9443/Login_Server/generateFP.jsp",
      "icon": { "mode": "letter",  "src": "",             "crc": "0f1e2d3c" } },
    { "name": "음소거",  "kind": "keys",    "target": "^+m",
      "icon": { "mode": "file",    "src": "C:\\그림\\mute.png", "crc": "5a6b7c8d" } },
    { "name": "인사말",  "kind": "text",    "target": "안녕하세요. 3학년 2반입니다.",
      "icon": { "mode": "builtin", "src": "hwp",          "crc": "" } },
    { "name": "바탕화면", "kind": "builtin", "target": "#desktop",
      "icon": { "mode": "builtin", "src": "desktop",      "crc": "" } }
  ]
}
```

- `cells` 는 **항상 16개**(칸 0~15). 비워 둔 칸은 `{"name":"", "kind":"none", "target":"", "icon":{"mode":"builtin","src":"","crc":""}}` — 보드는 이름 없는 칸을 흐리게 그리고, 눌러도 보내지 않는다(cfg `n[i]==""`).
- `kind`: `app`(프로그램·파일·`.lnk`·`프로토콜:`) · `url`(사이트) · `keys`(SendKeys 표기, 예 `^+m`, `%{F4}`, `^c`) · `text`(클립보드에 넣고 `^v`; 300ms 뒤 클립보드 원래 값 복구는 하지 않음) · `builtin`(`#desktop` 바탕화면 보기, `#altf4` 창 닫기, `#lock` 잠금(`LockWorkStation`), `#mute` 소리 끄기(`VK_VOLUME_MUTE` keybd_event)) · `none`.
- `icon.mode`: `auto`(프로그램 아이콘에서) · `favicon` · `letter` · `file`(사용자 그림, `src` 는 경로) · `builtin`(`src` 는 16개 키 중 하나). `crc` 는 만들어 둔 `icons\cell_i.bin` 의 CRC(`builtin` 은 `""`). **저장 때 설정 창이 .bin 을 다시 만들고 crc 를 적는다**(도우미는 보낼 때 crc 를 다시 계산하지 않고 믿되, 파일이 없으면 다시 만든다).
- 없으면: 도우미는 "꾸민 적 없음"으로 보고 옛 방식(apps.txt/DefaultApps)만 쓴다. 설정 창을 처음 열면 기본 16개(DefaultApps + 기본 그림)로 채워 보여 준다(파일은 저장을 눌러야 생긴다).

### 6-2. `cfg.json`(보드로 보내는 것, 도우미가 deck.json 에서 만든다; 공백 없음·키 차례 고정)

```
{"v":1,"n":["탐색기","Claude","제미나이","GPT","CMD","파워셸","나이스","네이버","유튜브","쿨메신저","카카오톡","엑셀","PPT","창닫기","한글","바탕화면"],"ic":["a1b2c3d4","","","builtin:gpt","","","0f1e2d3c","","","","","","","","",""]}
```

- `n[i]`: 칸 이름(UTF-8, 보드 글꼴 안 글자만, 설정 창이 막는다). `ic[i]`: `"<crc 8자리>"`(= `/deck/i.bin` 있음) · `""`(내장 i) · `"builtin:<키>"`.
- 보드가 읽을 때 길이 상한: 파일 4KB, 이름 39바이트.

## 7. 설정 창(C) — '단축키 꾸미기'

작업 표시줄 아이콘 오른쪽 클릭 메뉴에 **"단축키 꾸미기…"**(첫 줄 바로 아래). 누르면 `DeckForm`(WinForms, 한 번에 하나만) 이 **화면 스레드**에서 열린다. `Helper` 와의 접점은 세 함수뿐:

```csharp
// Helper 쪽(B 가 만든다)
public DeckConfig LoadDeck();                 // deck.json 읽기(없으면 기본 16개)
public void SaveDeck(DeckConfig c);           // deck.json 쓰기 + icons\cell_i.bin/.png 다시 만들기 + crc 채우기
public void RequestPush(bool force);          // 보드 스레드에 "보내라" 표시(force = 실패 3번 뒤 멈춘 것도 다시)
public event Action<string> PushProgress;     // "아이콘 보내는 중 3/16" 같은 글(보드 스레드에서 옴 → 창은 ui.Post 로 받는다)
// 아이콘(B): Bitmap IconFromApp(string path, int px=256); Bitmap IconLetter(string name); Bitmap IconFavicon(string url);
//            Bitmap Tile(Bitmap glyph);  byte[] ToBin(Bitmap tile72);  string Crc32Hex(byte[] b);
```

### 7-1. 화면 구성(가로 900 × 세로 560, 최소)

```
┌ 단축키 꾸미기 ───────────────────────────────────────────────────────────┐
│ 왼쪽: 미리보기 4×4 (칸 120×120, 아이콘 72 + 이름)        오른쪽: 고른 칸 편집     │
│  ┌────┬────┬────┬────┐   칸 7 · 윗줄 8번째(7인치) / 2줄 4번째(4인치)              │

│  ├────┼────┼────┼────┤   종류   (●)프로그램 열기 ( )사이트 열기 ( )단축키 누르기      │
│  │ 4  │ 5  │ 6  │ 7  │          ( )글자 넣기 ( )내장 기능                           │
│  ├────┼────┼────┼────┤   대상   [C:\…\Hwp.exe            ] [찾아보기…]             │
│  │ 8  │ 9  │ 10 │ 11 │          (종류에 따라: 주소 / 단축키 표기 도움말 / 긴 글칸 / 목록) │
│  ├────┼────┼────┼────┤   아이콘 (●)자동(프로그램에서) ( )글자 ( )그림 파일… ( )기본 그림 ▾ │
│  │ 12 │ 13 │ 14 │ 15 │          [파비콘 받기]  미리보기 72×72                          │
│  └────┴────┴────┴────┘   [이 칸 비우기]                                              │
│ 상태 줄: "보드: 7인치 연결됨 · 보드와 같음" / "아이콘 보내는 중 3/16"                     │

└───────────────────────────────────────────────────────────────────────────┘
```

- 미리보기 칸을 누르면 오른쪽이 그 칸으로 바뀐다. 보드 화면 그대로의 어두운 바탕(`#1E2230` 근처)에 그린다. 7인치는 실제로 8×2 지만 창은 4×4 로 보여 주고 칸에 번호를 작게 적는다(번호가 같으니 혼동 없음).
- **끌어다 놓기**: `.exe/.lnk/.url/파일/폴더` 를 칸에 떨어뜨리면 → 이름 = 파일 이름(확장자 뺌, 보드 글꼴 밖 글자는 빼고, 8자에서 자름), 종류 = `.url`/`http` 면 사이트 아니면 프로그램, 대상 = 경로(`.lnk` 는 그대로 두고 아이콘만 풀어서), 아이콘 = 자동. 떨어뜨린 뒤 바로 그 칸이 편집 상태.
- 이름 검사(실시간): `Encoding.GetEncoding(51949)` 에 `EncoderExceptionFallback` 을 두고 **한 글자씩** 변환해 안 되는 글자를 빨간 밑줄/빨간 글자로 표시하고 저장을 막는다(안내: "이 글자는 보드에 나오지 않아요: ㉮"). 영문·숫자·기본 기호(ASCII)는 모두 된다. 길이: 7인치 kr16 기준 **한글 6자 / 영문 10자**를 넘으면 노란 경고(저장은 됨, 보드에서 `…` 로 잘림).
- 종류별 대상 칸: `app` [찾아보기]는 파일 열기(필터 exe·lnk·모든 파일) · `url` 은 글칸 + "https:// 로 시작" 자동 보정 · `keys` 는 글칸 + 옆에 작은 표(`^`=Ctrl `+`=Shift `%`=Alt `{F4}` `{ENTER}` 예) · `text` 는 여러 줄 글칸 · `builtin` 은 목록(바탕화면 보기 / 맨 앞 창 닫기 / 화면 잠그기 / 소리 끄기).
- 아이콘: 라디오를 바꾸면 즉시 72×72 미리보기 갱신(그리는 함수는 B 의 것). "기본 그림" 콤보는 16개 PNG 를 그림으로 보여 준다.
- **[저장하고 보드에 보내기]**: 검사 → `SaveDeck` → `RequestPush(true)` → 상태 줄에 `PushProgress` 글. 보드가 안 붙어 있으면 "저장했어요. 보드를 꽂으면 저절로 보내요".
- **[기본값으로]**: "16칸을 처음 상태로 되돌릴까요?" 예 → deck.json 을 기본 16개로 바꿔 저장하고 **`@deckreset` 을 보내게**(`RequestReset()` — B 쪽 네 번째 함수) + 상태 "보드를 기본 아이콘으로 되돌렸어요". 이후 보드는 `deck=0`, 도우미 deck.json 은 '기본값' 표시(`"default":true` 한 줄 추가) → 해시가 달라도 보내지 않는다. 사용자가 뭔가 바꿔 저장하면 `default` 가 빠지고 다시 보낸다.
- 창을 닫을 때 저장 안 한 변경이 있으면 "저장하지 않은 변경이 있어요. 저장할까요?"(예/아니오/취소).
- 글은 전부 쉬운 한국어. 전문어 쓰지 않기("SendKeys" 대신 "단축키 표기", 도움말 표로 보충).

## 8. 옛 판 호환

| 상황 | 동작 |
|---|---|
| 새 도우미 + 옛 보드(`@board ok` 만) | 연결·단축키는 지금처럼. 절대 보내지 않음. 설정 창 상태 줄 "이 보드는 아이콘 받기를 못 해요(보드 프로그램을 새로 구워야 해요)". |
| 옛 도우미(exe 1.0) + 새 보드 | 보드의 `@board ok deck=…` 를 옛 도우미는 `line == "@board ok"` 로 비교해 **못 알아본다** → 연결 확인이 안 된다. 그래서 새 보드는 **`@pc on` 에 두 줄을 답한다: `@board ok` 다음 줄에 `@board ok deck=<해시>`**. 옛 도우미는 첫 줄로 확인하고 둘째 줄은 버린다(아무 규칙에도 안 맞음). 새 도우미는 둘째 줄이 오면 그 값을, 안 오면(옛 보드) '보낼 수 없음'으로. `@pc?` 답도 같게. |
| 옛 도우미 + 새 보드에 사용자 설정이 있을 때 | 보드가 `@deck s3` 를 보내면 옛 도우미는 '모르는 단추' → `@deck fail s3` → 보드에 "열지 못했습니다 · 컴퓨터 도우미 설정을 확인하세요". 사용자가 새 도우미를 받으면 해결. |
| PowerShell 옛 판 `7inch/tools/deck_helper.ps1` | 최소 고침 두 줄: `$line -eq '@board ok'` → `$line.StartsWith('@board ok')`, 그리고 `@deck s<번호>` 가 오면 `deck.json` 이 있을 때 그 칸의 `kind/target` 을 같은 규칙으로 연다(없으면 fail). 파일 머리에 "옛 판 — exe 도우미를 쓰세요" 한 줄. 보내기 기능은 넣지 않는다. |
| apps.txt | 그대로 둔다. 옛 보드(영문 키)만 쓴다. 메뉴 '여는 프로그램 바꾸기(메모장)'는 "옛 보드용"으로 이름을 바꾼다. |
| 4인치 보드 | 코드 구조가 같으니 7인치와 **같은 줄 약속·같은 파일**. 차이는 10장. |

## 9. 시험 도구(B, 먼저 만든다) — `7inch/tools/deck_push.py`

```
python tools\deck_push.py COM5 --ls                  # @deckls 만
python tools\deck_push.py COM5 --png 3 그림.png      # PNG 하나를 다크 사각으로 만들어 칸 3 에 보내고 이름 "시험"
python tools\deck_push.py COM5 --cfg deck.json       # deck.json 전체를 보냄(아이콘은 icons\cell_N.bin)
```

pyserial + Pillow. 2~4장 규칙을 그대로 따르고 줄마다 보낸 것/받은 것/걸린 시간을 찍는다. A 는 이것으로 보드를 시험하고, C 는 보드 없이 창을 만든다(`RequestPush` 는 기록만 남기는 가짜로).
도우미를 켜 둔 채 쓰면 포트를 못 연다 → 도우미 메뉴 '잠깐 멈추기' 뒤 실행.

## 10. 7인치(UART)·4인치(USB) 차이

| | 7인치 / 7B | 4인치 |
|---|---|---|
| 선 | CH343 UART(VID 1A86), 115200bps, `Serial` = `HardwareSerial` | 칩 내장 USB-CDC(VID 303A), `Serial` = `HWCDC`, 속도는 USB 가 정함(115200 설정은 형식뿐) |
| RX 버퍼 | 기본 256B → **`Serial.setRxBufferSize(2048)` 를 `begin` 앞에** | 같은 함수 있음(HWCDC). 같은 자리에 같은 값 |
| 속도 | 아이콘 1개 ≈ 2~3초, 16개 ≈ 1분 | 거의 왕복 지연만, 16개 ≈ 10~20초 |
| 기록 줄 섞임 | UART 는 보드 기록도 같은 선 → 도우미는 `@` 줄만 본다(지금과 같음) | 같음 |
| 보드가 다시 켜질 때 | CH343 은 DTR/RTS 를 끈 채 연다(지금 코드) | USB-CDC 는 다시 켜지면 포트가 사라졌다 돌아온다 → 세션 폐기, 다음 `@board ok` 에서 다시 |
| 화면 | 8×2, 아이콘 72, 이름 kr16(800폭 이하면 kr14) | 4×4, 아이콘 72, 이름 kr14 |
| 안내 줄 | `s_deckState`(한 줄, `…` 잘림) | `s_deckState`(두 줄 wrap), `deckSay()` 헬퍼 있음 |
| 설정 장 [기본 아이콘으로] | 설정 화면(와이파이 아래) | 설정 장(tileview) |
| 굽기 중 | 도우미 '잠깐 멈추기' 파일(`%TEMP%\deck_helper.stop`)이 있으면 보내기도 멈춘다 | 같음 |

## 11. 마무리 점검표(세 사람 합쳐서)

1. 보드에 아무 설정 없음 → `@board ok` / `@board ok deck=0` 두 줄, 칸 누르면 `@deck explorer`.
2. 설정 창에서 칸 3 을 메모장으로 바꾸고 저장 → 60초 안에 보드 칸 3 이 바뀜(안내 줄 "아이콘 받는 중 1/1"), 누르면 `@deck s3` → 메모장 열림.
3. 보드를 껐다 켜도 칸 3 유지(`/deck/cfg.json`, `/deck/3.bin`).
4. 보내는 중에 선을 뽑음 → 보드 30초 뒤 "받기를 멈췄습니다", 다시 꽂으면 저절로 이어서(바뀐 것만) 완료.
5. 와이파이 받기 중에 저장 → `@deckbusy` → 끝난 뒤 보내짐.
6. [기본값으로] → 보드 즉시 내장 16개, `deck=0`.
7. 옛 exe 1.0 도우미로 새 보드 연결 → 초록(연결됨), 기본 키 동작.
8. 이름에 '㉮' 넣으면 빨갛게, 저장 안 됨. 한글 2350자 안의 '똠' 은 됨.
9. 7인치 전체 16개 보내기 ≤ 90초, 보내는 동안 시계 화면 멈춤 없음(deckPoll 매 바퀴, 그리기는 끝에 한 번).
10. `heap` 기록에서 내부 RAM 최대 빈 덩어리가 보내기 전후 5KB 이상 줄지 않음.
