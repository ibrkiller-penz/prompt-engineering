교실 알림판 '단축키' 도우미 (7인치·4인치 공통, 윈도 PC용 exe)

보드의 단축키 단추를 누르면 이 컴퓨터의 프로그램·사이트가 열리게 해 주는 작은 프로그램입니다.
보드의 16칸을 스트림덱처럼 마음대로 꾸밀 수 있고, 컴퓨터가 꺼지면 보드 화면도 꺼지게 알려 줍니다.
받는 곳: https://penedu.web.app/deck

■ 깔기 (한 번만)
  1. 교실알림판_도우미.exe 를 더블클릭합니다(압축 안에서 바로 눌러도 됩니다).
     파란 'Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행]. (서명이 없는 프로그램이라 처음 한 번 뜹니다)
  2. 화면 오른쪽 아래 작업 표시줄(^ 안쪽)에 알림판 아이콘이 생깁니다.
     관리자 권한은 필요 없고, 컴퓨터를 켤 때 저절로 켜집니다.
  3. 보드를 USB 로 꽂습니다. 7인치는 'UART' 단자, 4인치는 USB-C 단자.
     5초 안에 잡히면 아이콘이 초록으로 바뀌고 "알림판과 연결됐어요" 알림이 뜹니다.
  아이콘 색: 회색 = 알림판을 찾는 중, 초록 = 연결됨, 주황 = 잠깐 멈춤
  컴퓨터를 다시 켠 뒤 아이콘이 안 보이면: 시작 메뉴의 '교실알림판 도우미'를 눌러 켭니다.

■ 칸 꾸미기 (작업 표시줄 아이콘 오른쪽 클릭 → [단축키 꾸미기…])
  가운데: 보드 모양 미리보기(오른쪽 위에서 7인치·4인치 모양 바꾸기)
  오른쪽: 동작 목록 — '자주 쓰는 동작'과 아이콘 모음 205개(마이크로소프트·어도비·구글·한컴·학교·인공지능·윈도 도구…).
          찾기 칸에 '소리', '한글' 처럼 치면 바로 나옵니다.
  아래:   고른 칸의 이름·하는 일·대상·아이콘

  - 목록에서 끌어 칸에 놓기: 이름·하는 일·아이콘이 한꺼번에 들어갑니다(Shift 를 누른 채 놓으면 아이콘만).
  - 칸을 끌어 다른 칸에 놓기: 두 칸이 바뀝니다(Ctrl 을 누른 채 끌면 복사).
  - 프로그램·바로 가기·인터넷 주소를 칸에 끌어다 놓기: 저절로 채워집니다. 그림 파일을 놓으면 아이콘만 바뀝니다.
  - 칸 오른쪽 클릭: 눌러 보기 · 복사 · 붙여넣기 · 비우기 · 아이콘 바꾸기
  - [▶ 눌러 보기]: 보드 없이 이 컴퓨터에서 바로 해 봅니다(저장 전에도 됩니다).
  - 위 [한 번에 채우기]: 이 컴퓨터에 깔린 프로그램으로 / 수업용 / 업무용 / 발표·원격수업용
  - 위 [아이콘 모양]: 모음 아이콘을 보드 색 테마(기본·따뜻함·남색밤·밝은종이·고대비·숲초록)에 맞게 한꺼번에 바꿉니다.
  - 위 [더보기]: 내보내기·가져오기(다른 선생님과 설정 나누기) · 기본값으로 · 글꼴 안내
  - 키보드: 화살표 칸 옮기기, Enter 눌러 보기, Delete 비우기, Ctrl+C/V, F2 이름, Ctrl+S 저장, Ctrl+F 찾기
  - 이름: 보드 칸 아래 글자. 한글 6자·영문 10자 안쪽이 좋아요. 보드에 없는 글자는 빨갛게 알려 줍니다.
  - 하는 일: 프로그램 열기 / 사이트 열기 / 단축키 누르기(^=Ctrl, +=Shift, %=Alt, 예: ^c) / 글자 넣기 /
             내장 기능(바탕화면 보기·창 닫기·화면 잠그기·소리 끄기·소리 크게·작게·재생·다음 곡·이전 곡)
  - 여러 동작: 하는 일 [여러 동작] → [동작 차례 고치기…]. 칸 하나로 여러 일을 차례대로(동작 사이 기다리기 0~5초, 최대 12가지)
  - 단축키 칸의 [눌러서 넣기]: 키보드에서 단축키를 그대로 누르면 들어갑니다. Win 키 조합은 'Win 키도 함께'를 켭니다.
  - [자세히…]: 프로그램 = 함께 넘길 값(열 파일)·시작 폴더·관리자 권한·이미 열려 있으면 그 창을 앞으로
               사이트 = 브라우저(크롬·엣지·웨일·파이어폭스)·새 창 / 글자 = 넣은 뒤 Enter
  - 아이콘: 자동(프로그램 아이콘) / 글자 / 사이트 아이콘 받기 / 그림 파일(틀에 넣기·그대로) / 기본 그림 / 모음에서
    인공지능으로 아이콘을 직접 만드는 법은 '아이콘_직접만들기.md' 를 보세요(크기·프롬프트 예시).

  [저장하고 보드에 보내기]를 누르면 바뀐 아이콘만 보냅니다. 7인치는 아이콘 하나에 3~7초(16개 다 바꾸면 1분쯤).
  보드 단축키 화면 안내 줄에 '아이콘 받는 중 3/16' 이 보이고, 끝나면 '새 단축키를 받았습니다'.
  보드가 꽂혀 있지 않으면 다음에 꽂을 때 저절로 보냅니다.
  ※ 칸 꾸미기는 보드 프로그램이 새것이어야 합니다. 예전 보드면 '이 보드는 아이콘 받기를 못 해요' 가 나옵니다.
  ※ 설정은 %LOCALAPPDATA%\PeneduBoard 에 저장됩니다.

■ 끄기·지우기
  끄기.bat 을 더블클릭합니다(켜진 도우미를 끄고 저절로 켜기를 지웁니다. 꾸민 설정을 지울지는 물어봅니다).
  잠깐만 끄려면 아이콘 오른쪽 클릭 → [잠깐 멈추기] 또는 [끝내기].

■ 안 될 때 (아이콘 오른쪽 클릭 → [기록 보기], 마지막 줄을 봅니다)
  - '포트 열어 봄' 이 없다 → 컴퓨터가 보드를 못 봄(단자·데이터 케이블·7인치는 CH343 드라이버)
  - '알림판 아님(답 없음)' → 보드 프로그램이 예전 것이거나 같은 칩을 쓰는 다른 장치. 1분 뒤 다시 봅니다
  - '알림판 확인' 까지 있는데 안 열림 → 칸의 대상(프로그램 경로)을 고칩니다
  - 학교 백신이 exe 를 막으면: 백신의 '예외(허용)'에 교실알림판_도우미.exe 를 넣어 주세요.
