교실 알림판 '단축키' 도우미 (7인치·4인치 공통)

보드의 단축키 단추를 누르면 이 컴퓨터의 프로그램·사이트(탐색기, 네이버, 나이스, 한글 ...)가 열리게 해 주는 작은 프로그램입니다.
컴퓨터가 꺼지면 보드 화면도 꺼지게 알려 줍니다.

■ 쉬운 방법: 교실알림판_도우미.exe (권장)
  1. 교실알림판_도우미.exe 를 더블클릭합니다.
     파란 'Windows의 PC 보호' 창이 뜨면 [추가 정보] → [실행]. (서명이 없는 프로그램이라 처음 한 번 뜹니다)
  2. 화면 오른쪽 아래 작업 표시줄(^ 안쪽)에 알림판 아이콘이 생깁니다. 관리자 권한은 필요 없고, 컴퓨터를 켤 때 저절로 켜집니다.
  3. 보드를 USB 로 꽂습니다. 7인치는 'UART' 단자, 4인치는 USB-C 단자.
     5초 안에 잡히면 아이콘이 초록으로 바뀌고 "알림판과 연결됐어요" 알림이 뜹니다.
  아이콘을 오른쪽 클릭하면:
  - 단축키 꾸미기…: 보드의 16칸을 마음대로 바꿉니다(아래 '칸 꾸미기').
  - 여는 프로그램 바꾸기(옛 보드용, 메모장): 칸 꾸미기를 쓰지 않을 때 '단추 이름 = 열 것' 을 고칩니다.
  - 기록 보기 · 잠깐 멈추기(보드를 다시 구울 때) · 컴퓨터를 켤 때 저절로 켜기 · 끝내기
  아이콘 색: 회색 = 알림판을 찾는 중, 초록 = 연결됨, 주황 = 잠깐 멈춤
  컴퓨터를 다시 켠 뒤 아이콘이 안 보이면: 시작 메뉴의 '교실알림판 도우미'를 눌러 켭니다.
  보드 단축키 화면 오른쪽 아래 ⟳ 단추: 누르면 도우미 연결을 바로 다시 확인합니다.

■ 칸 꾸미기 (스트림덱처럼 — 보드를 다시 굽지 않아도 바뀝니다)
  1. 작업 표시줄 아이콘 오른쪽 클릭 → [단축키 꾸미기…]
  2. 왼쪽 16칸 중 하나를 누르고, 오른쪽에서 고칩니다.
     - 이름: 보드 칸 아래 글자. 한글 6자·영문 10자 안쪽이 좋아요. 보드에 없는 글자는 빨갛게 알려 줍니다.
     - 하는 일: 프로그램 열기 / 사이트 열기 / 단축키 누르기(^=Ctrl, +=Shift, %=Alt, 예: ^c) / 글자 넣기 / 내장 기능(바탕화면 보기·창 닫기·화면 잠그기·소리 끄기)
     - 아이콘: 자동(프로그램 아이콘을 가져와 보드 모양으로) / 글자 / 사이트 아이콘 받기 / 그림 파일 / 기본 그림 16개
     프로그램이나 바로 가기를 칸에 끌어다 놓으면 이름·대상·아이콘이 저절로 채워집니다.
  3. [저장하고 보드에 보내기]. 바뀐 아이콘만 보내며, 7인치는 아이콘 하나에 3초쯤(16개 다 바꾸면 1분쯤) 걸립니다.
     보드 단축키 화면 안내 줄에 '아이콘 받는 중 3/16' 이 보이고, 끝나면 '새 단축키를 받았습니다'.
     보드가 꽂혀 있지 않으면 다음에 꽂을 때 저절로 보냅니다. 보드가 날씨·시간표를 받는 중이면 끝난 뒤 보냅니다.
  4. 처음으로 되돌리기: 창의 [기본값으로] (보드도 기본 아이콘으로 돌아갑니다).
  ※ 칸 꾸미기는 보드 프로그램이 새것이어야 합니다. 예전 보드면 창 아래에 '이 보드는 아이콘 받기를 못 해요' 가 나옵니다.
  ※ 설정은 %LOCALAPPDATA%\PeneduBoard\deck.json 과 icons 폴더에 저장됩니다.

■ 백신이 exe 를 막을 때: 설치.bat (PowerShell 방식, 같은 일을 함)
  1. 이 압축 파일을 먼저 풉니다(압축 안에서 바로 실행하면 안 됩니다).
  2. 설치.bat 을 더블클릭합니다. 끄기·지우기는 끄기.bat.
  여는 프로그램은 %LOCALAPPDATA%\PeneduBoard\deck_helper.ps1 의 $Apps 표에서 고칩니다.
  ※ exe 와 설치.bat 중 하나만 쓰세요(exe 를 켜면 설치.bat 쪽 도우미는 저절로 꺼집니다).

연결이 안 되면 기록(%TEMP%\deck_helper.log)의 마지막 줄을 봅니다.
  - '포트 열어 봄' 이 없다 → 컴퓨터가 보드를 못 봄(단자·데이터 케이블·7인치는 CH343 드라이버)
  - '알림판 아님(답 없음)' → 보드 프로그램이 예전 것이거나 같은 칩을 쓰는 다른 장치. 1분 뒤 다시 봅니다
  - '알림판 확인' 까지 있는데 안 열림 → 여는 프로그램의 경로를 고칩니다
