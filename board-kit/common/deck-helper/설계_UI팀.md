# 설계(UI팀): '단축키 꾸미기' 창 — 스트림덱처럼 다시 배치하기

작성 2026-10-26 · UI팀. 대상 파일 `exe/DeckForm.cs`(창), `DeckGrid`(같은 파일, 보드 미리보기), 오른쪽 '동작 목록'은 새 컨트롤.
색·둥근 정도·그림자 같은 **겉모습 값은 디자인팀 문서가 정한다**. 이 문서는 **배치·크기·동작·이름표**만 정한다.

지킬 것: C# 5 문법만 · 통신 줄 형식(`DeckHelper.cs`) 안 건드림 · deck.json 모양(`DeckConfig.cs`) 안 바꿈 ·
지금 기능은 **하나도 빼지 않는다**(9장 대조표) · 화면 글은 쉬운 한국어, 영어 낱말 피함 · 스트림덱 그림·로고는 쓰지 않는다(배치와 느낌만).

---

## 1. 창 크기와 영역 나누기

- 창 안쪽 크기(ClientSize) **1240 × 720**, 가장 작은 크기도 같다(1366×768 노트북 화면에 들어감). 늘리면 **가운데 미리보기만** 커진다.
- 바탕은 어두운 색(스트림덱 느낌). 영역 사이 1px 선.

```
┌──────────────────────────── 위 막대 1240×56 ────────────────────────────────────┐
│ 단축키 꾸미기 ●저장 안 함 │ [7인치|4인치] │ 아이콘 모양:[기본(다크)▾] │ [한 번에 채우기▾][내보내기][가져오기] │
├──────────────────────────────────────────────────────────┬──────────────────────┤
│                                                          │ 동작 목록  300 폭     │
│        가운데: 보드 미리보기  940×360                     │ [🔍 찾기……………]       │
│   ┌────────────────────────────────────────────┐         │ ▼ 자주 쓰는 동작      │
│   │ [1][2][3][4][5][6][7][8]                    │         │   프로그램 열기 …     │
│   │ [9][10]……………………[16]      (7인치 모양)      │         │ ▶ 마이크로소프트  9   │
│   └────────────────────────────────────────────┘         │ ▶ 윈도  16            │
│  (처음 열면 한 줄 도움말)                                 │ ……                    │
├──────────────────────────────────────────────────────────┤ (y 56 ~ 656,         │
│        아래: 속성 창  940×240  (고른 칸 고치기)           │  높이 600)            │
├──────────────────────────────────────────────────────────┴──────────────────────┤
│ 맨 아래 1240×64: 상태 줄 ……(보내는 중 막대)   [기본값으로] [닫기] [저장하고 보드에 보내기] │
└─────────────────────────────────────────────────────────────────────────────────┘
```

| 영역 | 위치(x, y) | 크기(폭×높이) | 늘어날 때 |
|---|---|---|---|
| 위 막대 | 0, 0 | 1240×56 | 폭만 늘어남(오른쪽 단추는 오른쪽에 붙음) |
| 보드 미리보기 | 0, 56 | 940×360 | 폭·높이 모두 늘어남(칸 크기도 맞춰 커짐, 최대 칸 128) |
| 속성 창 | 0, 416 | 940×240 | 폭만 늘어남, 높이 240 고정 |
| 동작 목록 | 940, 56 | 300×600 | 높이만 늘어남, 폭 300 고정 |
| 맨 아래 막대 | 0, 656 | 1240×64 | 폭만 늘어남 |

안쪽 여백은 모두 **16px**, 컨트롤 사이 **8px**, 묶음 사이 **16px**.

## 2. 글꼴 — 에스코어 드림 3·4·5

| 쓰임 | 글꼴 | 크기 |
|---|---|---|
| 창 제목(위 막대 왼쪽), 속성 창 머리줄('3번 칸') | 에스코어 드림 **5 Medium** | 13pt / 11pt |
| 단추 글자, 묶음 이름(동작 목록), 미리보기 칸 이름 | 에스코어 드림 **5 Medium** | 9.5pt / 10pt / 9pt |
| 입력 칸·목록 항목·상태 줄·일반 글 | 에스코어 드림 **4 Regular** | 9.5pt |
| 도움말·예시·경고 아래 풀이·칸 번호 | 에스코어 드림 **3 Light** | 9pt / 8pt |

- 글꼴 파일 3개(`SCDream3.otf`, `SCDream4.otf`, `SCDream5.otf`)를 exe 안에 묻는다(`build_exe.ps1` 의 `/resource:`). 이름은 개발팀이 정해도 된다.
- 켤 때 한 번: `PrivateFontCollection.AddMemoryFont` **와** `gdi32 AddFontMemResourceEx` 를 둘 다 부른다
  (TextBox·ComboBox 같은 기본 컨트롤은 GDI 로 그려서 앞의 것만으로는 글꼴이 안 바뀐다). 직접 그리는 곳은 `TextRenderer` 사용.
- 글꼴을 못 읽으면 지금처럼 `맑은 고딕` 으로(창이 안 열리면 안 된다). 글꼴 3개를 한 곳(`Ui.F3/F4/F5(크기)`)에서만 만든다.
- 묻기 전에 에스코어 드림 사용 허락 범위(프로그램 안에 넣어 나눠 주기)를 개발팀이 한 번 확인한다.

## 4. 가운데: 보드 미리보기 (940×360)

- 보드를 닮은 **둥근 테두리 판**(베젤) 위에 **둥근 칸 16개**(진짜 단추처럼: 둥근 모서리 12px, 살짝 위에서 빛, 누르면 1px 내려감).
- 칸 안: 위에 아이콘(지금 `Tile` 72×72 그림을 줄여 그림), 아래에 이름 한 줄(넘치면 …), 왼쪽 위 작은 칸 번호(3 Light 8pt).
- 칸 번호 차례는 지금과 같다(0~15, 왼쪽 위부터). 7인치: 줄 = i/8, 칸 = i%8 / 4인치: 줄 = i/4, 칸 = i%4.

| 모양 | 칸 크기 | 칸 사이 | 판 안쪽 여백 | 판 전체 | 칸 안 아이콘 | 이름 글자 |
|---|---|---|---|---|---|---|
| 7인치 2줄×8칸 | 96×96 | 12 | 28 | 908×276 | 60×60 | 9pt(5 Medium) |
| 4인치 4×4 | 72×72 | 8 | 20 | 352×352 | 44×44 | 8pt(5 Medium), 4자 넘으면 … |

- 판은 영역 가운데. 창을 키우면 칸이 같은 비율로 커진다(최대 128).
- 판 아래 작은 글(3 Light): `7인치 보드 · 2줄 × 8칸` / `4인치 보드 · 4줄 × 4칸`.
- 칸 상태 그리기: 고른 칸 = 파란 테두리 3px / 끌어서 위에 올림 = 밝은 점선 테두리 / 빈 칸 = 흐린 `+` 와 `끌어다 놓기` / 이름에 보드에 없는 글자가 있음 = 칸 오른쪽 위 빨간 점.

### 처음 열 때 한 줄 도움말(초보 안내)
판 위쪽에 높이 32 띠: `오른쪽 목록에서 동작을 끌어 칸에 놓으세요. 칸을 누르면 아래에서 이름과 아이콘을 고칠 수 있어요.` `[알겠어요]`
- [알겠어요]를 누르면 다음부터 안 보인다(도우미 설정 폴더의 작은 파일에 기억, deck.json 은 건드리지 않음).
- 16칸이 모두 비어 있으면 [알겠어요] 와 상관없이 다시 보인다: `비어 있어요. 위의 [한 번에 채우기]로 시작해도 좋아요.`

## 5. 오른쪽: 동작 목록 (300×600)

- 맨 위 `동작` 머리(5 Medium 11pt) + 찾기 칸(268×30, 흐린 안내 글 `찾기 (예: 한글, 소리, 유튜브)`).
- 그 아래 접고 펴는 묶음. 묶음 머리 높이 32(`▶/▼ 이름  개수`), 항목 줄 높이 32(작은 그림 24×24 + 이름 + 오른쪽 흐린 꼬리표).
- 꼬리표(무엇을 하는 항목인지): `프로그램` · `사이트` · `단축키` · `글자` · `내장` · `그림만`(목록.json kind 가 빈 것 — 하는 일 없이 아이콘만 바꿈).
- 찾기: 글자를 넣으면 모든 묶음을 펴서 이름·묶음 이름에 그 글자가 든 항목만 보인다. 없으면 `찾는 것이 없어요`. Esc 로 지우기.
- 펴고 접은 상태는 창이 열려 있는 동안 기억. 처음엔 ①만 펴 있음.

## 6. 끌어다 놓기 규칙

| 무엇을 | 어디에 | 결과 | 지금 함수 |
|---|---|---|---|
| 동작 목록 ① 앞 넷(프로그램 열기 등) | 칸 | 5장 표대로 하는 일을 바꾸고 그 칸을 고름 | `SetKind` 와 같은 처리 |
| 동작 목록 ① 내장 기능 9 | 칸 | 이름·하는 일·대상·아이콘 함께 | 새(작은 함수) |
| 동작 목록 ② 모음 항목 | 칸 | **이름·하는 일·대상·아이콘 함께**(`ApplyLib(c, it, LibSrc(테마, key), true)`). `그림만` 항목은 아이콘만(빈 칸이면 이름도). 대상이 빈 추천(예: 학교 누리집)이면 상태 줄에 `주소를 넣어 주세요` 와 함께 대상 칸에 초점 | `ApplyLib` |
| 모음 항목을 **Shift 누른 채** 놓기 | 칸 | 아이콘만 바꿈(이름·하는 일 그대로) | `ApplyLib(…, false)` |
| 칸 | 다른 칸 | 두 칸 **바꾸기** | `SwapCells` |
| 칸을 **Ctrl 누른 채** | 다른 칸 | 복사(놓은 칸이 같은 내용이 됨) — 있으면 좋음 | `Clone` |
| 바깥: 프로그램·바로 가기(.exe .lnk .bat .cmd .url) | 칸 | 칸 채우기(이름은 파일 이름) | `FillFromPath(i, path, true)` |
| 바깥: 인터넷 주소 글자(브라우저 주소창에서 끌기) | 칸 | 사이트 열기 칸 | `FillFromPath` |
| 바깥: 그림 파일 | 칸 | 아이콘만 바꿈(틀에 넣기 / 그대로 묻기) | `SetIconFromImage` |
| 바깥: 그림 파일 | 속성 창 아이콘 상자 | 고른 칸 아이콘 바꿈 | `SetIconFromImage(sel, …)` |
| 무엇이든 | 칸 밖·동작 목록 | 아무 일 없음(마우스 모양 '금지') | |

- 끌고 있는 동안 놓일 칸에 점선 테두리. 놓은 뒤 그 칸을 고르고 상태 줄에 `3번 칸에 '한글'을 넣었어요.`
- 동작 목록 항목 **두 번 누르기** = 지금 고른 칸에 넣기(끌기 어려운 분용). 목록 오른쪽 클릭: `고른 칸에 넣기` · `아이콘만 넣기`.

## 7. 아래: 속성 창 (940×240)

```
┌ 아이콘 상자 ┐  3번 칸 · 7인치 윗줄 3번째 · 4인치 1줄 3번째        [▶ 눌러 보기]
│  120×120   │  이름    [한글          ]  보드 칸 아래에 나오는 이름이에요.   [이 칸 비우기]
│ (그림)      │  하는 일 [프로그램 열기|사이트 열기|단축키 누르기|글자 넣기|내장 기능]
└────────────┘  대상    [C:\…\Hwp.exe                         ][찾아보기…]
 [아이콘 바꾸기 ▾]        [찾아보기]로 고르거나, 프로그램·바로 가기를 위 칸에 끌어다 놓아요.
```

| 자리 | 위치(속성 창 안) | 크기 |
|---|---|---|
| 아이콘 상자(누르면 `아이콘 바꾸기` 메뉴, 그림 끌어다 놓기 됨) | 16, 16 | 120×120 |
| `아이콘 바꾸기 ▾` 단추 + 지금 방식 글(예: `모음에서`) | 16, 144 | 120×30 / 120×20 |
| 머리줄(칸 번호·자리, 5 Medium 11pt) | 156, 16 | 600×24 |
| 이름표 열(이름·하는 일·대상) | 156 | 64 폭 |
| 입력 열 | 228 | 520 폭 |
| 오른쪽 단추 열 `▶ 눌러 보기`, `이 칸 비우기` | 780, 16 / 780, 58 | 144×34 |

- 이름: 입력 칸 220×28(최대 20자) + 오른쪽에 경고 한 줄. 경고 규칙은 지금 `CheckName` 그대로(빨강 = 보드에 없는 글자·너무 김 → 저장 막음 / 노랑 = 조금 김 / 회색 = 안내).
- 하는 일: 라디오 단추 대신 **이어 붙은 다섯 단추**(누른 것만 밝게) 520×32. 빈 칸이면 아무것도 안 눌린 모양.
- 아이콘 방식은 라디오 대신 `아이콘 바꾸기 ▾` 메뉴로: `자동(프로그램에서)` · `글자` · `사이트 아이콘 받기` · `그림 파일…` · `기본 그림 ▸`(16개 그림이 든 하위 메뉴, 지금 `cmbIcon`) · `모음에서 고르기…`(지금 `LibraryPicker` 창). 쓸 수 없는 것은 흐리게(자동은 프로그램 열기일 때만, 사이트 아이콘은 사이트 열기일 때만 — 지금 `LayoutKind` 규칙). 지금 방식 앞에 ●.

## 10. 키보드

초점이 **미리보기**에 있을 때(칸을 누르면 미리보기로 초점이 감):

| 키 | 하는 일 |
|---|---|
| ← → ↑ ↓ | 고른 칸 옮기기(7인치 모양은 8칸씩, 4인치 모양은 4칸씩 위아래. 끝에서 멈춤) |
| Enter | ▶ 눌러 보기 |
| Delete | 이 칸 비우기(바로 비움. 실수하면 Ctrl+V 로 되살릴 수 있게 비우기 전 내용을 '복사'에 넣지는 않는다 — 단순하게) |
| Ctrl+C / Ctrl+V | 칸 복사 / 고른 칸에 붙여넣기 |
| F2 | 이름 입력 칸으로 |

어디서나: Ctrl+S = 저장하고 보드에 보내기 · Ctrl+F = 동작 찾기 칸으로 · Tab 은 미리보기 → 속성 창 → 동작 목록 → 아래 단추 차례.
입력 칸 안에서는 Delete·Ctrl+C/V·화살표가 **글자 고치기**로만 동작한다(칸을 지우지 않음).

## 11. 오른쪽 클릭 메뉴

미리보기 칸:
```
▶ 눌러 보기(이 컴퓨터에서)      Enter
──────────
복사                          Ctrl+C
붙여넣기                       Ctrl+V   (복사한 것이 없으면 흐리게)
비우기                         Delete
──────────
아이콘 바꾸기  ▸  (7장 메뉴와 같음)
```
동작 목록 항목: `고른 칸에 넣기` · `아이콘만 넣기`.

## 12. 저장 안 했을 때 표시

- 창 제목: `● 단축키 꾸미기 — 교실 알림판` (저장하면 ● 빠짐)
- 위 막대 제목 옆 `● 저장 안 함`(주황), 맨 아래 저장 단추 왼쪽 ●.
- 닫을 때 지금 질문 그대로: `저장하지 않은 변경이 있어요. 저장할까요?` (예/아니요/취소).
- 7인치/4인치 바꾸기·찾기·묶음 펴기는 '바뀜'이 아니다(● 안 붙음).

## 14. 개발팀에 넘길 쪼개기(제안)

1. `Ui` 글꼴 묶음(에스코어 3·4·5 묻기, 못 읽으면 맑은 고딕) — 혼자 먼저.
2. `DeckGrid` 다시 그리기: 둥근 칸, 7인치/4인치 모양, 늘어나기, 끌기 표시, 키보드.
3. `ActionList` 새 컨트롤(직접 그리는 목록: 묶음 접기·찾기·끌기 시작 `DataObject("PeneduAction", 문자열)` — 모음은 `lib:<key>`, 자주 쓰는 동작은 `kind:app` / `builtin:#desktop`).
4. 속성 창 재배치(지금 컨트롤 재사용, 라디오→이어 붙은 단추, 아이콘 메뉴).
5. 위·아래 막대, 저장 표시, 처음 도움말.
겉모습 값(색 이름·둥근 정도)은 디자인팀 문서의 이름을 그대로 쓴다.
