# 단축키 아이콘 직접 만들기 (인공지능 그림·내 그림)

보드 단추 한 칸의 그림은 **72×72 점**입니다. 크게 만들어 넣으면 탭덱이 알아서 줄여 보드로 보냅니다.

## 1. 그림 규격

| 항목 | 권장 |
|---|---|
| 크기 | **정사각형 512×512 이상**(1024×1024 가장 좋음) — 작게 그리면 줄일 때 뭉개집니다 |
| 파일 | **PNG**, 배경 **투명** (투명이 안 되면 단색 배경도 괜찮음) |
| 그림 | 가운데에 **기호 하나**, 칸의 약 80%를 채움 |
| 모양 | 굵은 선, 평면(flat), 색 2~3개, 진한 대비 |
| 피할 것 | 작은 글씨, 가는 선, 사진 같은 그림, 복잡한 배경 — 72점에서는 안 보입니다 |
| 글자 | 넣고 싶으면 **한두 글자**만, 아주 굵게 |

## 2. 넣는 방법 두 가지 (탭덱 설정 창 → 칸 고르기 → 아이콘 → 그림 파일)

- **틀에 넣기**: 투명 배경의 기호만 만들었을 때. 탭덱이 다른 칸과 같은 '다크 사각 테두리'를 씌워 줍니다(가장 깔끔).
- **그대로**: 테두리까지 다 그린 완성 그림일 때. 테두리를 또 씌우지 않고 그대로 보냅니다.

## 3. 인공지능에게 줄 말(프롬프트) — 고쳐 쓰세요

ChatGPT·제미나이·코파일럿·캔바 같은 그림 인공지능에 붙여 넣고, `[ ]` 안만 바꾸면 됩니다.

**① 기호만(틀에 넣기용, 가장 추천)**
```
[출석부] 를 나타내는 앱 아이콘 기호 하나를 그려 줘.
정사각형 1024x1024, 배경은 완전히 투명(PNG).
가운데에 기호 하나만, 화면의 80% 크기. 굵은 선의 평면(flat) 스타일,
색은 [밝은 초록] 한 가지와 흰색만. 글씨·그림자·배경 무늬는 넣지 마.
아주 작게(72픽셀) 줄여도 알아볼 수 있게 단순하게.
```

**② 완성 타일(그대로용, 보드 테마와 맞추기)**
```
[유튜브 재생 목록] 앱 아이콘을 그려 줘. 정사각형 1024x1024.
둥근 모서리 사각형(모서리 반지름 약 24%), 안쪽은 아주 어두운 남회색(#1E222C),
테두리는 [빨간색] 굵은 선(두께 약 5%), 테두리 안쪽에 같은 색이 은은하게 번지는 빛.
가운데 [재생 단추] 기호를 같은 계열의 밝은 색으로, 칸의 70% 크기, 굵은 선, 평면 스타일.
글씨 없이, 사각형 바깥은 투명.
```

**③ 테마별로 바꿀 말** (②에서 안쪽·테두리 부분만 바꿈)

| 보드 테마 | 안쪽 색 | 느낌 |
|---|---|---|
| 기본·남색밤 | #1E222C / #16213A | 어두운 바탕, 네온 테두리, 은은한 빛 |
| 따뜻함 | 테두리 색이 살짝 섞인 어두운 갈색(#2B231E) | 빛 없이, 따뜻한 크림빛 기호 |
| 밝은종이 | 크림색(#FFFCF5) | 빛 없이, 진한 색 기호(흰 바탕용) |
| 고대비 | 검정(#000000) | 아주 굵은 밝은 테두리, 빛 없음 |
| 숲초록 | 테두리 색이 옅게 섞인 짙은 초록(#15241F) | 얇은 테두리, 파스텔 기호 |

## 4. 잘 안 될 때
- **배경이 하얗게 나와요** → "배경 투명"을 다시 말하거나, 캔바의 '배경 제거'를 쓰세요. 흰 배경 그대로 '틀에 넣기'를 하면 흰 네모가 보입니다.
- **보드에서 흐릿해요** → 선을 더 굵게, 색을 더 적게 해 달라고 하세요("선 두께 두 배, 색은 하나만").
- **회사 로고**는 그대로 베끼지 말고, 그 회사 색의 글자 한두 개(예: 파란 W)로 만드세요. 탭덱에 이미 들어 있는 '모음'을 먼저 찾아보세요.
