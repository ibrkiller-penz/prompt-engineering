# 03. 시간표 자료 형식 — 어디를 보나

보드가 받는 파일(`index.json`, `t/NNN.json`, `where.json`)의 모양은 **`tools\data-format.md`** 에 칸 하나까지 적어 두었습니다.

## 가장 빨리 이해하는 법
1. `node tools\make_sample_data.mjs` 를 돌려 `site\public\board\` 에 샘플을 만든다.
2. `site\public\board\t\001.json` 을 메모장(또는 VS Code)으로 열어 `data-format.md` 와 나란히 본다.
3. 칸 하나 = `[종류, 위 글, 아래 글, 꼬리표]` 이고, 하루는 7칸, 한 주는 월~금 5일이다.

## 내 학교 자료로 바꾸는 길
- **AI 도우미와 함께**: `tools\data-format.md` 와 샘플 파일 한 개를 도우미에게 주고 "내 시간표(엑셀·표)를 이 모양의 JSON 으로 바꿔 주세요"라고 합니다. 만든 뒤에는 도우미에게 **날짜가 월요일로 시작하는지, 하루가 7칸인지, 목록의 name 이 board_config.h 와 같은지** 검사하게 하세요.
- **직접**: `tools\make_sample_data.mjs` 의 `SUBJECTS`·`TEACHERS`·`CLASSES`·`HOLIDAYS`·`EVENTS` 를 우리 학교 값으로 바꿔 돌려도 됩니다(간단한 시간표에 알맞습니다).
- 학생·교사 **실명을 넣을 때**는 호스팅 주소가 공개 주소라는 점을 기억하세요(`data-format.md` 4장).

올리는 방법은 `docs\01_Firebase_호스팅_올리기.md` 입니다.
