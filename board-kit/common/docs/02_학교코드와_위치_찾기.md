# 02. 급식 학교 코드(NEIS)와 학교 위치(위도·경도) 찾기

시계 화면의 **급식**과 **날씨·미세먼지**를 쓰려면 `firmware\include\board_config.h` 에 학교 정보를 넣습니다.
**안 넣어도 보드는 정상으로 돕니다.** 비워 두면 그 칸에만 "설정 필요"라고 보입니다.

| 값 | 어디에 쓰나 | 안 넣으면 |
|---|---|---|
| `NEIS_ATPT_CODE`, `NEIS_SCHOOL_CODE` | 오늘 급식 메뉴 | 급식 칸에 "급식 설정 필요" |
| `WEATHER_LAT`, `WEATHER_LON` | 날씨·미세먼지 | 날씨 칸에 "위치 설정 필요" |
| `SUNEUNG_DATE` | 수능 D-day | 아무것도 안 보임(고3 교실만 쓰면 된다) |

## A. 교육청 코드와 학교 코드 (NEIS)
NEIS 교육정보 개방 포털은 **인증키 없이** 쓸 수 있습니다(키 없이는 결과가 최대 5건).

1. 브라우저 주소창에 아래를 붙여 넣고 `학교이름` 만 우리 학교로 바꿉니다(한글 그대로 써도 됩니다).
   ```
   https://open.neis.go.kr/hub/schoolInfo?Type=json&SCHUL_NM=학교이름
   ```
2. 나온 글에서 두 값을 찾습니다.
   - `ATPT_OFCDC_SC_CODE` → **교육청 코드**(영문 1글자 + 숫자 2글자, 예: `B10` 은 서울 — 우리 학교 값을 쓰세요) → `NEIS_ATPT_CODE`
   - `SD_SCHUL_CODE` → **학교 코드**(숫자 7자리) → `NEIS_SCHOOL_CODE`
   - 같은 이름의 학교가 여러 개면 `ORG_RDNMA`(주소)로 우리 학교를 가립니다.
3. `board_config.h` 에 따옴표 안에 넣습니다.
   ```c
   #define NEIS_ATPT_CODE "교육청코드"
   #define NEIS_SCHOOL_CODE "학교코드"
   ```
4. **확인**(선택): 아래 주소에 두 코드와 평일 날짜(`20261006` 꼴)를 넣어 열면 급식 메뉴가 나옵니다.
   ```
   https://open.neis.go.kr/hub/mealServiceDietInfo?Type=json&ATPT_OFCDC_SC_CODE=교육청코드&SD_SCHUL_CODE=학교코드&MLSV_YMD=20261006
   ```
   (방학·주말이거나 학교가 급식 정보를 안 올렸으면 "정보 없음"이 나옵니다. 보드에는 "오늘은 급식이 없습니다"로 보입니다.)

## B. 학교 위치(위도·경도)
날씨는 **Open-Meteo**(무료, 열쇠 없음)에서 이 좌표의 값을 받습니다. 학교 정문 근처면 충분합니다(소수점 넷째 자리까지).

방법 1 — Google 지도: 학교 위치에서 **마우스 오른쪽 클릭** → 맨 위에 나오는 숫자 두 개(예: `37.5665, 126.9780`)를 클릭하면 복사됩니다. **앞이 위도(LAT), 뒤가 경도(LON)** 입니다.

방법 2 — OpenStreetMap(openstreetmap.org): 학교를 검색해 지도에서 우클릭 → "여기 주소 보기"에 좌표가 나옵니다.

```c
#define WEATHER_LAT "위도"   // 한국은 보통 33~38 사이
#define WEATHER_LON "경도"   // 한국은 보통 124~132 사이
```
- 따옴표 안에 **숫자만**(공백·글자 없이) 넣습니다.
- **미세먼지**는 측정소 값이 아니라 Open-Meteo 의 **모델 추정값**입니다(대략적인 참고용).

## C. 수능 날짜(선택)
```c
#define SUNEUNG_DATE "2026-11-19"   // 해마다 다르다. 학사일정을 보고 YYYY-MM-DD 로
```
시계 화면에 `수능 D-n` 이 보이고, 수능 다음 날부터 숨겨집니다. 비워 두면(`""`) 아예 안 나옵니다. 7인치는 설정 > 보이기의 D-day 단추로도 끌 수 있어요.

값을 바꾼 뒤에는 **다시 빌드하고 보드에 올려야** 반영됩니다.
