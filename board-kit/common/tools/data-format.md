# 알림판 자료(JSON) 형식 — 칸 하나까지 풀어 쓴 설명

보드는 **내 Firebase 사이트의 `board/` 폴더**에서 아래 파일을 받아 갑니다(1시간마다 잠깐).
이 설명은 `firmware/src/main.cpp` 가 실제로 읽는 항목만 적었습니다. (JSON = 사람이 읽을 수 있는 자료 글 형식입니다.)

```
board/
  index.json        시간표 목록 (설정 화면의 '볼 시간표' 칸을 채운다)       ← 꼭 필요
  t/001.json …      시간표 한 개당 파일 한 개 (학년도 전체 주차)            ← 꼭 필요
  where.json        '찾기' 화면용 (선생님 전체 × 오늘부터 수업일 10일)      ← 없어도 된다(찾기 화면만 비어 있음)
```

샘플은 `node tools/make_sample_data.mjs` 로 만듭니다. 내 학교 자료는 **같은 모양**으로 직접(또는 AI 도우미와 함께) 만들어 올리면 됩니다.

---

## 1. `index.json` — 목록

```json
{
  "generated": "2026-10-06T00:00:00.000Z",
  "mods": 0,
  "periods": ["08:40","09:40","10:40","11:40","13:30","14:40","15:40"],
  "items": [
    { "name": "국어A",     "label": "국어A 선생님", "kind": "teacher", "file": "t/001.json" },
    { "name": "1학년1반",  "label": "1학년 1반",    "kind": "class",   "file": "t/013.json" }
  ]
}
```

| 항목 | 뜻 | 보드가 쓰는가 |
|---|---|---|
| `items[].name` | 시간표 이름. **보드에 저장되는 값**이고 `board_config.h` 의 `BOARD_DEFAULT_TT` 와 똑같이 써야 한다 | 예 |
| `items[].label` | 설정 화면 목록에 보이는 글(없으면 name) | 예 |
| `items[].file` | 이 시간표 파일의 위치(`board/` 기준). 보드는 `BOARD_BASE_URL + file` 을 받는다 | 예 |
| `items[].kind` | `teacher`(선생님) 또는 `class`(학급·특별실) | 목록 용도(파일 안의 `kind` 가 실제 동작을 정한다) |
| `generated`, `mods`, `periods` | 만든 시각 · 수업 교체 건수 · 교시 시작 시각 | 아니오(참고용). 교시 시각은 `main.cpp` 의 `PERIOD_START` 에 들어 있다 |

`items` 가 없거나 비어 있으면 목록을 못 쓴 것으로 보고 이전 저장본을 유지합니다.

## 2. `t/NNN.json` — 시간표 파일

```json
{
  "name": "국어A", "kind": "teacher", "hours": "18", "home": "1학년1반",
  "weeks": [
    { "n": 1, "days": [
        { "date": "2026-03-02", "dow": "월", "type": "normal", "tag": "",
          "lunch": "", "night": "수학A",
          "cells": [ ["n","국어","101",""], ["", "", "", ""], … 모두 7칸 ] },
        … 월~금 5일
    ] },
    … 학년도 전체 주
  ]
}
```

### 위쪽(파일 전체)

| 항목 | 뜻 |
|---|---|
| `name` | 시간표 이름(목록의 `name` 과 같게). 위쪽 막대 제목에 쓰인다 |
| `kind` | **`teacher`** 이면 제목 뒤에 " 선생님"이 붙고, 빈 칸을 '공강'으로 보이며, 급식지도·야자 감독·공강지도 같은 **'할 일'을 모아 보여 준다**. 그 밖의 값(`class`)은 학급·특별실 시간표로 본다 |
| `hours` | 주당 수업 시간 수(글자). 주간 화면 위쪽 줄에 "주당 18시간"으로 보인다 |
| `home` | 담임 반 이름(없으면 `""`). 주간 화면 위쪽 줄과 '찾기'에 쓰인다 |
| `weeks` | 주(週) 목록. **날짜가 빠른 순서**로 둔다 |

### 주(`weeks[]`)

| 항목 | 뜻 |
|---|---|
| `n` | 몇 주차인지(1부터). 주간 화면에 "12주차 3/2 ~ 3/6"으로 보인다 |
| `days` | **월~금 5일**(휴일도 빼지 말고 5일 모두). 첫 날(`days[0]`)은 **월요일**이어야 한다. 보드는 첫 날 날짜로 '이번 주'를 찾는다 |

### 하루(`days[]`)

| 항목 | 뜻 |
|---|---|
| `date` | `"YYYY-MM-DD"` (한국 날짜). 보드의 오늘 날짜와 맞춰 오늘 칸을 찾는다. 오늘이 없으면(주말·방학) 다음 수업일을 보인다 |
| `dow` | 요일 글자 `"월"`~`"금"` |
| `type` | `"normal"`, `"holiday"`, `"exam"`, `"festival"` 등. **보드가 구별하는 것은 `"holiday"` 하나뿐**(휴일이면 밤처럼 2분 뒤 화면 불을 끈다) |
| `tag` | 그날 제목 옆에 붙는 붉은 꼬리표(예: `"삼일절"`, `"중간고사"`). 없으면 `""` |
| `lunch` | 선생님 시간표: 이 선생님이 그날 **급식지도**이면 `"급식지도"`, 아니면 `""` · 학급 시간표: 그날 점심 줄에 보일 글(예: 급식지도 선생님 이름들) |
| `night` | 그날 **야자 감독** 선생님 이름(없으면 `""`). 이 값이 시간표의 `name` 과 같으면 '할 일'에 "야자 감독 18:30"이 뜬다 |
| `cells` | **정확히 7칸**(1~7교시). 아래 '칸' 참고. 7칸보다 적으면 빈 칸으로 취급되지 않을 수 있으니 항상 7칸 |

### 칸(`cells[p]`) = `[종류, 위 글, 아래 글, 꼬리표]` — 글자 4개짜리 목록

| 자리 | 이름 | 뜻 |
|---|---|---|
| 0 | 종류 | 한 글자(아래 표). 빈 칸이면 `""` |
| 1 | 위 글 | 큰 글씨. 선생님 시간표는 **과목**, 학급 시간표도 **과목** |
| 2 | 아래 글 | 작은 글씨. 선생님 시간표는 **교실**, 학급 시간표는 **선생님 이름** |
| 3 | 꼬리표 | 위 글 옆에 붙는 주황색 작은 딱지(예: `"보강"`). 없으면 `""` |

**종류(한 글자)와 색** — 화면이 어두운 바탕이라 칸 전체가 아니라 **테두리 색**으로 구별합니다.

| 종류 | 뜻 | 테두리 색 | 위 글 / 아래 글 / 꼬리표 예 |
|---|---|---|---|
| `n` | 보통 수업 | 초록 `#34d399` | `["n","국어","101",""]` |
| `d` | 당겨온 수업(다른 날 수업을 옮겨옴) | 주황 `#fb923c` | `["d","과학","102","당겨옴 금3"]` |
| `j` | 공강지도 · 보강 · 대강(아래 설명) | 남보라 `#818cf8` | `["j","공강지도","도서관","지도"]` |
| `x` | 결강(수업이 없어짐) | 빨강 `#f87171` | `["x","영어","대강 사회A","결강"]` |
| `c` | 창체(동아리·자율 등) | 보라 `#a78bfa` | `["c","창체","",""]` |
| `e` | 시험 | 분홍 `#f472b6` | `["e","1학기 중간고사","",""]` |
| `f` | 행사 | 하늘 `#38bdf8` | `["f","체육대회","",""]` |
| `h` | 휴일 | 연한 빨강 `#f87171` | `["h","삼일절","",""]` |
| `""` | 빈 칸(공강) | 회색 | `["","","",""]` |

- 시험·행사·휴일처럼 **하루 종일**인 날은 7칸 모두 같은 종류로 채우고, 제목은 **첫 칸에만** 쓰면 깔끔합니다(나머지 칸의 위 글은 `""`).
- 선생님 시간표에서 빈 칸은 화면에 **"공강"** 이라고 흐리게 보입니다. 학급 시간표의 빈 칸은 아무 글도 없습니다.
- **'할 일' 목록**(시계 화면 왼쪽 가운데): 선생님 시간표에서 종류가 `j` 이고 꼬리표가 정확히 `"지도"` 이면 "N교시 공강지도 ○○", `"보강"` 이면 "N교시 보강 ○○"으로 모아 보여 줍니다. `○○` 는 **아래 글에서 `" · "`(점 양옆 빈칸) 앞부분**입니다(예: `"201 · 수학A 대신"` → `201`). 그래서 보강 칸의 아래 글은 `"교실 · 누구 대신"` 모양으로 씁니다.
- 시간표를 받으면 **오늘(없으면 다음 수업일)** 한 날만 큰 화면에 보이고, 주간표는 '시간표' 탭에서 봅니다.

## 3. `where.json` — 선생님 찾기

```json
{
  "generated": "2026-10-06T00:00:00.000Z",
  "dates": ["2026-10-06", "2026-10-07", … 최대 10개(오늘부터의 수업일)],
  "teachers": [
    { "n": "국어A", "h": "1학년1반",
      "d": [ ["n:101 국어", "", "j:공강지도 도서관", …7칸], … dates 와 같은 개수의 날 ] }
  ]
}
```

| 항목 | 뜻 |
|---|---|
| `dates` | 오늘부터의 수업일(`YYYY-MM-DD`). `d` 의 날 순서와 1:1 |
| `teachers[].n` | 선생님 이름(찾기 화면에 단추로 나열된다. 배열 순서 그대로) |
| `teachers[].h` | 담임 반(없으면 `""`) |
| `teachers[].d[날][교시]` | `"종류:글"` 한 줄. 종류는 칸 종류와 같은 한 글자. 수업(`n`)은 `"n:교실 과목"`, 그 밖은 `"j:공강지도 도서관"`처럼 위 글·아래 글을 공백으로 이은 것. **빈 칸은 `""`**(= 공강 → "공강 (교무실)"로 보인다) |

`teachers` 가 없으면 `where.json` 을 못 쓴 것으로 봅니다(찾기 화면은 "자료를 받는 중"으로 남는다).

## 4. 크기 · 주의

- 보드 저장 공간(LittleFS)은 약 **3.4MB**이고, 시간표 한 개(`tt.json`)·목록·찾기·날씨·급식 파일이 함께 들어갑니다. 시간표 파일은 **300KB 이하**(샘플은 약 60KB, 52주)를 권합니다. 받는 중에 끊기거나 JSON 이 깨져 있으면 보드는 **저장본을 바꾸지 않습니다**.
- 파일은 **UTF-8**, 한글 그대로 쓰면 됩니다. 단, 보드 글꼴에는 **KS X 1001 한글 2,350자**와 영문·숫자·기본 기호만 들어 있습니다. 드문 글자(예: 일부 이름의 글자)는 **빈 네모/빈칸**으로 보입니다(필요하면 `firmware/fonts/src/hangul2350.txt` 에 글자를 더하고 `build_fonts.cjs` 로 글꼴을 다시 만든다).
- 학생 이름 등 **개인정보는 이 자료에 넣지 않는 것**을 권합니다. Firebase 호스팅 주소는 공개 주소라 주소를 아는 사람은 누구나 파일을 볼 수 있습니다.
- 급식·날씨·미세먼지는 이 폴더가 아니라 **나이스·Open-Meteo 에서 보드가 직접** 받습니다(`board_config.h` 의 코드·위치).
- 수업 교체(결보강) 같은 매일 바뀌는 내용은 자료를 다시 만들어 `firebase deploy` 하면 됩니다. 보드는 1시간 안에 받아 갑니다.
